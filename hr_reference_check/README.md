# Vérification de Références (hr_reference_check)

Checklist de vérification de références : questions standardisées par référence contactée, synthèse d'avis, go/no-go tracé et archivé avec la candidature.

## Problème
Appeler les références d'un candidat finaliste est improvisé : questions variables, avis non tracés, aucune preuve de la vérification.

## Fonctionnalités
- Checklist de questions standardisée
- Suivi par référence contactée
- Synthèse d'avis structurée
- Décision tracée
- Archivage avec la candidature

## Dépendances
- `recruitment`, `mail`
