# Mutations Inter-Sociétés (hr_group_transfers)

Assistant de mutation : transfert du dossier salarié entre sociétés du groupe, continuité des données (contrat, congés reportés, documents), trace complète et dual-data cohérente.

## Problème
Déplacer un salarié d'une filiale à une autre exige de recopier le dossier, recalculer les droits et cohérer deux dossiers : sources d'erreurs et de perdus de vue.

## Fonctionnalités
- Transfert entre sociétés du groupe
- Continuité des droits reportés
- Documents recopiés avec trace
- Calendrier de bascule
- Journal complet du transfert

## Dépendances
- `hr`, `hr_holidays`, `mail`
