# Regroupement d'Interventions (job_merge)

Détecteur de regroupements : interventions compatibles (site, jour, compétences), proposition de fusion et gains chiffrés (km, temps).

## Problème
Deux interventions chez le même client le même jour doublent les trajets et les coûts fixes.

## Fonctionnalités
- Détection de compatibilités
- Proposition de fusion
- Gains chiffrés
- Application au planning
- Statistiques d'économies

## Dépendances
- `project`, `mail`
