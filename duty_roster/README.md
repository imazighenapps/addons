# RosterBook

Fair Rounds, Weeks Ahead

## The problem

On-call schedules live in spreadsheets, rotations become unfair, and nobody can prove who was on duty or what compensation each assignment earned.

## The solution

Plan the on-call roster weeks ahead with fair rotations and the compensation each duty earns.

## Main features

- Duty rosters with a clear planning period.
- Slots per employee with start, end and compensation.
- Draft, published and closed workflow for each roster.
- Stored slot and compensation totals per roster.
- Search filters for draft, published and closed plans.
- Grouping by state for planning visibility.
- Validation of dates and compensation amounts.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Roster Book** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
