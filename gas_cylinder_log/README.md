# GasCylinderLog

Gas Cylinder Tracking Register

## The problem

Gas cylinders tracked on slips are lost with their deposits and tests.

## The solution

Track gas cylinders with reference, gas type, capacity, supplier, test dates and states.

## Main features

- Cylinders with reference, gas type and capacity.
- Supplier partner and storage location.
- Last and next test dates.
- Draft, in use, empty, returned and cancelled states.
- Search and grouping by gas type, supplier and state.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Gas Cylinders** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
