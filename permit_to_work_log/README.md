# PermitToWorkLog

Permit to Work Register

## The problem

High-risk work permits on paper hide approvals and expiry.

## The solution

Authorize and track high-risk work permits with type, location, contractor, validity and states.

## Main features

- Permits with type, location and description.
- Contractor or requester and safety measures.
- Validity start and end dates.
- Draft, requested, approved, active, closed and cancelled states.
- Search and grouping by type, location and state.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Permits to Work** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
