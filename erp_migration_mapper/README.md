# Mapper de Migration de Données (erp_migration_mapper)

Mapper générique de migration : tables sources importées, correspondances assistées par similarité, essai à blanc, journal des écarts non mappés.

## Problème
Migrer depuis un ancien ERP (fichiers tiers, produits, commandes) demande un mapping refait à chaque projet avec des essais hasardeux.

## Fonctionnalités
- Import des tables sources
- Correspondances assistées
- Essai à blanc avec rapport
- Écarts non mappés
- Projet de migration réutilisable

## Dépendances
- `base`, `mail`
