# Déploiement de Préréglages (preset_deployer)

Déploiement de préréglages : paquet de modules + réglages par vertical, installation contrôlée avec étapes, journal et vérification finale.

## Problème
Démarrer une nouvelle instance exige la même liste de modules et de réglages, répétée par erreur à chaque fois.

## Fonctionnalités
- Paquet par vertical
- Installation contrôlée par étapes
- Vérification finale
- Journal de déploiement
- Paquets versionnés

## Dépendances
- `base`, `mail`
