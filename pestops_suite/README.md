# PestOps Suite — Odoo 19 Community

This is the meta-module for installing the complete PestOps suite.

It contains no business logic. Installing it pulls the following modules:

- Core
- Sales
- Accounting
- Stock & traceability
- Portal
- Calendar
- Automation
- Equipment
- Quality & compliance
- Analytics & BI
- Proof & signatures
- Localization
- Production hardening

For installations where Accounting, Sales or Portal are intentionally omitted,
install the individual PestOps modules instead of this meta-module.
