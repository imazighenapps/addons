# ExpenseGuard - Expense Policy Compliance

## The problem

Managers approve expense claims without seeing that the receipt is missing, the cap is exceeded or the expense is six months old. Finance finds out after reimbursement.

## The solution

Control expense claims against your own policy: amount caps, receipt required, maximum age, duplicate check, block or warn, with an audit trail.

## Main features

- Policy per expense category.
- Amount cap, receipt required, maximum age.
- Block or warn mode.
- Permanent violation audit trail.
- Message on the expense and in the chatter.
- Violation report.
- Works with standard expenses.

## Installation

1. Install the module from the Apps list.
2. Open the **Expense Control** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
