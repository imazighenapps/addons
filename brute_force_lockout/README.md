# Anti-Force-Brute (brute_force_lockout)

Verrouillage temporaire après N échecs par utilisateur et/ou IP, fenêtres glissantes, alertes et liste de déblocage contrôlée.

## Problème
Aucun verrouillage après échecs répétés : les attaques par dictionnaire tournent sans limite.

## Fonctionnalités
- Verrouillage après N échecs
- Fenêtres glissantes
- Alertes d'attaque
- Déblocage contrôlé
- Journal des tentatives

## Dépendances
- `base`, `mail`
