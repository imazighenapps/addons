# Ritenuta Italie (it_ritenuta_desk)

Registre ritenuta IT : calcul par régime, certificazione unica annuelle, reversement F24 et journal de conformité.

## Problème
La ritenuta d'acconto italienne (professionnels/co.co.co) exige calcul, certificazione unica et reversement précis.

## Fonctionnalités
- Calcul par régime
- Certificazione unica
- Reversement F24
- Journal de conformité

## Dépendances
- `account`, `mail`
