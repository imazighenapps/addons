# EcoFlowPro - Engineering Change Orders on Bills of Materials

## The problem

BOM corrections are typed straight into the bill of materials with no request, no approval and no effective date, so a running BOM can be silently changed, a supplier substitution is never traced back, and nobody knows which ECO moved which quantity.

## The solution

Turn every bill of materials correction into a tracked engineering change request with review, approval and one-click application on the BOM.

## Main features

- Engineering change requests with ECO number and effective date.
- Change lines typed add, remove or change with old and new qty.
- Target BOM chosen directly or as the first BOM of the template.
- Draft, review, approved, applied and refused workflow.
- Apply writes the BOM: qty change, line creation or removal.
- Application blocked until the request is approved.
- Reset to draft for refused or already applied requests.
- Multi-company audit trail in the chatter.

## Installation

1. Install the module from the Apps list.
2. Open the **Engineering Changes** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
