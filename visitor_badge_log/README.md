# VisitorBadge

Visitor Badge Issuance Log

## The problem

Visitor badge issuance tracked on paper lacks visibility on outstanding badges and return status.

## The solution

Register visitor badges and log issuance with visitor, host and times, track issued/returned/lost status, and keep a company-safe badge history.

## Main features

- Badge catalogue with identifier.
- Issuance records with visitor, host and times.
- Issued, returned and lost states.
- Return and lost actions updating status and times.
- Search and group by badge, visitor and state.
- Chatter tracking on issuances.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Visitor Badges** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
