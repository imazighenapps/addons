# Absences Familiales Codifiées (hr_family_event_leave)

Catalogue d'absences familiales : droits par événement (durée, rémunération), justification exigée, décompte automatique et contrôle avant validation.

## Problème
Les droits d'absence pour événements familiaux (mariage, naissance, décès, enfant malade) dépendent du type : appliqués de mémoire, parfois contestés.

## Fonctionnalités
- Catalogue par type d'événement
- Durée et rémunération paramétrées
- Justification exigée
- Décompte automatique
- Contrôle avant validation

## Dépendances
- `hr`, `hr_holidays`, `mail`
