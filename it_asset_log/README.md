# ITAssetLog

IT Asset Assignment Register

## The problem

Spreadsheet-based IT asset tracking leaves assignments and lifecycle status unclear.

## The solution

Register IT assets with tag/serial, assignee, status and key dates to track assignments and lifecycle states.

## Main features

- Asset records with tag/serial, type and model details.
- Current assignee, location and status.
- Purchase/warranty dates and notes.
- Draft, in use, in repair, spare and retired states.
- Assignment and lifecycle notes.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **IT Assets** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
