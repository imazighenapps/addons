# KeyCustody

Key and Badge Issuance Tracking

## The problem

Physical keys and badges tracked informally lead to unknown holders, lost items and weak accountability.

## The solution

Register physical keys and badges, track issuance and return per employee, mark items issued, returned or lost, and keep a company-safe custody history.

## Main features

- Key/badge catalogue with identifier and type.
- Custody records per employee with issue and return dates.
- Issued, returned and lost states.
- Return and lost actions updating status and dates.
- Search and group by item, employee and state.
- Chatter tracking on custody records.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Key Custody** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
