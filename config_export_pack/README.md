# Export/Import de Configuration (config_export_pack)

Export des paramètres système et configurations clés vers un fichier de lot, diff avant import, import contrôlé dans une autre instance.

## Problème
Répliquer une configuration d'instance vers une autre (nouveau site, nouvelle filiale) est un travail manuel d'homothétie.

## Fonctionnalités
- Export vers fichier de lot
- Diff avant import
- Import contrôlé
- Périmètres paramétrables
- Journal des déploiements

## Dépendances
- `base`, `mail`
