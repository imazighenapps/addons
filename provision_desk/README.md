# ProvisionBook

Provisions, Recomputed

## The problem

Bad debt and warranty provisions are recomputed in spreadsheets with overwritten lines, leaving no auditable trail of how the balance moved from one month to the next.

## The solution

Recompute your bad debt and warranty provisions every month and keep an auditable trail of each movement.

## Main features

- A register of provisions with type, owner and opening balance.
- Dated movements for every increase and decrease with a reason.
- Current balance computed and stored from the movement history.
- Provision types for bad debt, warranty and other risks.
- Open and closed states with a controlled workflow.
- Movements refused on a closed provision.
- Amounts guarded against impossible values.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Provision Book** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
