# Customer Order Snapshot

Give salespeople a concise, contextual view of recent customer buying behavior while preparing an order.

Target: Odoo 19 Community and Enterprise.

## Product principles
- Uses Odoo native business objects as the source of truth.
- No Enterprise-only dependency in the core module.
- English UI with French and Spanish translation files.
- Server-side validation and automated tests for critical workflows.
- No parallel stock, sales, purchasing, POS or MRP engines.
