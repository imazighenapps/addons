# Quêtes d'Apprentissage (learning_quest_engine)

Moteur de quêtes d'apprentissage : parcours par compétences, séries de missions, jalons récompensés et tableaux de progression par équipe.

## Problème
Les parcours de formation interne s'essoufflent : aucune dynamique de progression visible ni séquence motivante.

## Fonctionnalités
- Parcours par compétences
- Missions séquencées
- Jalons récompensés
- Progression par équipe
- Séries et régularité

## Dépendances
- `hr`, `mail`
