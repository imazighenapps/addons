# Campagne d'Évaluation Annuelle (hr_appraisal_campaign)

Campagne structurée : formulaires par famille de métier, rappels automatiques aux retards, consolidation multi-niveaux, décisions de rémunération et de carrière rattachées.

## Problème
Les évaluations annuelles se lancent par emails dispersés : forms non retournés, managers en retard, aucune consolidation pour la direction.

## Fonctionnalités
- Formulaires par famille de métier
- Rappels automatiques
- Consolidation par service
- Décisions rattachées (rémunération, carrière)
- Historique par campagne

## Dépendances
- `hr`, `mail`
