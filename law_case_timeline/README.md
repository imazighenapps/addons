# Chronologie d'Affaire & Délais (law_case_timeline)

Chronologie par dossier : étapes procédurales avec délais légaux calculés, alertes, historique des actes et statut d'avancement.

## Problème
Les avocats suivent les délais de procédure (assignation, conclusions, audiences) sur des agendas personnels : un délai raté est une responsabilité.

## Fonctionnalités
- Étapes procédurales par dossier
- Délais calculés avec alertes
- Historique des actes
- Vue par avocat et par dossier
- Dossier clos avec archivage

## Dépendances
- `crm`, `mail`
