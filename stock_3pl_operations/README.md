# 3PL Operations

Unified third-party logistics management for Odoo.

## Features

- 3PL contracts with customer, warehouse, and billing rates
- Periodic stock statements with opening/inbound/outbound/closing quantities
- Billing lines and invoice generation
- Chatter tracking and multi-company support
