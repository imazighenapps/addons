How it works

From quotation line to confirmed order

Every confirmation attempt goes through the same rigorous resolution engine, so the result is always predictable.

1
Scan Lines

Every quotation line's product, template and category are inspected
2
Match Rules

Active rules are searched in order: Product > Category > Customer > Global
3
Resolve Strictest

If several rules match at the same level, the highest minimum margin wins
4
Convert Currency

Product cost is converted to the order's currency before comparison
5
Decide

Order confirms, or is blocked with a clear message — unless the user can override
Rule Engine

Four levels of priority

Rules are checked from the most specific to the most general scope, so exceptions always take precedence over defaults.

Priority Scope Field Example
1 Product / Template product_id / product_tmpl_id Never sell this laptop below 12% margin
2 Product Category categ_id All "Electronics" products require 8% minimum
3 Customer partner_id Key account X always requires at least 5%
4 Global Default ir.config_parameter Company-wide fallback of 10%, set once in Settings

Rules can optionally be scoped to a single company, or left empty to apply everywhere.

Configuration

Up and running in minutes

No developer knowledge required — everything is configured from the Sales app.

1
Install the module

Copy sale_margin_block_pro to your addons path, restart Odoo, then go to Settings → Apps and click Install.
2
Set your default margin

Go to Settings → Sales → Sales Margin Control and set the Default Minimum Margin (%) applied when no specific rule matches.
3
Create advanced rules

Open Sales → Margin Control → Margin Rules and scope exceptions by product, template, category or customer.
4
Grant override rights if needed

Sales Managers get override rights automatically. Assign the "Override Margin Block" group to individual users from Settings → Users if required.
5
Sell as usual

Every quotation now shows its live margin and the required threshold. Confirmation is blocked automatically whenever the rule is breached.

FAQ

Common questions

Everything you need to know before installing.

Can sales reps edit or delete margin rules?
No. Only users in the Sales Manager group can create, edit or delete rules. Sales reps have read-only access, so they know the target margin but can never weaken a rule to get an order through.
What happens if several rules match the same order?
The engine always keeps the strictest (highest) minimum margin among the matching rules at the same priority level, so an order can never slip through because of an unrelated low-margin line.
What if no rule matches the order?
The module falls back to the Default Minimum Margin defined once in Settings → Sales → Sales Margin Control.
Is every override tracked?
Yes. Every blocked attempt and every override is recorded in the Margin Block / Override Log, accessible from the Sales menu and from a smart button directly on the order. Overrides are also posted to the order's chatter.
Does it work with multi-currency companies?
Yes. Product cost is automatically converted to the order's currency before the margin is calculated, so the comparison is always accurate.
Can I have different rules per company?
Yes. Each rule can be scoped to a specific company, or left empty to apply across your whole group.
