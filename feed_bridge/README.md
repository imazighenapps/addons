# FeedBridge - Google and Meta Product Feeds

## The problem

Product data in Odoo rarely matches the Google Merchant specs. The team exports a manual CSV, discovers the errors in the Merchant Center, and the feed is outdated the next day.

## The solution

Generate validated Google Merchant and Meta product feeds in XML or CSV, with a public URL, error report and automatic refresh.

## Main features

- Google Merchant and Meta feed formats.
- XML and CSV output.
- Public token URL.
- Automatic daily refresh.
- Validation report per product.
- Variant export.
- Live stock and price.

## Installation

1. Install the module from the Apps list.
2. Open the **Product Feeds** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
