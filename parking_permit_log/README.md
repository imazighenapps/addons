# ParkingPermitLog

Parking Permit Register

## The problem

Informal parking permit tracking causes unclear authorizations and expired or duplicate permits.

## The solution

Register parking permits with holder, vehicle, zone/spot and validity dates, tracking active, expired and cancelled authorizations.

## Main features

- Permit records with holder, vehicle plate and zone/spot.
- Start and expiry dates with responsible issuer.
- Permit type and notes.
- Draft, active, expired and cancelled states.
- Search and filters by state and validity dates.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Parking Permits** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
