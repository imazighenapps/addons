# Dictionnaire de Données Généré (data_dictionary_doc)

Génération du dictionnaire de données : modèles, champs, relations, obligations, valeurs par défaut, export HTML/Excel et horodatage par version.

## Problème
Documenter les modèles et champs d'une instance personnalisée est un chantier manuel qui se périme dès la première évolution.

## Fonctionnalités
- Modèles et champs documentés
- Relations et obligations
- Export HTML/Excel
- Horodatage par version
- Filtres par module

## Dépendances
- `base`, `mail`
