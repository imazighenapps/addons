# Etsy Bridge

Sync Etsy listings and orders

## The problem

Etsy orders and listing updates are managed separately, causing stock mismatches and fulfillment delays.

## The solution

Connect Etsy shop to import orders, sync listing references and track fulfillment status from Odoo.

## Main features

- Etsy shop connection profile.
- Order records with status and tracking.
- Listing sync entries linked to products.
- Import/fulfill/cancel actions.
- Sync log history.
- No external Python dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Etsy Bridge** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
