# Brevo Bridge

Connect Odoo contacts with Brevo

## The problem

Contacts and campaign engagement in Brevo are disconnected from Odoo CRM, causing duplicates, stale consent data and poor visibility for sales teams.

## The solution

Sync contacts and lists with Brevo, track campaign/event feedback and keep marketing data aligned with your CRM.

## Main features

- Connection profile with API key, sender and environment.
- Contact sync entries linked to partners with mapped attributes.
- Audience/list management and membership tracking.
- Sync states and error messages with retry/reset.
- Engagement event log (delivered, opened, clicked, bounced).
- Consent/opt-in flag and last sync timestamps.
- Bulk-ready structure and audit trail.
- No external Python dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Brevo Bridge** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
