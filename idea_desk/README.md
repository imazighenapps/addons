# IdeaDesk

Ideas That Land

## The problem

Improvement ideas are raised informally and forgotten: nobody evaluates them on time, implemented ideas give no credit and employees stop sharing because nothing visible happens.

## The solution

Give employees one place to post improvement ideas, evaluate them fairly and credit the ones implemented.

## Main features

- A register of improvement ideas with author, area and expected gain.
- A simple flow from submitted to evaluated, accepted or rejected.
- Implemented ideas stamped with the date they went live.
- Review notes captured on every evaluation for a clear decision trail.
- One open-ideas screen for everything still waiting for an answer.
- A negative expected gain is refused for you.
- An implemented idea must be accepted before it is marked done.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Ideas** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
