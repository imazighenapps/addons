# Desk de Litiges sur Lignes de Commande (po_dispute_desk)

File de litiges par ligne de commande : description du désaccord, pièces jointes, proposition fournisseur, décision de l'acheteur et application concrète (avoir, régularisation, refus).

## Problème
Les désaccords sur une ligne de commande (quantité livrée, prix appliqué, date ratée) se règlent par emails épars sans verdict ni trace.

## Fonctionnalités
- Litige ouvert sur une ligne
- Pièces jointes et échanges tracés
- Décision avec justification
- Application opérationnelle reliée
- Statistiques par fournisseur

## Dépendances
- `purchase`, `account`, `mail`
