# CycleCountPro - Inventory Cycle Counting

## The problem

A full inventory stops the warehouse for a day, and the stock is still wrong three weeks later because nobody counts regularly.

## The solution

Plan ABC cycle counts, count by location, control variances and post stock adjustments without freezing the warehouse.

## Main features

- Count plans per warehouse with frequency.
- Sessions with theoretical quantities prefilled.
- Count by product and location.
- Variance in quantity and value.
- Review before posting the adjustment.
- Standard Odoo stock adjustment.
- Session history and counter tracking.
- Scheduled session creation.

## Installation

1. Install the module from the Apps list.
2. Open the **Cycle Counting** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
