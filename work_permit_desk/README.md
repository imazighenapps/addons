# WorkPermit

Permits Before Tools

## The problem

Contractor interventions start on verbal approval, so reception cannot verify who is authorised, for which zone or until when the work may happen.

## The solution

Authorise each contractor intervention on site with a dated work permit and a validity the reception checks.

## Main features

- A register of contractor work permits with site area and scope.
- Validity period with start and end dates checked at the gate.
- Authorisation workflow before work can begin.
- A close action that stamps when the intervention ended.
- Active and expired permits visible in one screen.
- One register for every contractor intervention on site.
- An end date before the start date is refused for you.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Work Permits** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
