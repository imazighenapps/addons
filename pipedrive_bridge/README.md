# Pipedrive Bridge

Sync deals and contacts with Pipedrive

## The problem

Deals and contacts maintained in Pipedrive become out of sync with Odoo, creating duplicate work and poor visibility.

## The solution

Synchronize contacts and deals between Odoo CRM and Pipedrive with status tracking and sync logs.

## Main features

- Pipedrive connection profile with token reference.
- Contact sync linked to partners.
- Deal sync linked to CRM opportunities.
- Direction and status tracking with error messages.
- Prepare/sync/reset actions and sync logs.
- No external Python dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Pipedrive Bridge** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
