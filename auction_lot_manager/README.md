# Lots d'Enchère & Adjudications (auction_lot_manager)

Lots d'enchère avec estimations, adjudications enregistrées, facturation avec primes acheteur/vendeur et suivi des impayés de vente.

## Problème
La maison de ventes gère catalogues, adjudications, primes acheteur et impayés dans des fichiers séparés.

## Fonctionnalités
- Lots avec estimations
- Adjudications enregistrées
- Primes acheteur/vendeur appliquées
- Facturation des enchérisseurs
- Impayés de vente suivis

## Dépendances
- `sale`, `account`, `mail`
