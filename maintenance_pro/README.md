# MaintenancePro - Equipment Maintenance Management

## The problem

Maintenance lives in a paper logbook and a shared spreadsheet: preventive services are forgotten, breakdowns are repaired twice, warranty deadlines are missed and nobody can say what a machine really costs per year.

## The solution

Keep an equipment register, plan preventive maintenance and track corrective requests with downtime, costs and full history.

## Main features

- Equipment register with code, category, location, serial number and criticality.
- Warranty tracking with a purchase date control.
- Preventive plans with a period in days and an automatic next due date.
- Daily scheduler that creates the preventive work orders.
- Corrective requests with priority, technician and scheduled date.
- Downtime, duration and cost recorded on every intervention.
- Status workflow with chatter and full history.
- Filters and grouped views per equipment, type, state and technician.

## Installation

1. Install the module from the Apps list.
2. Open the **Maintenance** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
