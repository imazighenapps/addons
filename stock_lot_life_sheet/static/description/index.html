Feature 01

Every Detail in One Structured Record

The list view keeps the fields your team checks every day, and the form groups the full record — parties, dates, amounts, progress and history — on a single page.

  • ✓ List columns: Reference, Partner, Responsible, Start Date, Amount, Progress and Status
  • ✓ Status bar: Draft → Confirmed → In Progress → Done
  • ✓ Header actions: Confirm, Start, Done, Cancel and Reset to Draft
  • ✓ Tracked fields: Reference, Partner, Responsible, Start Date, End Date and Amount
  • ✓ Detailed text: Description, Notes and Journal
  • ✓ Export file generated and attached to the record
  • ✓ Chatter with mail, activities and change history
