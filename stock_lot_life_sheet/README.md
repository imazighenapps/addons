# Fiche de Vie du Lot (stock_lot_life_sheet)

Fiche de vie du lot : dossier unique par lot (réceptions, contrôles qualité, blocages, mouvements, expéditions), PDF exportable pour l'audit.

## Problème
Pour un lot contesté, reconstituer sa vie (réceptions, blocages, contrôles, expéditions) exige de fouiller plusieurs rapports.

## Fonctionnalités
- Dossier unique par lot
- Événements qualité inclus
- Historique des blocages
- Expéditions rattachées
- Export PDF d'audit

## Dépendances
- `stock`, `mail`
