# Registre ICPE (icpe_permit_registry)

Registre ICPE : autorisations avec conditions, inspections datées, actions correctives et échéances de rapports.

## Problème
Les sites soumis aux installations classées suivent autorisations, inspections et conditions d'exploiter dans des classeurs.

## Fonctionnalités
- Autorisations avec conditions
- Inspections datées
- Actions correctives
- Échéances de rapports
- Historique de site

## Dépendances
- `documents`, `mail`
