# Réception des Machines (FAT/SAT) (maintenance_machine_acceptance)

Module de réception : checklists FAT/SAT paramétrables, essais exécutés avec critères, liste des défauts résiduels et archivage du PV d'acceptation.

## Problème
Réceptionner une machine neuve (essais fournisseur FAT, essai sur site SAT) se fait avec des checklists papier : PV perdus, défauts non suivis.

## Fonctionnalités
- Checklists FAT/SAT paramétrables
- Essais avec critères et résultats
- Défauts résiduels suivis jusqu'à levée
- PV d'acceptation signé
- Lien avec la fiche d'équipement

## Dépendances
- `maintenance`, `purchase`, `mail`
