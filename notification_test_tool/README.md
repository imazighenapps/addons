# Testeur de Notifications (notification_test_tool)

Testeur de notifications : envoi d'essai d'un template vers un destinataire de test, diagnostic complet et historique des tests.

## Problème
Vérifier qu'un template d'email, SMS ou webhook part correctement exige de déclencher un vrai événement métier.

## Fonctionnalités
- Envoi d'essai par template
- Destinataire de test
- Diagnostic complet
- Historique des tests
- Rapport de conformité

## Dépendances
- `mail`
