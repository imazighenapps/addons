# Échéanciers Emprunts Bancaires (bank_loan_schedule)

Registre d'emprunts : échéancier complet, distinction capital/intérêts/assurance, réécriture automatique des échéances, provisions d'intérêts courus et clôture anticipée avec frais.

## Problème
Les échéanciers d'emprunts (capital+intérêts, assurance, frais) vivent dans Excel et alimentent mal la comptabilité.

## Fonctionnalités
- Échéancier capital/intérêts/assurance
- Provision d'intérêts courus
- Clôture anticipée avec pénalités
- Courbe de dette restante
- État de conformité bancaire

## Dépendances
- `account`, `mail`
