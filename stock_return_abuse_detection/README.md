# Détection d'Abus de Retours (stock_return_abuse_detection)

Détection d'abus : indicateurs par client (fréquence, valeur, motifs suspects), score d'abus, seuils d'alerte et restriction documentée.

## Problème
Certains clients multiplient les retours (port, refus, motif douteux) : la fraude aux retours n'est jamais chiffrée.

## Fonctionnalités
- Indicateurs par client
- Score d'abus
- Seuils d'alerte
- Restriction documentée
- Historique des signalements

## Dépendances
- `stock`, `sale`, `mail`
