# Rework

Second Pass, Documented

## The problem

Rejected output is reworked informally, so there is no trace of the reason, the quantity fixed or who performed the second pass.

## The solution

Turn rejected production output into a controlled rework order with the trace instead of a whispered fix.

## Main features

- A register of rejected production output with quantity and reason.
- Controlled rework orders linked to each rejection.
- A workflow from draft to planned, running and done.
- Quantities compared so rework cannot exceed the rejection.
- Owners and planned dates kept on every rework order.
- Stored counters for rework orders per rejection.
- Completion dates recorded on done orders.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Rework** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
