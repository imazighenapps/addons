# ReturnFlow Pro

Customer Returns Desk

## The problem

In Odoo Community a customer return is a bare reverse transfer with no motive, no inspection, no decided outcome and no guided link to the credit note, so every return is handled manually and the quality signal is lost.

## The solution

Handle customer returns from validated deliveries: multi-line returns with configurable motives, a received/inspected workflow with restock, repair or scrap outcome, and a guided credit note in one company-safe desk.

## Main features

- Multi-line return created from a validated delivery.
- Configurable return motives, tracked on every return.
- Workflow: requested, received, inspected, restocked, repaired or scrapped.
- Returned quantity is capped at the delivered quantity.
- Restock posts stock in; scrap does not move stock back.
- Guided credit note pre-filled from the inspected return lines.
- Kanban and search by customer, product, motive and state.
- Multi-company and multi-currency safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Returns** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
