# Taux de Première Visite Fructueuse (first_fix_rate)

Taux de résolution à la première visite : chaînage des visites par site/équipement, motifs de seconde visite et plan d'action.

## Problème
Les interventions suivies d'une seconde visite (pièce manquante, diagnostic raté) coûtent double : le KPI n'est pas mesuré.

## Fonctionnalités
- Chaînage des visites
- Motifs de retour
- Taux FTR par équipe
- Coût des re-visites
- Plan d'action

## Dépendances
- `project`, `mail`
