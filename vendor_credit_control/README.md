# Contrôle des Avoirs Fournisseurs (vendor_credit_control)

Confrontation des avoirs : chaque dossier générateur d'avoir (retour, écart, pénalité) est comparé à l'avoir réellement reçu, avec alerte sur les manquants et vieillissement.

## Problème
Les avoirs promis par les fournisseurs (retours, manquants, pénalités) tombent parfois, parfois pas : aucune confrontation avec ce qui était dû.

## Fonctionnalités
- Dossier générateur d'avoir tracé
- Confrontation avec l'avoir reçu
- Alerte sur les manquants
- Vieillissement des dossiers
- Bilan par fournisseur

## Dépendances
- `purchase`, `account`, `mail`
