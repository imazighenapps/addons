# Primes de Production (hr_production_bonus_calc)

Moteur de primes : règles par ligne et par équipe (rendement, qualité, temps perdu), calcul depuis les données MO, validation du chef et export vers la paie.

## Problème
Les primes de rendement d'atelier (individuelles, d'équipe) sont calculées à la main chaque mois depuis les MOs : disputes et erreurs fréquentes.

## Fonctionnalités
- Règles de prime paramétrables
- Calcul depuis les données MO
- Validation du chef d'équipe
- Simulation avant clôture
- Export pour la paie

## Dépendances
- `mrp`, `hr`, `mail`
