# VehicleInspectionLog

Vehicle Inspection Register

## The problem

Vehicle inspection records on paper hide open defects and due dates.

## The solution

Record periodic vehicle inspections with odometer, check results, inspector and states.

## Main features

- Inspections with vehicle plate, model and date.
- Odometer reading at inspection.
- Brake, tyre, light and body check results.
- Responsible inspector and notes.
- Draft, passed, defect and cancelled states.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Vehicle Inspections** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
