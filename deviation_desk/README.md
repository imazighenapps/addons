# Deviation

Deviations Closed For Real

## The problem

Production deviations are discussed but not formally reviewed, so impact assessment and approval are missing when quality needs to release or block a batch.

## The solution

Record every unplanned production deviation, judge its impact and close it with the approvals quality needs.

## Main features

- A register of production deviations with area, product and owner.
- Impact reviews with risk level, judgement and reviewer.
- A workflow from draft to investigation, approval and closure.
- Approvals recorded with decision, approver and date.
- Open deviations filtered for quality follow-up.
- Closure refused until an approval is granted.
- Stored counters for impact reviews and approvals.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Deviations** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
