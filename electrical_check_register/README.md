# Contrôles Électriques Périodiques (electrical_check_register)

Registre des installations avec échéances de contrôle, certificats joints, anomalies relevées et levées suivies.

## Problème
Les installations électriques exigent des contrôles périodiques dont les certificats se perdent dans les tiroirs.

## Fonctionnalités
- Installations avec échéances
- Certificats joints
- Anomalies relevées
- Levées suivies
- Alertes avant échéance

## Dépendances
- `documents`, `mail`
