# PackCheck

Checked Before It Leaves

## The problem

Packing benches rely on memory and handwritten notes, so weight and count errors are discovered only after shipping disputes or customer claims.

## The solution

Verify weight and piece count on the packing bench before the box leaves, with a log the claims team can trust.

## Main features

- A packing check register with expected and actual weight and count.
- Variance and pass or fail result computed and stored on each check.
- A workflow to draft, verify, approve or reject every packing check.
- A decision date stamped when a check is approved or rejected.
- Search filters and group-by views for result and status.
- A dedicated log view of approved checks for claims follow-up.
- Notes to capture issues found at the packing bench.
- Multi-company isolation with per-company records.

## Installation

1. Install the module from the Apps list.
2. Open the **Packing** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
