# Résumé des Documents (doc_summarizer)

Résumeur intelligent : résumé structuré des documents (parties, montants, échéances, clauses sensibles), affiché sur l'enregistrement.

## Problème
Les contrats, BL et rapports longs ne sont jamais lus en entier : des clauses risquées passent.

## Fonctionnalités
- Résumé structuré
- Points sensibles
- Affichage sur record
- Journal
- Modèle configurable (local/API)

## Dépendances
- `base`, `mail`
