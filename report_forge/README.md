# ReportForge - No-Code Document Templates

## The problem

Every change to a quote or invoice layout needs a developer, a QWeb template and a deployment. Business teams wait weeks for a logo or a footer.

## The solution

Build your own PDF documents with placeholders, no QWeb developer needed: quotes, invoices, letters and product sheets.

## Main features

- No-code templates with {{ field }} placeholders.
- Automatic line tables with {{ lines }}.
- Header and footer per template.
- Generate PDF from contacts, quotations and invoices.
- Template versioning.
- Archived PDF attachment.

## Installation

1. Install the module from the Apps list.
2. Open the **Report Forge** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
