# Rôles Réutilisables (reusable_role_manager)

Rôles réutilisables : paquets de groupes par métier, application contrôlée avec diff, héritages et audit des attributions.

## Problème
Réattribuer un métier (comptable, magasinier) exige de cocher dix groupes : erreurs et incohérences entre sites.

## Fonctionnalités
- Rôles = paquets de groupes
- Application avec diff
- Héritages de rôles
- Audit des attributions
- Paquets standards fournis

## Dépendances
- `base`, `mail`
