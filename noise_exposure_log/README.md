# NoiseExposureLog

Workplace Noise Measurement Register

## The problem

Noise readings tracked in folders leave 85 dB exceedances unclear.

## The solution

Record noise measurements with area, level, exposure duration, limit and exceedance flag.

## Main features

- Measurements with area, date and optional employee.
- Measured level and exposure duration.
- Configurable limit with automatic exceedance flag.
- Responsible measurer and notes.
- Draft, recorded, action required and cancelled states.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Noise Exposure** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
