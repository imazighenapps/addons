# Intrastat

Flows Filed, Not Guessed

## The problem

Intra-EU dispatch and arrival figures are gathered from scattered moves at filing time, so the declaration is late, incomplete and impossible to justify when the customs office asks questions.

## The solution

Assemble the intra-EU dispatch and arrival data from your moves and hand the customs office a filing file.

## Main features

- Declarations per period and direction, dispatch or arrival.
- Flow lines with partner country, commodity code and net mass.
- Quantity and invoice value recorded on every movement line.
- Stored line count and total value on each declaration.
- Draft, review and filed states with a dated filing stamp.
- Filed declarations locked to preserve the submitted figures.
- A review screen for declarations still waiting to be filed.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Intrastat** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
