# FieldWatch

Field Change Audit Trail

## The problem

A price, a credit limit or an address changes without a trace: the value is saved in the chatter, mixed with notes and emails, and nobody can say who changed it, when, or what the previous value was without reading the whole thread.

## The solution

Turn Odoo native tracking into a readable audit journal: who changed which field, when, from what to what, filterable by model, user and date.

## Main features

- Audit journal built from native tracking values.
- Old and new value on every line.
- Watch rules per model, with an optional field list.
- Collector filterable by period, model and rule.
- Search and group by model, user, field and date.
- Reviewed, ignored and reopen workflow.
- No duplicate on a second collection.
- Kanban, graph and pivot, multi-company isolation.

## Installation

1. Install the module from the Apps list.
2. Open the **Audit** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
