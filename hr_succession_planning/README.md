# Plan de Succession (hr_succession_planning)

Plan de succession : postes clés recensés, successeurs potentiels avec readiness, plans de développement associés, alerte sur les postes sans plan.

## Problème
Les postes clés (direction, technique, commercial) n'ont pas de successeur identifié : un départ imprévu met l'entreprise en danger.

## Fonctionnalités
- Postes clés recensés
- Successeurs et readiness
- Plans de développement associés
- Alerte sur les postes sans plan
- Revue annuelle tracée

## Dépendances
- `hr`, `mail`
