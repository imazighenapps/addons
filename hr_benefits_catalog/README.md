# Catalogue d'Avantages Salariés (hr_benefits_catalog)

Catalogue d'avantages : offres partenaires avec conditions, éligibilité par salarié, demandes de remboursement ou codes, statistique d'usage par catégorie.

## Problème
Les avantages négociés (remises partenaires, billetterie, abonnements) restent connus des seuls voisins de bureau : jamais centralisés ni mesurés.

## Fonctionnalités
- Offres partenaires centralisées
- Éligibilité par salarié
- Demandes ou codes tracés
- Usage par catégorie
- Rapport annuel des avantages

## Dépendances
- `hr`, `mail`
