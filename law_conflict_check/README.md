# Contrôle de Conflit d'Intérêts (law_conflict_check)

Recherche de conflit : saisie des parties du nouveau dossier, recherche inverse dans tous les dossiers et clients, attestation de non-conflit archivée.

## Problème
Avant d'accepter un nouveau client, le cabinet doit vérifier qu'aucun opposant n'est déjà client : vérification faite de mémoire.

## Fonctionnalités
- Saisie des parties du dossier
- Recherche inverse multi-dossiers
- Attestation de non-conflit datée
- Historique des contrôles
- Alertes de similitude de noms

## Dépendances
- `crm`, `sale`, `mail`
