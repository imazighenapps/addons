# FMEA Produit et Process (quality_fmea_register)

Registre FMEA : causes, effets et maîtrises par ligne, calcul d'indice de criticité, actions assignées avec clôture vérifiée, révision datée par version.

## Problème
Les FMEA vivent dans Excel jamais synchronisés avec les processus réels : les actions restent ouvertes sans suivi.

## Fonctionnalités
- Lignes FMEA avec cotation (G/O/D)
- Indice de criticité calculé
- Actions assignées et vérifiées
- Versions datées par révision
- Lien avec les gammes et contrôles

## Dépendances
- `quality`, `mrp`, `mail`
