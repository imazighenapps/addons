# VIESGuard - EU VAT Number Validation

## The problem

A wrong intra-community VAT number means a wrong reverse charge, a wrong declaration and a tax adjustment. Nobody keeps a dated proof that the number was valid when the invoice was issued.

## The solution

Check every EU VAT number against the official VIES service, keep a dated proof, re-check automatically and audit every result.

## Main features

- Automatic VIES check on partner creation and VAT change.
- Valid, invalid or unavailable status with the VIES message.
- Trader name and address from VIES.
- Dated audit trail of every check.
- Batch verification wizard.
- Automatic re-check scheduler.
- Warning on the partner form.
- Multi-company.

## Installation

1. Install the module from the Apps list.
2. Open the **VIES** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
