# Journal des Accès Refusés (deny_log)

Journal des refus : par utilisateur/règle, motifs, alertes de patterns et rapport de sécurité.

## Problème
Les tentatives d'accès refusées (pages, enregistrements) sont invisibles : signaux de sondage ou de frustration ignorés.

## Fonctionnalités
- Journal des refus
- Patterns détectés
- Alertes
- Rapport de sécurité
- Retenue

## Dépendances
- `base`, `mail`
