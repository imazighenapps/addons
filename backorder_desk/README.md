# BackorderDesk

Shortages With News

## The problem

Backordered sale lines are scattered across deliveries and emails, so promised dates, owners and customer updates are unclear and shortages linger.

## The solution

Gather every backordered sale line in one queue with the promised date and the message to send to the customer.

## Main features

- A shortage case per backordered line with customer and product.
- Quantities ordered and missing, plus the promised fulfilment date.
- A customer-facing message kept on the case for quick updates.
- Dated update notes to trace what was communicated and when.
- One open queue showing only unresolved shortages.
- Search filters for late promises and resolved cases.
- Validation that blocks negative quantities and impossible dates.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Backorders** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
