# ShelfLife

Oldest Out First

## The problem

Perishable lots expire without a clear warning, so teams ship old stock or discover waste too late because shelf life is not tracked in one place.

## The solution

Guard the shelf life of every perishable lot, push the oldest to the front and warn before dates expire.

## Main features

- A perishable lot register with product, location and quantity.
- Received and expiry dates stored on every lot.
- Remaining shelf life computed and stored in days.
- Status tracking for fresh, expiring, expired, quarantined and closed lots.
- Actions to quarantine, consume or dispose of risky stock.
- One screen focused on lots expiring soon or already expired.
- Expiry before receipt is refused for you.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Shelf Life** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
