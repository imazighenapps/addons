# Facture Proforma d'Export (export_proforma_desk)

Générateur de proforma export : HS et origine depuis la fiche produit, liste de colisage, bloc documents exigés par destination et jeu de documents export assemblé.

## Problème
L'export exige une proforma avec code HS, origine et documents (certificat d'origine, liste de colisage) : le montage se fait dans Word à chaque commande.

## Fonctionnalités
- Proforma avec HS et origine
- Liste de colisage automatique
- Documents exigés par destination
- Jeu de documents export assemblé
- Historique des dossiers export

## Dépendances
- `sale`, `stock`, `mail`
