# Bibliothèque de Questions d'Entretien (hr_interview_question_bank)

Bibliothèque de questions par métier et par compétence : questions comportementales et techniques, guide de réponse attendue, insertion en un clic dans le plan d'entretien.

## Problème
Les questions d'entretien sont improvisées à chaque recrutement : les biais se répètent et les nouveaux recruteurs ne bénéficient pas de l'expérience de l'équipe.

## Fonctionnalités
- Questions par métier et compétence
- Guide de réponse attendue
- Sélection pour le plan d'entretien
- Retours après usage (efficacité)
- Partage entre recruteurs

## Dépendances
- `recruitment`, `mail`
