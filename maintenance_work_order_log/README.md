# WorkOrderLog

Maintenance Work Order Records

## The problem

Work performed on maintenance interventions is not recorded in a structured way, so repair effort and outcomes are hard to review.

## The solution

Record maintenance interventions with equipment, technician, dates, duration, work done and outcome states to keep a clear repair history.

## Main features

- Work order records linked to equipment and optional request.
- Technician, planned/start/end dates and duration in hours.
- Work description, parts notes and outcome.
- Draft, in progress, done and cancelled states.
- History of interventions per equipment.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Work Orders** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
