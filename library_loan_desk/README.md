# Prêts de Bibliothèque (library_loan_desk)

Catalogue avec exemplaires, prêts avec dates de retour, retards et relances, file de réservations et statistiques d'emprunts.

## Problème
Les médiathèques et bibliothèques associatives gèrent catalogues, prêts et retards sur des fichiers maison.

## Fonctionnalités
- Catalogue avec exemplaires
- Prêts avec dates de retour
- Retards et relances
- File de réservations
- Statistiques d'emprunts

## Dépendances
- `stock`, `mail`
