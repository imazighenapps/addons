# EmergencyLightLog

Emergency Lighting Test Register

## The problem

Emergency lighting tests tracked on paper leave failures and due dates unclear.

## The solution

Record emergency lighting tests with location, type, duration, battery and lamp results.

## Main features

- Light records with reference, location and type.
- Test date, next test date and duration.
- Battery and lamp result flags.
- Responsible tester and notes.
- Draft, tested, failed and cancelled states.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Emergency Lighting** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
