# ProbationReviewLog

Employee Probation Review Register

## The problem

Probation reviews tracked in calendars leave decisions undocumented.

## The solution

Document employee probation periods, review dates, scores and confirmation decisions.

## Main features

- Reviews with employee, reviewer and period dates.
- Review date and 0-100 score.
- Decision: pending, passed, extended or failed.
- Draft, submitted, closed and cancelled states.
- History of probation reviews per employee.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Probation Reviews** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
