# DocExpiry - Document Expiry and Renewal Tracking

## The problem

Expiry dates live in spreadsheets, shared mailboxes and paper folders. Nobody knows which policy, certificate or licence runs out next month, renewals are started too late, and the proof of a valid document is impossible to produce during an audit.

## The solution

Keep every contract, insurance policy, certificate and licence in one register with automatic expiry status, reminder dates and one-click renewals.

## Main features

- Register for contracts, insurance, certificates and licences.
- Categories with default validity and reminder lead time.
- Expiry date proposed from the issue date.
- Live status: valid, expiring soon or expired.
- Days left and reminder date computed for each document.
- One-click renewal with old and new dates kept in history.
- Daily scheduler that logs reminders once per day.
- Multi-company register with searchable filters.

## Installation

1. Install the module from the Apps list.
2. Open the **Document Expiry** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
