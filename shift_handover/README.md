# ShiftHandover

Nothing Lost Between Shifts

## The problem

The handover between shifts lives in a paper notebook at the end of the line, or in the head of whoever leaves last. Open incidents are rediscovered at the next shift, unfinished tasks are done twice or not at all, and nobody can say who was told what.

## The solution

A dated handover book for every shift: open incidents, pending tasks, stock and quality points, with an owner, a severity and a follow-up flag for the next team.

## Main features

- Dated handover per shift, with a responsible employee.
- Items typed as incident, task, stock, quality or other.
- Severity and follow-up flag on every item.
- Resolve and reopen an item with a timestamped resolution.
- Live open-item counter on the handover.
- Draft, done and cancelled states with a chatter trail.
- Browsable by shift, status, responsible and category.
- Multi-company isolation, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Shift Handovers** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
