# Matrice d'Exposition Chimique (hr_chemical_exposure_matrix)

Matrice d'exposition : produits par poste (durée, fréquence, VLEP), protections exigées, déclenchement des surveillances médicales adaptées et historique pour les dossiers.

## Problème
Les expositions aux produits chimiques par poste (produits, durées, protections) vivent dans des fiches papier : obligations de suivi médical non pilotées.

## Fonctionnalités
- Expositions par poste
- VLEP et seuils
- Protections exigées
- Surveillance médicale déclenchée
- Historique pour dossiers

## Dépendances
- `hr`, `hr_attendance`, `mail`
