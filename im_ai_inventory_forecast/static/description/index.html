How It Works

1️⃣ Configure Algorithm

Choose Prophet, ARIMA, or Ensemble method. Set forecast horizon (7-365 days), confidence level (90-99%), and enable seasonality detection.

2️⃣ Generate Forecasts

Click "Generate Forecasts" wizard. Select products and warehouses. The AI analyzes historical stock movements (minimum 90 days) and generates predictions.

3️⃣ Monitor Dashboard

View real-time forecasts on the interactive dashboard. Analyze charts, check accuracy metrics, and review top products by predicted demand.

4️⃣ Handle Alerts

Receive automatic alerts for critical situations. Review recommended actions, acknowledge alerts, create purchase orders, or adjust inventory policies.

5️⃣ Optimize Reorder Rules

Review AI-calculated optimal min/max quantities and safety stock. Compare with current rules and apply improvements with one click.
