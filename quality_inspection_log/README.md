# QualityInspectionLog

Quality Inspection Register

## The problem

Inspections tracked on paper or spreadsheets lack traceability and consistent results.

## The solution

Record product inspections with criteria, observations, results and follow-up notes to keep a traceable quality history.

## Main features

- Inspection records with product, source reference and date.
- Inspector, criteria notes and observations.
- Pass, fail or pending result with decision notes.
- Draft, in progress, passed, failed and cancelled states.
- Corrective action and follow-up notes.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Quality Inspections** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
