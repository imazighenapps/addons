# KeyIssueLog

Key Issue and Return Register

## The problem

Informal key handovers leave key holders and returns unclear.

## The solution

Record physical key issues and returns with holder, dates, condition notes and states to keep a clear custody history.

## Main features

- Key records with identifier and holder.
- Issue, expected return and actual return dates.
- Responsible issuer and condition notes.
- Draft, issued, returned and lost states.
- Handover history and status tracking.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Key Issues** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
