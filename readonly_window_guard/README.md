# Mode Lecture Seule Planifié (readonly_window_guard)

Fenêtres de lecture seule planifiées : périmètres gérés (modèles), exceptions par groupe, message aux utilisateurs et journal de la fenêtre.

## Problème
Pour une démo, un audit ou une maintenance, geler les saisies sans couper les consultations est impossible.

## Fonctionnalités
- Fenêtres planifiées
- Périmètres de modèles
- Exceptions par groupe
- Message aux utilisateurs
- Journal de la fenêtre

## Dépendances
- `base`, `mail`
