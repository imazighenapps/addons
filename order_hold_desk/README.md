# HoldDesk

A Hold With A Reason

## The problem

A confirmed order is stopped by a chat message: nobody knows which orders are actually on hold, the release leaves no dated trace and the same customer is blocked five times for the reason nobody recorded.

## The solution

Place a confirmed order on hold for credit, stock, quality or commercial reasons, and release it with a dated trace.

## Main features

- One hold record per blocked order, with amount and customer.
- A reason per hold: credit, stock, quality, commercial or custom.
- Placing an order on hold takes one click and keeps its date.
- Release stamps the date, the user and the days on hold.
- The active-holds screen lists everything still frozen.
- A hold cannot be released twice or before being placed on hold.
- Reason counters show which rule blocks your revenue most.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Hold Desk** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
