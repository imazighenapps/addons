# Réception de Chantier avec Réserves (site_handover)

Processus de réception : liste de réserves par lot, responsable, délai de levée, levée avec photos, PV de réception et suivi des retenues.

## Problème
La réception de chantier se fait sur papier : réserves non consolidées, levées sans preuve, retenues bloquées sans suivi.

## Fonctionnalités
- Réserves par lot
- Délais de levée
- Levée avec photos
- PV de réception
- Suivi des retenues

## Dépendances
- `project`, `mail`
