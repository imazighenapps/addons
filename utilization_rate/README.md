# Taux d'Utilisation Consultants (utilization_rate)

Suivi du taux d'utilisation : cible par profil, taux réel mensuel, écarts par personne/équipe et rapport direction.

## Problème
Le taux d'utilisation (heures facturables/ disponibles) n'est ni calculé ni piloté : la rentabilité du personnel se dégrade sans alerte.

## Fonctionnalités
- Cible par profil
- Taux réel mensuel
- Écarts par équipe
- Rapport direction
- Alertes de sous-utilisation

## Dépendances
- `hr_timesheet`, `project`, `mail`
