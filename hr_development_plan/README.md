# Plan de Développement Individuel (hr_development_plan)

PDI : compétences visées, actions associées avec échéances et owners, avancement revu périodiquement, lien avec les formations et les mouvements internes.

## Problème
Les ambitions de carrière et les actions d'évolution (formations, missions, mentorat) restent dans les entretiens : rien n'est suivi d'une année sur l'autre.

## Fonctionnalités
- Compétences visées
- Actions avec échéances et owners
- Revue périodique tracée
- Lien aux formations et mobilités
- Historique par année

## Dépendances
- `hr`, `mail`
