# Références Clients sur Documents (stock_customer_item_codes)

Registre des références clients : code client par couple produit/client, affichage sur BL/facture/étiquette, contrôle à la saisie de commande et import en masse.

## Problème
Chaque enseigne référence vos produits avec son propre code : les bons de livraison ne l'affichent pas, le client bloque la réception.

## Fonctionnalités
- Code client par couple produit/client
- Affichage sur BL/facture/étiquette
- Contrôle à la saisie de commande
- Import en masse
- Journal des changements

## Dépendances
- `stock`, `sale`, `mail`
