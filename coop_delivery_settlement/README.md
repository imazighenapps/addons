# Apports Coopératifs (coop_delivery_settlement)

Apports pesés par adhérent, déductions paramétrées (capital, avance), liquidation par période avec relevés imprimés.

## Problème
Les coopératives agricoles pèsent les apports des adhérents, déduisent les prélèvements et liquident les soldes sur des bordereaux papier.

## Fonctionnalités
- Apports pesés par adhérent
- Déductions paramétrées
- Liquidation par période
- Relevés imprimés
- Historique par campagne

## Dépendances
- `stock`, `account`, `mail`
