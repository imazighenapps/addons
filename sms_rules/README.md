# SMS par Règles (sms_rules)

Moteur de SMS : règles de déclenchement par événement, gabarits, plafonds budgétaires et journal d'envoi.

## Problème
Les SMS transactionnels (relance, alerte, rappel) sont envoyés à la main depuis des téléphones.

## Fonctionnalités
- Déclencheurs par événement
- Gabarits de SMS
- Plafond budgétaire
- Journal d'envoi
- Exclusions

## Dépendances
- `base`, `mail`
