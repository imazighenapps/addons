# WasteWatch

Registers Without Drawers

## The problem

Waste collections and their receipts are tracked on paper, so the environmental register is incomplete and hard to produce when required.

## The solution

Keep the register of industrial waste collections with the receipts your environmental file requires.

## Main features

- A register of waste streams with code, hazard class and contractor.
- Collection logs with date, quantity and contractor reference.
- Receipt numbers kept on every filed collection.
- A workflow from planned to collected and filed.
- Filing refused when the receipt number is missing.
- Stored counters for collections and pending receipts.
- Areas and notes recorded for the environmental file.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Waste Watch** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
