# Cycle de Vie des Mandats (sepa_mandate_lifecycle)

Registre autonome des mandats SEPA : cycle de vie (nouveau, actif, suspendu, révoqué, expiré), versioning des RIB, alertes d'expiration/révocation, pièces signées et piste d'audit (mail.thread).

## Dépendances
- `account`, `mail`

## Internationalisation
7 langues : en_US, fr_FR, ar_001, es_ES, de_DE, pt_BR, zh_CN.
