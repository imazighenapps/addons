# Repos Compensateur (hr_compensatory_rest)

Registre du repos compensateur : crédit généré par événement, prise du repos tracée comme congé, péremption réglementaire suivie et état pour la paie.

## Problème
Les heures donnant droit à repos compensateur (astreintes, heures sup au-delà du contingent) s'accumulent sans compte : les repos finissent payés ou contestés.

## Fonctionnalités
- Crédit généré par événement
- Prise tracée comme absence
- Péremption suivie avec alerte
- État par salarié pour la paie
- Historique des générations

## Dépendances
- `hr`, `hr_holidays`, `mail`
