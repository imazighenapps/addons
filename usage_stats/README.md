# Statistiques d'Usage (usage_stats)

Statistiques d'usage : menus/fonctions consultés, utilisateurs actifs par module, fonctions mortes et rapport d'optimisation.

## Problème
Les modules et menus installés ne sont jamais audités : licences payées pour des fonctions jamais utilisées.

## Fonctionnalités
- Usage par module
- Utilisateurs actifs
- Fonctions mortes
- Rapport d'optimisation
- Historique

## Dépendances
- `base`, `mail`
