# Revues 1:1 Récurrentes (hr_one_on_one)

1:1 récurrents : cadence par duos, agenda partagé avec sujets proposés, notes de chaque session, actions assignées et suivi des sujets récurrents non traités.

## Problème
Les points réguliers manager-salarié tombent sous le coup du urgent : jamais planifiés, jamais notés, les frictions restent muettes.

## Fonctionnalités
- Cadence par duos
- Sujets proposés par les deux côtés
- Notes par session
- Actions assignées suivies
- Alerte sur les duos silencieux

## Dépendances
- `hr`, `calendar`, `mail`
