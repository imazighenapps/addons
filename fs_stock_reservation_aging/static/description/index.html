Feature 01

Every Reservation, Aged Automatically

A scheduled job scans reserved move lines and scores each one against your thresholds — Normal, Aging or Critical — with exact age in days and reservation dates.

  • ✓ Per-company aging / critical thresholds in days
  • ✓ Linked product, picking, sales order and location
  • ✓ Bounded batch cron — safe on large databases
  • ✓ One analysis row per reservation line, no duplicates
Feature 02

Release Only What's Stuck

The release wizard unreserves only the selected line quantity — never the whole move — with a mandatory reason stored in a full audit trail.

  • ✓ Targeted move-line release, unrelated reservations untouched
  • ✓ Inventory managers only, reason required
  • ✓ Release history per reservation (who, when, why)
  • ✓ Analysis rows protected from manual edits
