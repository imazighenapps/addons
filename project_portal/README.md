# Portail Client Projet (project_portal)

Portail client : avancement des tâches, jalons, documents à valider, demandes de modification et factures, en accès restreint par projet.

## Problème
Les clients B2B demandent l'avancement par emails et appels : un flux d' interruptions pour l'équipe projet.

## Fonctionnalités
- Avancement par projet
- Jalons visibles
- Validation de documents
- Demandes de modification
- Factures du projet

## Dépendances
- `project`, `portal`, `mail`
