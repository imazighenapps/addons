# Scanner de Code Personnalisé (custom_code_scanner)

Analyse statique du code installé : règles paramétrables (sudo, SQL brut, appels déconseillés), gravités, rapport par module et suivi d'éradication.

## Problème
Le code personnalisé accumule des anti-patterns (sudo injustifié, SQL brut, appels déconseillés) que seul un audit payant révèle.

## Fonctionnalités
- Règles d'analyse paramétrables
- Gravités et score par module
- Rapport exportable
- Suivi d'éradication
- Scan planifié

## Dépendances
- `base`, `mail`
