# PalletDesk

Every Pallet Counted

## The problem

Returnable pallet balances are tracked informally, so disputes with partners drag on without a clear, dated record of what was lent and returned.

## The solution

Keep the account of every returnable pallet lent and owed to each partner, so the transport dispute ends.

## Main features

- A pallet account per partner with stored lent, returned and balance.
- A movement log recording pallets lent out or returned.
- States to draft and confirm each pallet movement.
- Confirmation date stamped on validated movements.
- Search filters and group-by views for partner and direction.
- An open-balance view to focus on partners who still owe pallets.
- Notes on accounts and movements for operational context.
- Multi-company isolation with per-company records.

## Installation

1. Install the module from the Apps list.
2. Open the **Pallets** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
