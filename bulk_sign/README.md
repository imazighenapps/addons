# Signature en Masse (bulk_sign)

Demandes de signature en masse : sélection par filtre, gabarit, file de demandes, suivi consolidé et reprise des échecs.

## Problème
Faire signer 200 documents (contrats annuels, cessions) un par un est un chantier.

## Fonctionnalités
- Sélection par filtre
- File de demandes
- Suivi consolidé
- Reprise des échecs
- Journal

## Dépendances
- `base`, `mail`
