# QuoteRevise

Approved Versions Only

## The problem

A confirmed quotation keeps being edited in place: the version the customer approved is no longer the one in Odoo, and no trail says when the price changed or who approved it.

## The solution

Turn every change to a confirmed quotation into a dated revision, so the approved version is never silently edited.

## Main features

- An explicit amendment for each change to a quotation.
- A revision number per version, always above zero.
- Old value and new value side by side for each change.
- A reason archived with the amendment.
- Submit then approve, with date and approver recorded.
- One compare screen of old and new values next to each other.
- One approved-versions screen of what was agreed.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Quote Desk** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
