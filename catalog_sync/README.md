# CatalogSync

Supplier Price Updates

## The problem

A new supplier price list means retyping costs product by product and guessing the new sale price. The margin is not reproducible, half the catalogue is forgotten, and nobody can prove what was applied.

## The solution

Paste a supplier price list, match products by reference, simulate the new cost and sale price with your margin rule, then apply the update with a full history.

## Main features

- Paste a supplier price list, no file format to learn.
- Match by internal reference or supplier code.
- Simulate the new cost and the new sale price first.
- Margin rules by category with a generic fallback.
- Rounding step and read-only sale price option.
- Unmatched references kept visible.
- Apply with a dated batch and a full history.
- Graph and pivot, multi-company isolation.

## Installation

1. Install the module from the Apps list.
2. Open the **Catalog** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
