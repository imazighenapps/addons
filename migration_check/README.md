# Validateur de Migration (migration_check)

Validateur de migration : comptages par modèle (avant/après), contrôle des champs clés, échantillons de vérification et rapport d'écarts.

## Problème
Après une migration de version, personne ne sait si les données sont complètes : comptages et cohérences jamais vérifiés.

## Fonctionnalités
- Comptages avant/après
- Contrôles de champs clés
- Échantillons aléatoires
- Rapport d'écarts
- Historique

## Dépendances
- `base`, `mail`
