# MergeDocs - Customer Document Dossier

## The problem

Sending a complete customer file means opening six PDFs, merging them in a random online tool, and losing the order of the documents.

## The solution

Merge quotations, orders, delivery notes and invoices for one customer into a single PDF dossier with a cover page.

## Main features

- Load all documents of a customer for a period.
- Quotations, orders, deliveries and invoices.
- Cover page and table of contents.
- One page per document with lines and totals.
- PDF archived on the dossier.
- Multi-company and multi-currency.

## Installation

1. Install the module from the Apps list.
2. Open the **Merge Docs** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
