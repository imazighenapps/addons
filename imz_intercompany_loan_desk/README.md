# Prêts Intersociétés (intercompany_loan_desk)

Registre de prêts intersociétés : conditions, échéancier d'amortissement, calcul d'intérêts périodique, écritures symétriques et juste-valeurs de clôture.

## Problème
Les prêts entre filiales (amortissements, intérêts, conventions réglementées) sont suivis sur tableur.

## Fonctionnalités
- Échéancier d'amortissement
- Intérêts calculés périodiquement
- Écritures symétriques inter-sociétés
- Annexes de conventions réglementées
- Alertes d'échéance

## Dépendances
- `account`, `mail`
