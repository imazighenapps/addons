# FxRevalPro

Period-End Currency Revaluation

## The problem

At period end the open receivables and payables in a foreign currency are still carried at their historical rate, so the balance sheet no longer reflects reality. The revaluation is rebuilt in a spreadsheet every month, one open item is always forgotten, and the unrealized exchange difference is booked without any traceable calculation.

## The solution

Revalue open receivables and payables in a foreign currency at the closing rate, book the unrealized gain or loss in a balanced entry and keep the trail.

## Main features

- Scan of every open receivable and payable in one foreign currency.
- Closing rate entered as company-currency units per foreign unit.
- Book value, revalued balance and unrealized gain or loss per item.
- Total gain, total loss and net unrealized result per revaluation.
- Balanced journal entry with dedicated gain and loss accounts.
- Draft and posted states, reset to draft, full chatter trail.
- Journal entry and rates frozen once the revaluation is posted.
- Multi-company and multi-currency, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **FX Revaluation** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
