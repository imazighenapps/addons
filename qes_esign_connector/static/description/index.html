Feature 01

Signature Level per Participant

The client signs qualified (QES), sales signs simple (SES), legal visas advanced (AdES) — all in one envelope, with the obtained level recorded for each participant.

  • ✓ Roles: signer, visa, copy, sealer
  • ✓ Signing order + authentication means
  • ✓ Obtained level + certificate info stored
Feature 02

Hash-Chained Audit Trail

Every event is hashed and chained to the previous one. Append-only: nobody can rewrite history, not even admins.

  • ✓ SHA256 chain over all envelope events
  • ✓ Actor, IP, timestamps recorded
  • ✓ One-click JSON evidence export
Feature 03

Multi-Provider Framework

Test everything today with the local demo provider, then switch to Universign REST for real qualified signatures. Webhooks with idempotency plus hourly polling keep states in sync.

  • ✓ Demo provider works without credentials
  • ✓ Universign transactions via REST API
  • ✓ Signed PDF retrieval + archive export
