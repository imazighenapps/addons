# Décomptes d'Intérim (temp_work_decompte)

Missions avec barèmes contractuels, décomptes hebdomadaires saisis, facturation client générée et solde par mission tracé.

## Problème
Les agences d'intérim décomptent les heures de missions sur des feuilles papier et refacturent chaque semaine avec des erreurs de barème.

## Fonctionnalités
- Missions avec barèmes contractuels
- Décomptes hebdomadaires saisis
- Facturation client générée
- Solde par mission
- Taux de placement par client

## Dépendances
- `sale`, `hr`, `mail`
