# ClaimDesk

Customer and Supplier Claims

## The problem

A quality claim arrives by mail, is copied into a spreadsheet, and is chased through a mailbox: the lot number is lost, the root cause is never written down, the corrective actions are forgotten, and the cost of the claim is discovered long after the customer has been answered.

## The solution

Register every quality claim with its product, lot, quantity and root cause, run a short eight-step resolution, and keep the cost and the corrective actions on one record.

## Main features

- One register for customer, supplier and internal claims.
- Product, lot reference, quantity and defect code on every claim.
- Severity level and monetary cost of the claim.
- Guided draft, open, investigation, action, done and refused workflow.
- Root cause mandatory before corrective actions are planned.
- Dated corrective actions with a responsible user.
- Closing refused while a corrective action is still open.
- Kanban, graph and chatter, multi-company isolation.

## Installation

1. Install the module from the Apps list.
2. Open the **Quality Claims** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
