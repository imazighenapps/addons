# Centre de Tests (test_center)

Centre de tests : lancement depuis l'UI, rapports, historique par version, comparaison avant/après et statut global.

## Problème
Lancer les tests d'un module exige la ligne de commande et un environnement dédié : personne ne le fait en continu.

## Fonctionnalités
- Lancement depuis l'UI
- Rapports
- Historique par version
- Comparaison avant/après
- Statut global

## Dépendances
- `base`, `mail`
