# Japon Qualifying Invoice (jp_invoice_system_pack)

Pack JP : numéro d'enregistrement sur documents, calcul de l'ajustement de crédit (facultatif), registre des factures qualifiantes et journal de conformité.

## Problème
Le Japon impose le système de factures qualifiantes (登録番号, taux d'enregistrement des émissions).

## Fonctionnalités
- Numéro d'enregistrement JP sur documents
- Registre des factures qualifiantes
- Journal de conformité
- Contrôles de complétude

## Dépendances
- `account`, `mail`
