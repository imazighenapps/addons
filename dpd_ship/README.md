# DPD Shipping

DPD parcel shipping from Odoo

## The problem

DPD shipments, labels and tracking are handled outside Odoo, reducing visibility for warehouse and customer service.

## The solution

Create DPD shipments, labels and tracking records from deliveries and monitor parcel status in Odoo.

## Main features

- DPD connection profile with depot/customer settings.
- Shipments linked to pickings and partners.
- Label/tracking references and parcel details.
- Lifecycle actions and status tracking.
- Event log history per shipment.
- Company-aware records.
- No external Python dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **DPD Shipping** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
