# Simulateur d'Impact Prix Matière (mrp_material_price_impact)

Simulateur : choix d'un composant et d'un nouveau prix, impact calculé sur le coût de revient de toutes les nomenclatures concernées, en-cours et marges projetées.

## Problème
Une hausse du prix d'une matière clé impacte des dizaines de références ; personne ne voit l'effet global avant les factures fournisseurs.

## Fonctionnalités
- Impact par nomenclature concernée
- Effet sur le coût de revient global
- Marges projetées recalculées
- Comparaison avant/après
- Export du rapport d'impact

## Dépendances
- `mrp`, `purchase`, `mail`
