# Comparateur de Profils de Droits (rights_profile_diff)

Diff lisible entre deux utilisateurs ou groupes, explication des différences, copie assistée d'un profil vers l'autre avec récap.

## Problème
Comparer deux profils de droits à l'écran est impossible : on copie des groupes au doigt mouillé.

## Fonctionnalités
- Diff entre profils
- Explication des écarts
- Copie assistée
- Récap avant application
- Historique des copies

## Dépendances
- `base`, `mail`
