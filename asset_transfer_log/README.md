# AssetTransferLog

Equipment Transfer Register

## The problem

Equipment handovers tracked informally create custody gaps and unclear transfer history.

## The solution

Record equipment handovers with from/to holders or locations, dates, condition notes and tracked states to keep a clear custody history.

## Main features

- Transfer records linked to equipment with transfer date.
- From/to holder or location and responsible user.
- Condition and notes at handover time.
- Draft, in progress, done and cancelled states.
- Transfer history per equipment asset.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Asset Transfers** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
