# Modifications après Confirmation (post_confirmation_changes)

Contrôle des modifications post-confirmation : journal des changements, nouvelle version envoyée au client, ré-acceptation exigée sur les changements sensibles.

## Problème
Après confirmation, la commande se modifie discrètement (quantités, dates, prix) : le client ne voit pas ce qui a changé et les litiges s'installent.

## Fonctionnalités
- Journal des changements après confirmation
- Version à jour envoyée au client
- Ré-acceptation exigée si sensible
- Alerte sur changements silencieux
- Historique des versions

## Dépendances
- `sale`, `mail`
