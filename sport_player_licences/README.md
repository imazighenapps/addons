# Licences des Joueurs (sport_player_licences)

Registre des licences par joueur avec statut de validation fédérale, éligibilité par match, relances des dossiers incomplets.

## Problème
Les licences fédérales arrivent avec des retards : la participation d'un joueur non licencié à un match est un risque de forfait.

## Fonctionnalités
- Licences avec statut fédéral
- Éligibilité vérifiée par match
- Dossiers incomplets relancés
- Tarifs de licence par catégorie
- Historique par saison

## Dépendances
- `sale`, `mail`
