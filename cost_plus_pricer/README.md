# Assistant Prix Coût-Plus (cost_plus_pricer)

Assistant de tarification coût-plus : prix suggéré depuis le dernier coût connu, règles de marge par famille, application en un clic sur la ligne et trace de la suggestion.

## Problème
Chiffrer un prix de vente à partir du coût fournisseur actuel se fait de tête, avec des marges qui varient selon qui vend.

## Fonctionnalités
- Prix suggéré depuis le coût courant
- Règles de marge par famille
- Application en un clic sur la ligne
- Trace des suggestions acceptées
- Alerte si le prix tapé s'écarte de la suggestion

## Dépendances
- `sale`, `purchase`, `product`, `mail`
