# RelancePro

Dunning Ladder for Overdue Invoices

## The problem

In Community, overdue invoices are chased by hand: somebody has to remember who was called, when, and what was promised. The follow-up is inconsistent, the dunning letters of Enterprise are missing, and the receivable keeps ageing.

## The solution

Escalate overdue customer invoices through dated dunning levels, ready-to-send emails, late fees and a per-customer pause, all traced on the invoice.

## Main features

- Dunning levels with day offset, template and late fee.
- Automatic selection of the highest level reached.
- Ready-to-send emails traced in the chatter.
- Per-customer pause with an end date.
- Dry run before sending anything.
- One dunning line per invoice and per level, never twice.
- Kanban, graph and pivot on the dunning history.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Dunning** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
