Every Odoo database has duplicate contacts — and Odoo never tells you.

Data imports, portal registrations and manual entries all create duplicates over time. They inflate your customer count, corrupt your sales reports, clutter your CRM pipeline, and cause duplicate emails. Odoo stores contact data but never alerts you when two records represent the same person or company.

Everything you need

🔍

4-Layer Detection Engine

Detects duplicates via identical email, phone, VAT number, and fuzzy name similarity — scoring each group 0 to 100%.
✅

One-Click Safe Merge

Choose your master record. All related data — sales orders, invoices, messages, followers — moves automatically.
📊

Live Dashboard

See at a glance how many groups are pending review, how many partners are affected, and how many have been merged.
🔔

Smart Button on Contacts

A warning badge appears directly on any contact form that has potential duplicates. One click to see all related groups.

Weekly Auto-Scan

A scheduled cron job re-scans your entire database every week. New duplicates are flagged automatically.
🛡️

Non-Destructive

Duplicates are archived, never deleted. Every merge is logged in the chatter with the original record ID.

How it works

1

Install the module

Copy the folder to your addons path and install from the Apps menu. No configuration page, no setup wizard.
2

Run the first scan

Go to Contacts → Duplicate Detector → Run Scan Now. On large databases (10,000+ partners) this takes about 1–2 minutes.
3

Review the groups

Browse the list sorted by similarity score. Each group shows the reason it was detected: identical email, phone, VAT, or similar name.
4

Merge or ignore

Click Merge to open the wizard. Select the master record to keep — all data transfers automatically. Or click Ignore if two contacts are intentionally different.

Detection methods

Method What is compared Score Example

📞 Exact Phone Digits only, phone & mobile 95% +33 6 12 34 56 78 = 0612345678
🏢 Exact VAT VAT / Tax identification number 98% FR12345678901 matched
🔤 Name Similarity Fuzzy match (accents removed) ≥ 85% ACME Ltd ≈ Acme Limited
