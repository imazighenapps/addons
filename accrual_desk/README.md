# AccrualBook

Book It, Reverse It

## The problem

Month-end accruals for services received but not billed live in spreadsheets, are forgotten when the next month opens, and the same expense ends up booked twice when the supplier bill arrives.

## The solution

Record the month-end accruals for services received but not billed and reverse them automatically next month.

## Main features

- A dated register of month-end accruals per period.
- Partner, amount, owner and planned reversal date on every entry.
- Draft, booked and reversed states with a clear workflow.
- One-click reversal that stamps the effective reversal date.
- Open accruals queue for what still needs to be reversed.
- Validation that refuses a reversal before the accrual is booked.
- Amounts and dates guarded against impossible values.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Accrual Book** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
