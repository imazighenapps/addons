# Atelier de Traductions (translation_desk)

Atelier de traduction : recherche de termes, édition directe, export/import contrôlé et diff entre versions.

## Problème
Corriger les traductions (libellés mal tournés, manquants) exige des manipulations techniques à chaque fois.

## Fonctionnalités
- Recherche de termes
- Édition directe
- Export/import contrôlé
- Diff entre versions
- Historique

## Dépendances
- `base`, `mail`
