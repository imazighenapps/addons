# RecoverBook

Money Owed Back

## The problem

Refunds, rebates and reimbursements owed to the company are chased in inboxes and notes, so outstanding amounts are forgotten and the money never comes back.

## The solution

Log every refund, rebate or reimbursement the company is owed by customers or suppliers and chase them.

## Main features

- One claim per refund, rebate or reimbursement owed to you.
- The counterparty, origin reference, amount and due date on each claim.
- Chase actions logged with a date and a note on every claim.
- A workflow to mark a claim as recovered or written off.
- The recovered amount tracked against the expected amount.
- One chase list for every claim still outstanding.
- A chase count stored on each claim for quick follow-up.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Recover Book** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
