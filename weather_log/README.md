# Journal Météo des Chantiers (weather_log)

Journal météo : relevés du jour par chantier (source configurable), jointure au journal de chantier, preuve pour les pénalités de délai.

## Problème
Les retards dus à la météo sont contestés : aucune preuve des conditions du jour sur le chantier.

## Fonctionnalités
- Relevés par chantier
- Source configurable
- Jointure au journal
- Preuve PDF
- Statistiques d'interruptions

## Dépendances
- `project`, `mail`
