# Pennylane Bridge

Sync your accounting with Pennylane

## The problem

Invoices, bills and payments recorded in Odoo must be re-keyed or manually exported to Pennylane, creating delays, mismatches and a painful month-end close for SMEs and their accountants.

## The solution

Export invoices, bills and payments from Odoo to Pennylane, track sync status and keep your accountant aligned.

## Main features

- Connection profile per company with environment and token settings.
- Export queue for customer invoices, vendor bills and payments.
- Payload snapshot and account mapping fields per document.
- Sync states: draft, ready, sent, error, with response messages.
- Manual prepare/send/reset actions and retry tracking.
- Full sync log history with timestamps and user traceability.
- Company-aware records and secure access rules.
- No external Python dependency (network calls handled outside core logic).

## Installation

1. Install the module from the Apps list.
2. Open the **Pennylane Bridge** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
