# Archivage à Froid (cold_storage_tier)

Archivage à froid : règles d'âge, déplacement vers stockage secondaire, accès à la demande et journal des déplacements.

## Problème
Les pièces jointes anciennes (factures de 5 ans) occupent le stockage chaud inutilement.

## Fonctionnalités
- Règles d'âge
- Déplacement automatique
- Accès à la demande
- Journal
- Gains mesurés

## Dépendances
- `base`, `mail`
