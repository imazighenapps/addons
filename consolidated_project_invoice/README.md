# Facturation Projet Consolidée (consolidated_project_invoice)

Facture consolidée : sélection de projets/bons, regroupement par projet avec sous-totaux, une seule facture et rattachement analytique préservé.

## Problème
Facturer plusieurs chantiers/projets d'un même client génère N factures : coûts d'émission et confusion comptable.

## Fonctionnalités
- Sélection multi-projets
- Sous-totaux par projet
- Une facture unique
- Analytique préservée
- Modèle de facture dédié

## Dépendances
- `sale`, `account`, `project`, `mail`
