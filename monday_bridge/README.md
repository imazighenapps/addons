# Monday.com Bridge

Connect Monday.com boards

## The problem

Monday.com work tracking is disconnected from Odoo projects.

## The solution

Synchronisation tableaux/items Monday.com avec projets/tâches Odoo.

## Main features

- Connection profile for Monday.com Bridge.
- Business records with status workflow and actions.
- Synchronization/execution logs for traceability.
- Company-aware records and access control.
- No external Python dependency; operations modeled locally.
- Chatter tracking on key records.
- List/form/search views and dedicated menus.
- Seed/demo-friendly data for screenshots and testing.

## Installation

1. Install the module from the Apps list.
2. Open the **Monday.com Bridge** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
