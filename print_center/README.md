# Centre d'Impression (print_center)

Centre d'impression : files par imprimante, gabarits, règles de routage (par modèle/site), comptages et historique de rejets.

## Problème
Les impressions (étiquettes, BL, factures) partent de tous les postes vers toutes les imprimantes : files chaotiques et paperasse.

## Fonctionnalités
- Files par imprimante
- Règles de routage
- Gabarits
- Comptages et coûts
- Historique de rejets

## Dépendances
- `base`, `mail`
