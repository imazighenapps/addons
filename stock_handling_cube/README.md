# Cubage de Manutention (stock_handling_cube)

Assistant de cubage : saisie/import des dimensions, calcul du cubage caisse/carton/palette par produit, alertes sur les fiches incomplètes et export slotting.

## Problème
Les dimensions et poids d'unité de manutention manquent au catalogue : impossible de dimensionner stockage, palettes et camions.

## Fonctionnalités
- Import dimensions en masse
- Calcul cubage par unité de manutention
- Alertes fiches incomplètes
- Export pour slotting/capacité
- Historique des corrections

## Dépendances
- `stock`, `product`, `mail`
