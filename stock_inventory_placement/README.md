# Répartition du Stock entre Entrepôts (stock_inventory_placement)

Analyse de placement : croisement des ventes régionales avec les emplacements, suggestions de transferts (quantité, coût, gain), suivi des gains réalisés.

## Problème
Le stock dort dans le mauvais dépôt : livraisons lointaines, transport coûteux, sans analyse pour rééquilibrer.

## Fonctionnalités
- Croisement ventes/emplacements
- Suggestions de transferts
- Coût et gain estimés
- Suivi des gains réalisés
- Historique des rééquilibrages

## Dépendances
- `stock`, `sale`, `mail`
