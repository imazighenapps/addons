# Retenue à la Source France (fr_withholding_desk)

Registre de retenue FR : règles par type de bénéficiaire/pays, calcul automatique sur factures fournisseurs, échéancier de reversement et état annuel.

## Problème
La retenue à la source sur prestations UE (dirigeants, artistes, sous-traitants) est calculée à la main et déclarée late.

## Fonctionnalités
- Règles par type/pays
- Calcul sur factures
- Échéancier de reversement
- État annuel
- Journal d'audit

## Dépendances
- `account`, `mail`
