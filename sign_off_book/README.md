# Preuve de Fin d'Intervention (sign_off_book)

Bon de fin d'intervention : signature du client sur tablette/mobile, photos avant/après, statut du client (réalisé/partial/refusé) et PDF horodaté.

## Problème
Les interventions terminées sont contestées : pas de bon signé du client avec photos avant/après.

## Fonctionnalités
- Signature client
- Photos avant/après
- Statut du client
- PDF horodaté
- Suivi des refus

## Dépendances
- `project`, `mail`
