# Avenants de Contrat Versionnés (hr_contract_amendments)

Générateur d'avenants : gabarits par type de modification, données pré-remplies depuis le dossier salarié, versioning du contrat avec historique complet.

## Problème
Les changements de contrat (augmentation, temps partiel, mutation) donnent lieu à des avenants rédigés à la main et archivés nulle part.

## Fonctionnalités
- Gabarits par type d'avenant
- Pré-remplissage depuis le dossier
- Versioning du contrat
- Signature tracée
- Historique complet

## Dépendances
- `hr`, `mail`
