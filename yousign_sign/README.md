# Yousign e-Signature

Send and track signatures with Yousign

## The problem

Signature requests are sent outside Odoo with no centralized tracking of signer status or signed document proofs.

## The solution

Create Yousign signature requests from documents, track signer status and store signed proofs in Odoo.

## Main features

- Yousign connection profile per company.
- Signature requests linked to partners and document references.
- Signer list with email and individual status.
- Request lifecycle with timestamps and proof references.
- Send/signed/declined/expired/cancel actions.
- Event log history.
- Chatter tracking and audit trail.
- No external Python dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Yousign e-Signature** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
