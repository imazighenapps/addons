# Rangement Automatique des Documents (auto_file_rules)

Règles de rangement : par type/expéditeur/référence, tags automatiques, dossiers créés à la volée et file d'anomalies.

## Problème
Les documents téléversés restent à la racine : impossibles à retrouver, sans tags ni dossiers cohérents.

## Fonctionnalités
- Règles de rangement
- Tags automatiques
- Dossiers dynamiques
- File d'anomalies
- Journal

## Dépendances
- `base`, `mail`
