# PurchaseRequest

Internal Purchase Requests

## The problem

Without an internal requisition step, purchase needs arrive unstructured and unapproved, so buyers lack context and approvals are not traceable.

## The solution

Capture internal purchase requests with requester, needed date and lines, run a submit/approve workflow, and track requisitions through to ordered status in a company-safe register.

## Main features

- Internal requisitions with requester, department and needed date.
- Request lines with description/product, quantity and estimated price.
- Submit and approve workflow before ordering.
- States: draft, submitted, approved, ordered, done, cancelled.
- Computed estimated total per requisition.
- Search and group by requester, state and period.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Purchase Requests** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
