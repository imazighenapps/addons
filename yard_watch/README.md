# YardWatch

A Yard That Runs Itself

## The problem

Trailers park wherever there is room and the yard board is a whiteboard: nobody knows how long each trailer has been waiting, which slot is free, or when the dock must absorb the next arrival.

## The solution

Know which trailer stands where in your yard, how long it has been waiting and when the dock must absorb it.

## Main features

- A register of yard slots with dock, capacity and status.
- Trailer arrivals logged with carrier, reference and arrival time.
- Waiting, docked and departed states with dated transitions.
- Waiting duration computed and stored on every trailer.
- Departure stamped with the exact time the trailer left the yard.
- One screen to see which trailer stands where right now.
- Slot capacity and occupancy kept under control.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Yard Watch** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
