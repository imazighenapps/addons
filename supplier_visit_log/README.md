# SupplierVisit

Supplier Visit and Audit Log

## The problem

Supplier visit outcomes recorded informally lack structured findings and follow-up tracking.

## The solution

Record supplier visits with purpose, findings and follow-up actions, track reports through submission and review, and keep a company-safe visit history per supplier.

## Main features

- Visit reports linked to supplier and responsible user.
- Purpose, findings and follow-up action fields.
- Draft, submitted and reviewed states.
- Search and group by supplier, responsible and state.
- Chatter tracking on reports.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Supplier Visits** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
