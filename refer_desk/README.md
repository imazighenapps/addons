# ReferBook

Referrals That Pay

## The problem

Referral programs are tracked informally, so rewards are missed, double-credited or impossible to tie back to the advocate who brought the order.

## The solution

Give every customer a referral code, credit the reward when the referred friend orders and rank your advocates.

## Main features

- A unique referral code per advocate with active and closed states.
- Referred friends recorded with order amount and reward value.
- One-click crediting that stamps the reward date.
- Referral totals and rewards computed and stored on each code.
- A referral workflow from pending to credited or cancelled.
- Crediting a cancelled or already credited referral is refused for you.
- Closing a code without touching its history is supported.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Referrals** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
