# TrainRecord

Employee Training and Certification Tracking

## The problem

Employee trainings and certifications tracked outside Odoo lack expiry visibility, so mandatory qualifications lapse unnoticed and audits require manual evidence gathering.

## The solution

Track employee trainings and certifications with provider, completion and expiry dates, computed validity status, and company-safe reporting by employee, type and period.

## Main features

- Training record per employee with provider and completion date.
- Expiry date with computed valid, expiring soon and expired status.
- Certificate reference, duration, cost and notes.
- Configurable training types per company.
- Search and group by employee, type, status and period.
- Chatter tracking on records.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Trainings** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
