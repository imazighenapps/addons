# LateShip

Late Shipment Alert Desk

## The problem

SMBs discover late deliveries only when customers complain, because late transfers are buried in the same operational list as on-time ones.

## The solution

Detect outgoing transfers past their scheduled date, open one alert per late shipment and follow it through contact, resolution or dismissal.

## Main features

- Scan of outgoing transfers past their scheduled date.
- One alert per late transfer with delay in days.
- Customer, transfer and sales order on the alert.
- Open, contacted, resolved and dismissed states.
- Chatter trail for the customer follow-up.
- No duplicate open alert for the same transfer.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Delivery Delays** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
