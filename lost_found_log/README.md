# LostFound

Lost and Found Item Register

## The problem

Lost-and-found items tracked informally are hard to search, claim and return, leading to low recovery rates.

## The solution

Log found items with description, date and location, track claimant and return or disposal status, and keep a searchable lost-and-found register.

## Main features

- Found item records with description, date and location.
- Finder, storage and claimant information.
- Found, claimed, returned and disposed states.
- Actions to mark claimed, returned or disposed.
- Search and group by state and date.
- Chatter tracking on items.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Lost & Found** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
