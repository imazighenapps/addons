# Conformité LME Paiements Fournisseurs (lme_compliance_desk)

Contrôle LME : catégories de fournisseur (TPE, PME, grands comptes), délai applicable calculé par facture, alerte sur les dépassements, bilan annuel et preuve de vigilance.

## Problème
La loi française plafonne les délais de paiement fournisseurs (60 jours, cas particuliers) : les PME découvrent les écarts au moment de l'inspection DGCCRF.

## Fonctionnalités
- Catégorisation des fournisseurs
- Délai légal calculé par facture
- Alertes de dépassement
- Bilan annuel type médiateur
- Journal de preuve

## Dépendances
- `account`, `purchase`, `mail`
