# OrderMin

Minimums, Enforced Politely

## The problem

Minimum order thresholds are promises nobody keeps: small orders ship anyway, the extra handling and transport cost the margin, and there is no ledger of the exceptions someone silently allowed.

## The solution

Enforce minimum order value or quantity per customer with a clean exception log for the orders you allow anyway.

## Main features

- One rule per customer with amount, quantity or both.
- The shortfall computed and stored on each exception.
- An explicit decision for each order below the minimum.
- A written reason required to allow an exception.
- Decision maker and date stamped on each decision.
- One clean exception log of every small order.
- A rule without any minimum is refused for you.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Minimum Log** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
