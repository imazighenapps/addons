# Lettrage en Masse (batch_lettering_assist)

Assistant de lettrage en masse : sélection par filtres, propositions par similitude, tolérance d'écart configurable, lettrage groupé avec motif tracé.

## Problème
Lettrer des centaines d'écritures (paiements partiels, écarts de centimes) prend des journées.

## Fonctionnalités
- Sélection par filtres
- Propositions par similitude
- Tolérance configurable
- Lettrage groupé tracé
- Statistiques de lettrage

## Dépendances
- `account`, `mail`
