# Portefeuille de Projets (portfolio_board)

Tableau portefeuille : phases, jalons consolidés, santé (vert/orange/rouge) par règles, alertes de chevauchement de jalons et charge.

## Problème
La direction voit les projets un par un sans vue d'ensemble : tensions de ressources et arbitrages à l'aveugle.

## Fonctionnalités
- Vue portefeuille par phase
- Jalons consolidés
- Règles de santé
- Alertes de chevauchement
- Charge agrégée

## Dépendances
- `project`, `mail`
