# Import de Balances d'Ouverture (open_balance_import)

Importeur de balances d'ouverture : CSV/Excel par compte+analytique, tiers avec lettrage initial, contrôle d'équilibre, écriture d'ouverture générée.

## Problème
Démarrer Odoo avec les balances de l'ancien logiciel exige des manipulations fragiles (écritures d'ouverture, tiers, stocks).

## Fonctionnalités
- Import CSV/Excel structuré
- Balances par tiers avec lettrage initial
- Contrôle d'équilibre
- Écriture d'ouverture générée
- Rapport de migration

## Dépendances
- `account`, `mail`
