Sales Margin Block LITE

Simple margin protection for your sales

Sales Margin Block LITE helps companies prevent unprofitable sales by blocking the confirmation of sale orders below a global minimum margin.

Designed for small teams or companies who want a simple way to protect their sales margin without advanced configuration.

Key Features

  • ✔ Automatic margin calculation on quotations
  • ✔ Block sale order confirmation if margin is too low
  • ✔ Global minimum margin only (no per product or customer)
  • ✔ Manager override via security group
  • ✔ Clean and native Odoo interface
  • ✔ No performance impact

How It Works

  1. Define a global minimum margin in Settings
  2. Create or edit a quotation
  3. Odoo calculates the margin automatically
  4. If the margin is below the threshold, confirmation is blocked
  5. Managers can override the restriction if required

Business Use Cases

  • Prevent sales at a loss
  • Control excessive discounts
  • Enforce a simple pricing policy
  • Protect company margins effortlessly

Configuration

  • Go to Settings → Sales Margin Block LITE
  • Set a global minimum margin percentage
  • Assign the “Allow Low Margin Sales” permission to managers

Security

Only users belonging to the Allow Low Margin Sales group can confirm sales orders below the global margin threshold.
