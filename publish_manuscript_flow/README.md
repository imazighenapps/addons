# Manuscrits & Avances (publish_manuscript_flow)

Pipeline de manuscrits avec décisions de comité tracées, contrats avec jalons de production, avances suivies et échéances de livraison.

## Problème
Les maisons d'édition reçoivent des centaines de manuscrits : décisions de comité, contrats et jalons de production s'éparpillent dans les mails.

## Fonctionnalités
- Pipeline de soumission
- Décisions de comité tracées
- Contrats avec jalons
- Avances suivies
- Échéances de livraison

## Dépendances
- `sale`, `project`, `mail`
