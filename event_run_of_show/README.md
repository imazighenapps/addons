# Run of Show (event_run_of_show)

Planning minute par minute de l'événement : interventions des prestataires avec horaires, responsables et checklists de déroulé, point d'avancement pendant l'événement.

## Problème
Le jour J, l'ordre exact des interventions (prestataires, sonorisation, entrées) vit dans une feuille que personne n'a synchronisée.

## Fonctionnalités
- Déroulé minute par minute
- Interventions prestataires horodatées
- Responsable par séquence
- Checklist du jour J
- Retour d'expérience tracé

## Dépendances
- `event`, `project`, `mail`
