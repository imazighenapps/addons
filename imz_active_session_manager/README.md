# Gestion des Sessions Actives (active_session_manager)

Gestionnaire de sessions actives : liste par utilisateur avec device, fermeture forcée, alerte de sessions multiples et journal.

## Problème
Sessions ouvertes partout (postes partagés, terminaux quittés) sans vue ni fermeture à distance.

## Fonctionnalités
- Liste des sessions actives
- Fermeture forcée
- Alerte de sessions multiples
- Journal des fermetures
- Vue par utilisateur

## Dépendances
- `base`, `mail`
