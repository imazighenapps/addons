# Clearance

Lines Start Clean

## The problem

Line changeovers are restarted without documented clearance, so residues from the previous run can contaminate the next batch and no proof exists.

## The solution

Force a documented line clearance between two runs: nothing restarted while the previous product lingers.

## Main features

- A register of line clearances for every changeover.
- Outgoing and incoming products recorded on each clearance.
- Checklist items for removal, cleaning and verification.
- Sign-off per item with user and completion state.
- Release blocked until every required item is done.
- Stored counters for total and completed items.
- Areas and planned restart times tracked on the record.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Clearance** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
