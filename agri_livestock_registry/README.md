# Identification du Cheptel (agri_livestock_registry)

Registre du cheptel : animaux identifiés par boucle, mouvements entre parcelles ou exploitations, naissances, mortalités, documents exigibles.

## Problème
Le registre d'élevage (boucles, naissances, morts, mouvements) tenu papier est pénible et passé sous silence lors des contrôles.

## Fonctionnalités
- Animaux identifiés par boucle
- Mouvements datés
- Naissances et mortalités
- Documents de contrôle générés
- Inventaire par site

## Dépendances
- `stock`, `mail`
