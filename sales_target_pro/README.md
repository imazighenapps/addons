# TargetPilot

Sales Targets and Achievement

## The problem

The quarterly target is announced once and then disappears: pipelines carry opportunities, reports carry history, and nobody compares the two numbers today instead of three weeks after the period closes.

## The solution

Set monthly or quarterly targets per salesperson and team, compute the confirmed revenue achieved, and show the gap, the pace and the projected end of period.

## Main features

- Dated target per salesperson and team.
- Achievement is the confirmed revenue of the window.
- Gap and percentage, both stored.
- Pace and end of period projection.
- Draft, running and done states.
- One target per owner and window.
- Graph per owner, pivot by state.
- Company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Sales Targets** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
