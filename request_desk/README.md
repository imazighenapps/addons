# PRDesk

Requests Beat Emails

## The problem

Purchase needs are sent by email and chat, so buyers lose track of who requested what, approvals are informal and urgent needs compete with forgotten ones.

## The solution

Give every department a proper purchase request desk instead of emails to the buyer, from need to order.

## Main features

- A purchase request register with requester and needed date.
- Request lines for the product, description and quantity needed.
- A clear workflow from draft to submitted, approved, ordered and done.
- Totals stored on the request for quick filtering and reporting.
- Buyer and department notes kept on the same request.
- One queue to see every request and its current state.
- Actions refuse edits after ordering and keep decisions traceable.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Purchase Requests** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
