# ReorderPlan

Days Of Stock, Planned

## The problem

Buyers see quantities but not days of cover, so fast movers run out while reorder decisions are made too late in spreadsheets.

## The solution

See how many days of demand your stock covers per product and turn every skimpy line into a planned purchase.

## Main features

- A coverage line per product with on-hand quantity and company.
- Daily demand and minimum days defined on every line.
- Covered days computed and stored for reliable filtering.
- Skimpy lines flagged automatically below the minimum.
- A planned purchase quantity recorded per exposed product.
- Decision states from draft to planned and ordered.
- Daily demand and minimum days must stay positive.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Reorder Plan** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
