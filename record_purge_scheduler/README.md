# Purge & Anonymisation Planifiée (record_purge_scheduler)

Règles de purge par modèle avec délai de rétention, vérification des dépendances, anonymisation ou suppression, journal d'exécution.

## Problème
Les données obsolètes (carts abandonnés, brouillons, logs d'activité) s'accumulent et ralentissent l'instance.

## Fonctionnalités
- Règles par modèle avec délai
- Vérification des dépendances
- Anonymisation ou suppression
- Fenêtres d'exécution
- Journal d'exécution

## Dépendances
- `base`, `mail`
