# SupplierCert

Certificates Alive Or Blocked

## The problem

Supplier certificates are stored in emails and folders, so expiries are missed and buyers cannot quickly prove which suppliers are currently certified.

## The solution

Keep the ISO, organic, halal or kosher certificates of each supplier alive and block orders when one lapses.

## Main features

- A certificate register per supplier with type and reference.
- Issue, expiry and reminder dates stored on every certificate.
- Status tracking from draft to valid, expiring, expired and renewed.
- Renewal actions that record a new validity period with history.
- A dedicated view for expiring and expired certificates.
- Responsible ownership and notes kept on the certificate.
- Expiry dates before issue dates are refused for you.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Supplier Certificates** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
