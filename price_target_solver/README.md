# Solveur de Prix Cible (price_target_solver)

Solveur de remise : donner le montant cible, répartition pondérée de la remise sur les lignes selon règles (marge protégée, priorités), aperçu avant application.

## Problème
Quand le client négocie un prix global cible, la répartition de la remise sur les lignes se fait au doigt mouillé et détruit les marges des bonnes lignes.

## Fonctionnalités
- Saisie du prix cible global
- Répartition pondérée par règles
- Protection des marges des lignes
- Aperçu avant application
- Historique des cibles négociées

## Dépendances
- `sale`, `mail`
