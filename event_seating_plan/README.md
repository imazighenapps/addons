# Plan de Table d'Événement (event_seating_plan)

Plan de table visuel par tables, placement par invité avec régimes et contraintes, permutations contrôlées et fichier du placement imprimé.

## Problème
Le placement des invités (tables, tabous, régimes alimentaires) vit sur des post-its réécrits dix fois.

## Fonctionnalités
- Tables et capacités
- Placement par invité avec contraintes
- Régimes alimentaires consignés
- Permutations contrôlées
- Fichier de placement imprimé

## Dépendances
- `event`, `sale`, `mail`
