# TaxCalendar

Tax Deadlines Under Control

## The problem

Tax deadlines live in a spreadsheet that is rebuilt every year: the recurrence is retyped by hand, one period is always forgotten, and nobody sees a late filing before the penalty. A single rule per tax type should produce the whole calendar and flag what is overdue.

## The solution

Generate every VAT, corporate tax and payroll deadline from simple recurrence rules, then track what is filed, paid or late in one dated calendar.

## Main features

- Recurrence rules per tax type and frequency.
- Monthly, quarterly and yearly generation in one click.
- Deterministic due dates from the period end and a day offset.
- Upcoming, done and late states with the completion date.
- Late flag and days left on every deadline.
- Amount per deadline, totals in the list and the graph.
- Search filters and grouping per tax type and status.
- Multi-company calendar, unique rule per company.
- No Enterprise dependency, no external library.

## Installation

1. Install the module from the Apps list.
2. Open the **Tax Calendar** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
