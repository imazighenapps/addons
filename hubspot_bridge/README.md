# HubSpot Bridge

Sync CRM data with HubSpot

## The problem

Contacts and deals in HubSpot and Odoo drift apart, creating duplicate records and lost sales context.

## The solution

Synchronize contacts and deals between Odoo CRM and HubSpot with mapping, sync logs and status tracking.

## Main features

- HubSpot connection profile with API token reference.
- Contact sync linked to partners with external IDs.
- Deal sync linked to leads/opportunities.
- Direction (push/pull) and status tracking.
- Prepare/sync/reset actions with error logging.
- Sync history and payload snapshots.
- No external Python dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **HubSpot Bridge** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
