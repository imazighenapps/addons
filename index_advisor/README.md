# Conseiller d'Indexation (index_advisor)

Conseiller d'indexation : analyse des requêtes lentes, propositions d'index, application contrôlée et mesure avant/après.

## Problème
Les requêtes lentes manquent d'index : le diagnostic exige un DBA et des essais risqués.

## Fonctionnalités
- Analyse des requêtes lentes
- Propositions d'index
- Application contrôlée
- Mesure avant/après
- Journal des index créés

## Dépendances
- `base`, `mail`
