# Liaison Automatique des Pièces (attachment_linker)

Liaison automatique : détection de la référence dans le nom/contenu du fichier, rattachement à l'enregistrement et file d'ambiguïtés.

## Problème
Les pièces jointes des emails (factures, bons) restent dans le thread : jamais rattachées au bon dossier.

## Fonctionnalités
- Détection de référence
- Rattachement automatique
- File d'ambiguïtés
- Journal
- Statistiques de couverture

## Dépendances
- `mail`
