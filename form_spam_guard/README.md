# Garde Anti-Spam des Formulaires (form_spam_guard)

Garde anti-spam : honeypot, détection de soumissions suspectes, quarantaine et statistiques par source.

## Problème
Les formulaires publics reçoivent des soumissions de bots : leads pollués, spam dans la CRM.

## Fonctionnalités
- Honeypot
- Détection suspecte
- Quarantaine
- Statistiques par source
- Journal

## Dépendances
- `website`, `mail`
