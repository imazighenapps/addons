# DualSupply

Never One Source Away

## The problem

Critical products rely on single suppliers without a visible qualified backup, so one failure can stop the plant before anyone sees the risk.

## The solution

Map a second source to every critical product and expose the single-supplier items that can stop your plant.

## Main features

- A sourcing record per critical product with company ownership.
- Supplier entries marked as primary or alternate sources.
- Qualification status tracked on every supplier entry.
- Qualified source count computed and stored per product.
- Single-source products flagged automatically for review.
- A screen focused on products with only one qualified source.
- Each product must keep exactly one primary supplier.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Dual Supply** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
