# Exécution de Scripts Encadrée (script_runner_console)

Console d'exécution de scripts : approbation préalable, timeout, journal complet, périmètres de modèles autorisés.

## Problème
Les interventions techniques (script ponctuel, job de correction) passent par du shell direct sans trace ni contrôle.

## Fonctionnalités
- Approbation préalable
- Timeout et interruption
- Journal complet
- Périmètres autorisés
- Historique des exécutions

## Dépendances
- `base`, `mail`
