# Mondial Relay Shipping

Relay point shipping made simple

## The problem

Mondial Relay shipments are prepared outside Odoo, making relay selection, label tracking and delivery status invisible to warehouse and support teams.

## The solution

Prepare Mondial Relay shipments, select relay points, generate label records and track parcel status from deliveries.

## Main features

- Merchant connection profile with credentials reference.
- Relay point directory (ID, address, opening info).
- Shipment records linked to pickings and partners.
- Weight, parcel count, label and tracking fields.
- Statuses: draft, ready, label, in_transit, delivered, exception.
- Prepare/label/ship/deliver/reset actions.
- Tracking event log per shipment.
- No external Python dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Mondial Relay** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
