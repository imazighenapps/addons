# Délais de Transit par Corridor (lane_benchmark_desk)

Benchmark de corridors : délais réels mesurés par origine-destination, distribution et dérive, délai de référence par corridor alimentant promesses et arbitrages.

## Problème
Les promesses de délai se fixent sans base : chaque corridor a ses réalités (ferries, douane, trafic) jamais consolidées.

## Fonctionnalités
- Délais réels par corridor
- Distribution et dérive
- Délai de référence proposé
- Comparaison transporteurs
- Évolution mensuelle

## Dépendances
- `stock`, `sale`, `mail`
