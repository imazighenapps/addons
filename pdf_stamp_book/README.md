# Tampon Numérique des Documents (pdf_stamp_book)

Tampon automatique : bandeau de validation (statut, date, émetteur) et QR de vérification pointant vers une page publique de contrôle.

## Problème
Les PDFs émis (devis, attestations) ne portent aucune preuve d'authenticité : les clients doutent des copies reçues.

## Fonctionnalités
- Bandeau de validation
- QR de vérification
- Page publique de contrôle
- Règles par type de document
- Journal des émissions

## Dépendances
- `base`, `mail`
