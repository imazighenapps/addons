# Plan de Prélèvements Microbiologiques (quality_micro_sampling_plan)

Plan de prélèvements : fréquences par type (surface, produit, eau, air), alertes aux échéances, résultats consignés, alertes sur les dépassements et tendances par zone.

## Problème
Les prélèvements microbiologiques (surfaces, produits, eau) sont planifiés dans Excel : fréquences oubliées et résultats éparpillés.

## Fonctionnalités
- Fréquences par type de prélèvement
- Alerte aux échéances
- Résultats consignés avec limites
- Alertes de dépassement
- Tendance par zone et période

## Dépendances
- `quality`, `mail`
