# Enquête d'Intégration (hr_onboarding_survey)

Enquêtes d'intégration à 30/60/90 jours : questionnaires automatiques, signalement des points durs (matériel, formation, accueil), alerte au manager et à RH.

## Problème
Les nouveaux embauchés se tusent sur leurs difficultés d'intégration : on ne découvre les problèmes qu'à la démission.

## Fonctionnalités
- Questionnaires 30/60/90 jours
- Alerte sur les points durs
- Suivi du manager
- Comparaison par service
- Historique par embauche

## Dépendances
- `hr`, `mail`
