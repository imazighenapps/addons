# Contamination Croisée par Emplacement (stock_cross_contamination_locations)

Règles de co-stockage : classification allergène/fragile par produit, blocage ou alerte si un emplacement récent héberge un produit incompatibles, historique de nettoyage requis.

## Problème
Un allergène stocké dans un emplacement puis remplacé par un produit incompatible crée un risque invisible pour l'auditeur.

## Fonctionnalités
- Classification par risque produit
- Règles d'incompatibilité par emplacement
- Blocage ou alerte au rangement
- Historique de nettoyage requis
- Dossier d'audit

## Dépendances
- `stock`, `mail`
