# Tests de Dépréciation (asset_impairment_test)

Registre de tests de dépréciation : CGU, hypothèses, valeur recouvrable calculée, dépréciation reprise/reconstituée et écritures datées.

## Problème
Les tests de dépréciation d'actifs (CGU, valeur recouvrable) sont faits dans Excel avec peu de traçabilité.

## Fonctionnalités
- Registre par CGU
- Hypothèses documentées
- Calcul valeur recouvrable
- Écritures de dépréciation
- Historique par exercice

## Dépendances
- `account`, `mail`
