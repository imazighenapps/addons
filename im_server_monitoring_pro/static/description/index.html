Visual & Interactive Dashboard

Get a full overview of your server metrics at a glance. Interactive charts and colored indicators (green/orange/red) make it easy to monitor CPU, RAM, Disk, Network traffic, and active processes. Configure alerts by thresholds and receive notifications in Odoo or by email.

Key Features

📊 Real-time Monitoring

Monitor CPU, RAM, Disk, and Network traffic live. Historical charts for 24h, 7d, 30d periods. Per-core CPU usage and partition-level disk statistics.

⚙️ Process Management

List all server processes, inspect memory & CPU usage, and securely terminate processes with confirmation. Audit logs included.

🔔 Configurable Alerts

Set threshold-based alerts and receive notifications by email or directly in Odoo. Severity levels (Low/Medium/High/Critical) are color-coded.

🌐 Network Monitoring

Real-time upload/download speed per network interface. Track total bytes sent/received and identify potential network bottlenecks.

💾 Disk Monitoring

Monitor partitions, used/free space, and disk percentage usage with color-coded visual indicators.

📈 Dashboard Analytics

Interactive graphs for real-time and historical trends. Quickly analyze server performance, uptime, and resource utilization.
