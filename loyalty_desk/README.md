# PointsBank

Points Your Customers Bank

## The problem

Loyalty points are tracked in spreadsheets, so balances are disputed, movements are hard to prove and redemptions can silently exceed what customers earned.

## The solution

Reward every paid invoice with points your customers can redeem on the next order, with a clean point ledger.

## Main features

- A point account per customer with a live stored balance.
- Earn and redeem movements recorded in a dated ledger.
- A running balance computed from every ledger entry.
- References kept on each movement for traceability.
- Accounts that can be suspended when needed.
- Redemptions that would overdraw the balance are refused for you.
- Negative earn amounts are refused for you.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Loyalty** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
