# VendorScore - Objective Supplier Rating

## The problem

Buyers negotiate with suppliers without any objective data. Nobody knows which supplier delivers late, ships short or slowly increases prices.

## The solution

Score every supplier automatically on on-time delivery, fill rate, price variance and quality, then drive a documented improvement plan.

## Main features

- Automatic OTIF from purchase data.
- Fill rate from received quantities.
- Price variance against standard cost.
- Quality rate and weighted score.
- A/B/C/D rating.
- Improvement plan with owner and deadline.
- Review history.

## Installation

1. Install the module from the Apps list.
2. Open the **Vendor Score** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
