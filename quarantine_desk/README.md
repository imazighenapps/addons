# QuarantineDesk

Doubt Never Ships

## The problem

Doubtful stock is parked with a note instead of a workflow, so nobody knows what is held, who owns the decision, or whether it was released, returned or scrapped.

## The solution

Move doubtful stock into a visible quarantine workflow instead of a note, and decide keep, return or scrap.

## Main features

- A quarantine register with product, lot, quantity and hold reason.
- A clear workflow to quarantine, release, return or scrap each case.
- Decision date and note captured on every resolved case.
- Stored counters and status ready for filters and reviews.
- One screen focused on stock still held in quarantine.
- Search filters and group-by views for reason and status.
- Reopen action to move a resolved case back under review.
- Multi-company isolation with per-company records.

## Installation

1. Install the module from the Apps list.
2. Open the **Quarantine** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
