# Tirage d'Échantillons d'Audit (audit_sample_generator)

Générateur d'échantillons : tirage aléatoire/stratifié documenté, feuilles de test, résultats consignés et conclusion par population.

## Problème
L'audit interne tire ses échantillons de tests à la main (risque de biais) sans trace documentée.

## Fonctionnalités
- Tirage aléatoire/stratifié
- Feuilles de test
- Résultats consignés
- Conclusion par population
- Journal d'audit

## Dépendances
- `account`, `mail`
