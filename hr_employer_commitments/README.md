# Engagements Employeur Tracés (hr_employer_commitments)

Registre d'engagements : promesse tracée (type, montant, échéance, owner), suivi jusqu'à l'exécution, alertes d'impayés d'engagement et statistique de tenue par manager.

## Problème
Les promesses faites aux salariés (formation, augmentation, équipement) se perdent : déceptions et démissions évitables.

## Fonctionnalités
- Engagement tracé avec échéance
- Suivi jusqu'à l'exécution
- Alertes d'engagements en retard
- Tenue par manager mesurée
- Historique par salarié

## Dépendances
- `hr`, `mail`
