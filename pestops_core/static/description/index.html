Feature 01 — Sites, Zones & QR Control Points

Model every customer location exactly like your technicians see it: sites divided into zones, each equipped with control points (rodent stations, cockroach traps, insect light traps, inspection points). Every point gets a unique QR token with a printable label — scan it on site to jump straight to its history.

  • ✓ Site address, GPS coordinates, site type and risk level
  • ✓ Last inspection date and activity level per control point
  • ✓ QR code image auto-generated + printable QR label report
  • ✓ Quick-inspection action from any control point

Site form with zones, control points, visits and QR tracking.

Feature 02 — Contracts That Generate Their Own Visits

Create the contract, attach sites with their own frequency, technician and horizon — confirming it builds the treatment plans automatically. A daily cron then generates the recurring visits idempotently (no duplicates, ever), sends reminders, and tracks renewals and expiries.

  • ✓ Contract states: draft → confirmed → suspended → to renew → expired
  • ✓ Per-site frequency (days / weeks / months), duration and technician
  • ✓ Visit reminders as activities + renewal and expiry maintenance
  • ✓ Service types: preventive, curative, IPM, disinfection, fumigation

Feature 03 — Technician Workspace App

A touch-friendly Owl app for the field: the technician sees today's visits, starts them, records inspections with photos, logs treatments with products and lots, captures the customer signature, checks in/out with GPS (geofence validated) and keeps working offline with local drafts.

  • ✓ Daily visit list with live status badges
  • ✓ Inspection lines per control point + photo evidence
  • ✓ Treatment products, lots, locations + stock consumption
  • ✓ GPS check-in/out, signature pad, offline drafts, completion rules enforced

Technician workspace — today's visits with live status badges.

Feature 04 — Inspections, Treatments & Anomalies

Every visit produces structured field data: inspections with activity levels and evidence (live pest, droppings, damage, nest…), treatments consuming real stock through validated moves, re-services for callbacks and anomalies with severity workflow that can spawn corrective re-services.

  • ✓ Visit lifecycle with inspection-required completion rules
  • ✓ Automatic project-task sync per visit
  • ✓ Customer feedback, chatter and full audit trail on every record
  • ✓ Service report PDF + treatment certificate PDF with signature blocks

Completed visit: action buttons, inspection lines and tabs for treatments, anomalies, quality, signature and proof.

Up and Running in 5 Steps

  1. Install the module — copy to addons and install from Apps.
  2. Create a site — customer, zones, control points, print QR labels.
  3. Create a contract — add sites with frequencies, then confirm.
  4. Generate visits — or let the daily cron do it, then dispatch technicians.
  5. Work the visits — inspect, treat, close, print the service report.
