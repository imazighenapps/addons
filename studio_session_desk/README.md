# Sessions de Studio (studio_session_desk)

Réservations de sessions avec ingénieur assigné, heures consommées (enregistrement, mixage), crédit d'heures et facturation à la session.

## Problème
Les studios d'enregistrement gèrent créneaux, ingénieurs et heures de mixage dans un agenda papier avec facturations approximatives.

## Fonctionnalités
- Sessions avec ingénieur assigné
- Heures consommées par activité
- Crédit d'heures prépayés
- Facturation à la session
- Historique par artiste

## Dépendances
- `sale`, `account`, `mail`
