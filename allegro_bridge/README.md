# Allegro Bridge

Sell and fulfill on Allegro from Odoo

## The problem

Allegro marketplace orders and offers are managed outside Odoo, creating manual work and stock inconsistencies.

## The solution

Connect Allegro marketplace to import orders, manage offers and track fulfillment status in Odoo.

## Main features

- Allegro connection profile per company.
- Offer records with price/stock/status.
- Imported orders with fulfillment states.
- Accept/ship/cancel/reset actions.
- Tracking and notes.
- No external Python dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Allegro Bridge** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
