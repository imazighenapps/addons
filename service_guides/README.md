# Base de Connaissances Techniques (service_guides)

Base de connaissances technique : fiches par équipement/typologie, procédures illustrées, recherche par panne et lien aux interventions.

## Problème
Le savoir-faire des anciens part avec eux : les procédures d'intervention vivent dans des PDF éparpillés.

## Fonctionnalités
- Fiches par équipement
- Procédures illustrées
- Recherche par symptôme
- Lien aux interventions
- Gestion des versions

## Dépendances
- `project`, `mail`
