# ForkCheck

Grounded Until Fixed

## The problem

Forklift daily checks live on paper, so defects have no owner or sign-off and unsafe trucks keep working until something breaks.

## The solution

Run the daily safety checklist of every forklift and ground the truck until the defect is signed off.

## Main features

- A daily safety check per forklift with operator and date.
- Checklist points recorded on each inspection.
- Defects created with description and repair sign-off.
- Grounded status when a defect remains open.
- Open defects counted and stored on the check.
- One screen to review checks and their defects.
- A repair sign-off without a date is refused for you.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Forklift Checks** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
