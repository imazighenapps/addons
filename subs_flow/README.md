# SubsFlow - Subscriptions and Recurring Invoicing

## The problem

Odoo Community has no native subscription engine, so recurring invoicing is done by hand every month, with forgotten customers and wrong periods.

## The solution

Recurring subscriptions for Odoo Community: plans, periods, prorata, automatic invoices, pause, MRR and churn.

## Main features

- Subscription plans: monthly, quarterly, yearly.
- Automatic invoice generation with a daily scheduler.
- Prorata on the first period.
- Pause, resume and close.
- MRR, ARR and churn.
- Invoice now button.
- Multi-company and multi-currency.

## Installation

1. Install the module from the Apps list.
2. Open the **Subscriptions** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
