# Générateur de Courriers RH (hr_letter_templates)

Générateur de courriers : modèles par type, données du salarié insérées automatiquement, revue obligatoire, envoi traçé et archivage au dossier.

## Problème
Chaque courrier RH (embauche, mutation, sanction, fin de contrat) est retapé : formulations à risque juridique et historique perdu.

## Fonctionnalités
- Modèles par type de courrier
- Données insérées automatiquement
- Revue obligatoire
- Envoi traçé
- Archivage au dossier salarié

## Dépendances
- `hr`, `mail`
