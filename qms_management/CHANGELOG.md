# Changelog

## 20.0.1.1.0 — Release Candidate 3

- Added standard-edition lifecycle and transition plans.
- Added requirement mappings for standard revisions.
- Added risk-based audit planning and auditor competency checks.
- Added customer complaint SLA escalation and hardened portal reads.
- Added measurement-management fields for traceability, uncertainty and impact review.
- Updated management review inputs with complaints, calibration, opportunities and compliance gaps.
- Optimized executive dashboard aggregation to reduce large-recordset processing.
- Added commercial documentation and translation-pack infrastructure.

- Benchmarked against the current indexed ISO Compliance feature set and closed integration gaps with optional Sales/Purchase, Stock/MRP and Quality bridges.
- Added current standard metadata for ISO 9001:2026, ISO 14001:2026, ISO 19011:2026, ISO 10012:2026, ISO 10002:2018, ISO 45001:2018 and ISO 22000:2018 without reproducing standard text.
- Added requirement implementation assessment, standard transition lifecycle and richer audit analytics.
- Added supplier smart button integration and weekly QMS management digest.
- Expanded automated test suite to 56 test methods.
- Added Portuguese (Portugal) alongside Brazilian Portuguese in the translation package.
