# Politique de Session (session_policy)

Politique de session : timeout par groupe, déconnexion des inactifs, restriction des postes simultanés et journal.

## Problème
Les sessions restent ouvertes des jours sur des postes partagés : accès non maîtrisés.

## Fonctionnalités
- Timeout par groupe
- Déconnexion des inactifs
- Postes simultanés
- Journal
- Exceptions

## Dépendances
- `base`, `mail`
