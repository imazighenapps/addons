# Extraction de Tableaux (table_extract)

Extracteur de tableaux : détection des tableaux dans les PDFs, export structuré, mapping vers enregistrements et contrôle de totaux.

## Problème
Les relevés et listings en PDF (relevés bancaires, états fournisseurs) doivent être ressaisis en Excel.

## Fonctionnalités
- Détection de tableaux
- Export structuré
- Mapping vers modèles
- Contrôle de totaux
- Historique

## Dépendances
- `base`, `mail`
