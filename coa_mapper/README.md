# Mapper de Plan Comptable (coa_mapper)

Mapper de plans comptables : import des deux plans, correspondances manuelles assistées par similarité, validation des comptes non mappés et export de la table de mappage réutilisable.

## Problème
Chaque migration exige un mappage de plan comptable ancien→nouveau refait à la main dans Excel.

## Fonctionnalités
- Import de deux plans
- Suggestions par similarité
- Validation des non-mappés
- Export réutilisable
- Historique par projet de migration

## Dépendances
- `account`, `mail`
