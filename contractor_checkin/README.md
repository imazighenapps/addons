# ContractorCheckin

Contractor and External Worker Check-in Log

## The problem

Contractor arrivals recorded on paper provide poor on-site visibility and weak audit trails.

## The solution

Log contractor and external worker check-ins with company, host, purpose and timestamps, track on-site and checked-out status, and keep a company-safe presence register.

## Main features

- Check-in records with contractor, company, host and purpose.
- Check-in and check-out timestamp tracking.
- On-site, checked-out and cancelled states.
- Check-out action setting departure time.
- Search and group by company, host, state and period.
- Chatter tracking on records.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Contractor Check-in** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
