# Plan de Distribution Hebdomadaire (delivery_frequency_plan)

Plan hebdomadaire par zone : clients affectés à une journée et une tournée type avec fréquence contractuelle, contrôle de charge par tournée et ajustement tracé.

## Problème
La distribution aux boutiques est improvisée semaine après semaine : fréquences incohérentes, tournées surchargées un jour et vides le lendemain.

## Fonctionnalités
- Affectation jour/tournée type
- Fréquences contractuelles suivies
- Contrôle de charge par tournée
- Ajustements tracés
- Dérives du plan mesurées

## Dépendances
- `sale`, `stock`, `mail`
