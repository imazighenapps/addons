# SkillMap

Skills Gap, Named

## The problem

Certified skills are tracked informally, so managers cannot see who is qualified, which certifications expired, and where the production plan is exposed to gaps.

## The solution

Map who in the team holds which certified skill and expose the gaps the production plan depends on.

## Main features

- A catalog of skills with required coverage targets.
- Assignments per employee with level and certification dates.
- Stored counters for holders and valid certifications.
- A workflow to certify, expire or revoke assignments.
- Search filters for certified and expired assignments.
- Grouping by skill and employee for coverage reviews.
- Validation of levels, dates and duplicate assignments.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Skill Map** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
