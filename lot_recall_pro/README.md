# RecallDesk

One Recall, One Click

## The problem

When a lot must be recalled, teams cannot quickly assemble who received it and which customers have been notified, turning recalls into slow manual investigations.

## The solution

When a lot must be recalled, list in one click every customer who received it and produce the recall letters.

## Main features

- A recall case per incident with product, reason and start date.
- Impact lines for affected lot, customer, quantity and reference.
- Stored totals for impacted lines and notified customers.
- A workflow from draft to active, notifying, closed and cancelled.
- One-click actions to mark all impacted customers as notified.
- A dedicated screen for open recalls and pending notifications.
- Closing is refused while impacted customers remain unnotified.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Recall Desk** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
