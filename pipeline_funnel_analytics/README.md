# Analyse de Conversion du Pipeline (pipeline_funnel_analytics)

Analyse d'entonnoir : taux de passage entre étapes, temps moyen par étape, points de fuite identifiés et comparaison entre vendeurs et sources.

## Problème
On ignore où le pipeline fuite : les taux de conversion par étape et les temps d'attente ne sont jamais calculés, si bien que les efforts de formation restent des paris.

## Fonctionnalités
- Taux de passage par étape
- Temps moyen par étape
- Points de fuite identifiés
- Comparaison entre vendeurs et sources
- Historique des tendances

## Dépendances
- `crm`, `mail`
