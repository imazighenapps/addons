# GuaranteeBook

Guarantees Released On Time

## The problem

Bank guarantees are tracked in emails and spreadsheets, so renewals are missed, fees are paid for nothing and released instruments keep consuming credit with no trace.

## The solution

Track every bank guarantee or standby letter from issue to release and never pay avoidable renewal fees.

## Main features

- A register of bank guarantees and standby letters of credit.
- Beneficiary, issuing bank, amount and currency per instrument.
- Issue and expiry dates with a stored active-guarantee flag.
- Release recorded with the exact date and a closing note.
- A renewal history with the previous and new expiry dates.
- One screen for guarantees still active and due to watch.
- An early release refused when the date predates the issue.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Guarantees** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
