# Dispatch par Compétences (dispatch_skills)

Affectation par compétences : exigences par type d'intervention, matching avec les habilitations valides du personnel, blocage en cas d'incompatibilité.

## Problème
Affecter la bonne personne à l'intervention requérant une habilitation (électrique, travail en hauteur) relève de la mémoire des dispatchers.

## Fonctionnalités
- Exigences par type
- Matching habilitations
- Blocage incompatibles
- Alerte d'habilitation expirée
- Statistiques de couverture

## Dépendances
- `project`, `hr`, `mail`
