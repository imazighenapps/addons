# GapWatch

No Site Slips Twice

## The problem

Sites with contractual visit frequencies slip past their due dates unnoticed because teams lack a clear, computed view of what is overdue and by how many days.

## The solution

Expose the sites whose contractual visit frequency you have let slip, before the customer notices instead.

## Main features

- Site register with customer, owner and required frequency.
- Computed and stored next due date per site.
- Automatic overdue status and overdue day counter.
- Action to log a completed visit and refresh scheduling.
- Stored counters for overdue tracking on each site.
- Search filters to focus immediately on overdue sites.
- Multi-company isolation for independent service teams.

## Installation

1. Install the module from the Apps list.
2. Open the **Visit Gaps** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
