# Nomenclatures Modulaires (mrp_modular_bom)

Nomenclatures modulaires : BOM de base + modules optionnels (groupes d'options avec règles), assemblage automatique de la nomenclature du MO selon la configuration vendue.

## Problème
Les produits configurables explosent en centaines de variantes de nomenclature à maintenir une par une dans Odoo Community.

## Fonctionnalités
- Groupes d'options par module
- Règles de compatibilité simples
- Génération de la BOM par MO
- Réduction du nombre de variantes à maintenir
- Coût calculé par configuration

## Dépendances
- `mrp`, `sale`, `mail`
