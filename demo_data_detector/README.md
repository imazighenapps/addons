# Détecteur de Données de Démonstration (demo_data_detector)

Détecteur de données de démo : signatures de jeux standards, liste des suspects, marquage et purge contrôlée avec journal.

## Problème
Les données de démo restent en production : faux clients, produits test qui polluent les états et la facturation.

## Fonctionnalités
- Signatures de jeux de démo
- Liste des suspects
- Marquage et purge contrôlée
- Journal de purge
- Historique des détections

## Dépendances
- `base`, `mail`
