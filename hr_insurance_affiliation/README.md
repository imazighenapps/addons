# Mutuelle et Prévoyance (hr_insurance_affiliation)

Registre d'affiliation : régime par salarié, taux employeur/employé, changements datés (entrée, sortie, dispense justifiée), état mensuel prêt pour la paie.

## Problème
Les affiliations mutuelle/prévoyance (régimes, taux, changements, dispenses) sont tenues dans un tableur : erreurs de prélèvement et DSN corrigées à la main.

## Fonctionnalités
- Régime par salarié
- Taux employeur/employé
- Changements datés
- Dispenses justifiées
- État mensuel pour la paie

## Dépendances
- `hr`, `mail`
