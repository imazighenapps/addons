# NearMissLog

Near Miss Report Register

## The problem

Near misses reported on paper lose follow-up and patterns.

## The solution

Record near misses with location, severity, reporter, corrective action and states.

## Main features

- Reports with event date, location and description.
- Severity: low, medium, high.
- Reporter and corrective action.
- Draft, reported, investigating, closed and cancelled states.
- Search and grouping by severity, location and state.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Near Misses** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
