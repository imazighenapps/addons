# Enquête Post-Intervention (job_csat)

Enquête post-intervention automatique : déclenchement par type d'intervention, score 1-5, escalade au-delà d'un seuil et tendance par technicien.

## Problème
La qualité des interventions est découverte par les réclamations : aucune mesure systématique de satisfaction par intervention.

## Fonctionnalités
- Enquête automatique
- Déclenchement par type
- Score et commentaire
- Escalade sous seuil
- Tendance par technicien

## Dépendances
- `project`, `mail`
