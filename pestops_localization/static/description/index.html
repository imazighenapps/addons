Feature 01 — Document Profiles

A profile per company sets the primary (and optional secondary) language, country context, display currency, and every customer-facing text: service, treatment and inspection titles, footer, legal/compliance notice and contact block — all translatable.

  • ✓ Primary + secondary language (bilingual auto-detected)
  • ✓ Country and currency display context
  • ✓ Localized titles, footers, legal notices, contacts
  • ✓ Unique profile name per company

Feature 02 — Automatic Resolution

Each visit resolves its profile automatically: visit override → customer preference → company default language → first active profile. Reports render through the resolved profile with zero manual selection — fiscal and legal rules stay 100% native Odoo.

  • ✓ Per-visit profile override field
  • ✓ Per-customer language and profile preference
  • ✓ Sensible company fallbacks, never empty
  • ✓ Zero interference with accounting localization
