# RenewalRadar - Contract Renewal Management

## The problem

Contracts expire silently. The sales team notices weeks later, the customer has already signed elsewhere, and nobody can explain why the recurring revenue dropped.

## The solution

Track contract end dates, notice periods and renewals, with automatic alerts, renewal history and churn reasons.

## Main features

- Contract register with type, owner, term and amount.
- Renewal date computed from the notice period.
- Days left and expiring alert on every contract.
- Daily scheduler flags contracts entering their notice period.
- One-click renewal extends the term and keeps history.
- Renewal history with user, date and note.
- Churn reason to explain lost contracts.
- Filters and groups per owner, type and status.

## Installation

1. Install the module from the Apps list.
2. Open the **Renewals** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
