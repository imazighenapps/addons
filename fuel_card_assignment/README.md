# FuelCardAssign

Fuel Card Assignment and Tracking

## The problem

Fuel card holders tracked informally lead to unclear accountability and attribution issues.

## The solution

Register fuel cards and assign them to employees with issue and return dates, track assigned/returned/blocked status, and keep a company-safe holder history.

## Main features

- Fuel card catalogue with identifier and provider.
- Assignments per employee with issue and return dates.
- Assigned, returned and blocked states.
- Actions to return or block assignments.
- Search and group by card, employee and state.
- Chatter tracking on assignments.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Fuel Cards** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
