# SupplyRequest

Internal Office Supply Requests

## The problem

Informal office supply requests are easily lost and lack an approval and fulfillment trail.

## The solution

Capture internal office supply requests with requester, needed date and item lines, run a submit/approve/fulfill workflow, and track requests in a company-safe register.

## Main features

- Internal requests with requester, needed date and priority.
- Request lines with description and quantity.
- Submit, approve and fulfill workflow states.
- Approval gate before fulfillment.
- Search and group by requester, state and period.
- Chatter tracking on requests.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Supply Requests** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
