# Carte des Interventions (dispatch_map)

Vue cartographique des interventions du jour/semaine : pins par statut, clusters, itinéraire suggéré et statistiques de distance.

## Problème
Le dispatcher ne voit pas les interventions sur une carte : zones de densité, trajets absurdes et optimisation impossibles.

## Fonctionnalités
- Carte des interventions
- Pins par statut
- Clusters de densité
- Itinéraire suggéré
- Statistiques de distance

## Dépendances
- `project`, `mail`
