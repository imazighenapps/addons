# TravelRequest

Employee Business Travel Request

## The problem

Business travel requested informally lacks prior approval and consolidated cost visibility.

## The solution

Submit and approve employee business travel requests with destination, dates, purpose and estimated cost, tracked through a company-safe approval workflow.

## Main features

- Travel requests with destination, dates and purpose.
- Estimated cost and travel notes.
- Draft, submitted, approved, refused and done states.
- Approval and refusal actions.
- Search and group by employee, state and period.
- Chatter tracking on requests.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Travel Requests** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
