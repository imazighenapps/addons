# Mises à Jour en Masse Planifiées (mass_update_rules)

Règles de mise à jour en masse : critères, valeurs/calculs, exécution planifiée, aperçu et journal avec annulation.

## Problème
Les mises à jour récurrentes de champs (indexations, statuts, tarifs) sont refaites à la main.

## Fonctionnalités
- Critères et valeurs
- Calculs
- Planification
- Aperçu avant run
- Journal avec undo

## Dépendances
- `base`, `mail`
