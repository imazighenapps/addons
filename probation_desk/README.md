# Probation

Decisions Before Deadlines

## The problem

Probation review deadlines are missed because no one tracks the decision date, turning trial periods into open-ended situations.

## The solution

Watch every probation period end date and force the review decision before the deadline turns into habit.

## Main features

- A probation period per employee with start, end and review dates.
- A stored overdue indicator for reviews past their deadline.
- Decisions to confirm, extend or close the probation with a state.
- Extensions update the end date and refuse invalid dates.
- The review date cannot come before the probation start.
- Search filters to focus on pending and overdue reviews.
- Employee-linked periods for HR follow-up.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Probation** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
