# Reliquats de Commandes Fournisseurs (po_backorder_desk)

File des reliquats : ligne par ligne, ancienneté, promesse du fournisseur, relances tracées et décision de solder ou réduire, avec rapport d'obsolescence.

## Problème
Les reliquats fournisseurs (quantités commandées jamais livrées) vieillissent invisiblement et polluent les stocks prévisionnels.

## Fonctionnalités
- File des reliquats datée
- Promesse fournisseur par ligne
- Relances tracées
- Décision de solde ou réduction
- Rapport d'obsolescence

## Dépendances
- `purchase`, `stock`, `mail`
