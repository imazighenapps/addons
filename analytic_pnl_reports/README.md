# P&L Analytique Interactif (analytic_pnl_reports)

P&L analytique interactif : axes (projet, département, canal), colonnes périodes, comparaison budgétaire, drill-down sur écritures.

## Problème
Lire un compte de résultat par projet/département exige des exports Excel interminables.

## Fonctionnalités
- Axes analytiques configurables
- Colonnes périodes
- Comparaison budgétaire
- Drill-down écritures
- Exports

## Dépendances
- `account`, `analytic`, `mail`
