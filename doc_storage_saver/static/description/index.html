Feature 01

Duplicates, Precisely Measured

Odoo already computes a SHA256 checksum for every file. The module groups identical checksums, counts copies and computes exactly how many bytes you can reclaim.

  • ✓ Group per checksum with copy count
  • ✓ Wasted bytes per group and per scan
  • ✓ Keep-newest cleanup, one click
Feature 02

Orphans & Guardrails

Files attached to records that no longer exist are flagged with a name and size snapshot. Cleanup skips anything still attached to a live record — you can never delete a real document by accident.

  • ✓ Name + size snapshot kept after deletion
  • ✓ Live-record guard on every delete
  • ✓ Minimum-size filter to skip noise
