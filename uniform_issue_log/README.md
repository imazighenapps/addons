# UniformIssueLog

Uniform and Workwear Issue Register

## The problem

Uniform issues tracked manually leave allocations and returns unclear.

## The solution

Record uniform and workwear issues and returns with employee, item details, dates and states.

## Main features

- Issue records with employee, item, size and quantity.
- Issue, expected return and actual return dates.
- Responsible issuer and condition notes.
- Draft, issued, returned and cancelled states.
- History of uniform issues per employee.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Uniform Issues** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
