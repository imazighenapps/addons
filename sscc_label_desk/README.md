# Étiquettes SSCC et Numérotation Logistique (sscc_label_desk)

Numérotation SSCC gérée : registre d'identifiants uniques, génération d'étiquettes conformes par palette, liée à l'expédition et réconciliable avec les réceptions client.

## Problème
Les clients industriels exigent des étiquettes SSCC GS1 sur les palettes : sans registre de numérotation, chaque expédition est un bricolage risqué.

## Fonctionnalités
- Registre SSCC unique
- Étiquettes conformes par palette
- Liaison à l'expédition
- Réconciliation réception client
- Journal de numérotation

## Dépendances
- `stock`, `sale`, `mail`
