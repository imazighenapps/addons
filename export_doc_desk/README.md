# Dossier Documentaire d'Export (export_doc_desk)

Générateur de dossier export : checklist par destination et produit, documents générés depuis les données Odoo, pièces jointes archivées et dossier complet prêt pour le transitaire.

## Problème
Chaque expédition export exige un jeu de documents (facture commerciale, packing list, origine, EUR.1, licences) reconstitué à la main et souvent incomplet.

## Fonctionnalités
- Checklist par destination
- Documents générés depuis Odoo
- Archivage par expédition
- Contrôle de complétude
- Historique par corridor

## Dépendances
- `sale`, `stock`, `account`, `mail`
