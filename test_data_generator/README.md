# Générateur de Données de Test (test_data_generator)

Générateur de données de test : profils de génération par modèle avec cohérence inter-modèles, volume paramétré et nettoyage à la fin.

## Problème
Tester une instance personnalisée exige des données cohérentes (tiers, commandes, stocks) que personne ne veut saisir.

## Fonctionnalités
- Profils de génération
- Cohérence inter-modèles
- Volume paramétré
- Nettoyage final
- Jeu réutilisable

## Dépendances
- `base`, `mail`
