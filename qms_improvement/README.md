# QMS Improvement

## Purpose
QMS Improvement provides a structured continuous-improvement and lessons-learned process so the QMS is used not only for compliance, but also for measurable improvement.

## Main capabilities
- Register improvement ideas and initiatives.
- Classify improvements as Kaizen, process improvement, cost reduction, customer experience, quality improvement or other.
- Record the source: audit, NCR/CAPA, complaint, risk review, objective, suggestion or other.
- Assign owner, priority and target date.
- Record baseline, target and actual values.
- Record unit of measure.
- Describe expected benefits and actual monetary benefit.
- Capture action plan.
- Capture lessons learned.
- Move an improvement from idea through approval, execution, completion and standardization.
- Cancel improvements when necessary.
- Register standalone lessons learned linked to a source model/reference.
- Mark lessons as shared.

## Models
- `qms.improvement`
- `qms.lesson.learned`

## Improvement workflow
`Idea → Approved → In Progress → Completed → Standardized`

`Cancelled` is available as an alternate end state.
