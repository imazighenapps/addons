# WarrantyClaimLog

Warranty Claim Register

## The problem

Warranty claims tracked informally lead to delayed responses and unclear outcomes.

## The solution

Register warranty claims with customer, product, issue details and resolution states to track after-sales follow-up.

## Main features

- Claim records with customer, product and sale/order reference.
- Issue description, serial/lot and key dates.
- Responsible user and planned resolution date.
- Draft, in review, approved, resolved and rejected states.
- Resolution notes and outcome tracking.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Warranty Claims** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
