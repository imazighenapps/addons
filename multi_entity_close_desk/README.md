# Clôture Multi-Entités (multi_entity_close_desk)

Coordinateur de clôture groupe : états par entité, dépendances (interco prêtes ?), consolidation de l'avancement et blocage des retards.

## Problème
Dans un groupe, la clôture de N filiales est coordonnée par emails ; l'entité bloquante n'est pas identifiée.

## Fonctionnalités
- États de clôture par entité
- Dépendances interco
- Avancement consolidé
- Blocage des retards
- Rapport final de groupe

## Dépendances
- `account`, `multicompany`, `mail`
