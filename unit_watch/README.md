# UnitWatch

No Unit Slips Through

## The problem

Unit slips like kg vs g or litre vs centilitre pass through orders and bills unnoticed, creating costly stock and invoice surprises with no simple place to track corrections.

## The solution

Catch the kg/lb, litre/cl and unit slips that slip into orders, receipts and bills before they cost money.

## Main features

- A register of unit checks with document, product and source.
- Expected and entered units with the suspicious quantity.
- Severity and source classification for every check.
- Stored suspicious flag for lines that still need attention.
- Correction fields to record the right quantity and close the check.
- Original values kept for a clear audit trail.
- A suspicious queue to review open slips in one screen.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Unit Watch** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
