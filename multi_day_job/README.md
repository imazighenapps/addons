# Interventions Multi-Jours (multi_day_job)

Découpage pluri-journalier : session par jour (heures, présence, avancement), consolidation sur l'intervention et contrôle du quota total.

## Problème
Les chantiers pluri-journées sont facturés/plannifiés comme une intervention : les journées réelles et les quotas dérivent.

## Fonctionnalités
- Sessions par jour
- Consolidation automatique
- Contrôle du quota
- Présence par jour
- Facturation au réel

## Dépendances
- `project`, `hr_timesheet`, `mail`
