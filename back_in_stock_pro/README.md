# BackInStock Pro - Back in Stock Alerts

## The problem

An out-of-stock product silently loses the sale. The customer leaves no email, and the shop never knows how much demand it missed.

## The solution

Capture out-of-stock demand, send automatic back-in-stock emails, and measure how much revenue you recover.

## Main features

- Public subscribe endpoint for any website.
- Double opt-in confirmation.
- Automatic back-in-stock email.
- Waiting list per product and variant.
- Demand analytics and CSV export.
- Unsubscribe and consent tracking.

## Installation

1. Install the module from the Apps list.
2. Open the **Stock Alerts** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
