# Alertes Équipe (Slack/Telegram) (team_alerts)

Pont d'alertes : règles d'événements (commande urgente, stock bas, SLA manqué), envoi vers Slack/Telegram/Mattermost avec action en retour.

## Problème
Les équipes vivent dans Slack/Telegram : les alertes Odoo arrivent trop tard ou pas du tout.

## Fonctionnalités
- Règles d'événements
- Canaux multiples
- Action en retour
- Anti-spam (seuils)
- Journal

## Dépendances
- `mail`
