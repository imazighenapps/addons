# Paliers d'Ancienneté (hr_tenure_milestones)

Module d'ancienneté : paliers calculés automatiquement, alertes aux managers et RH, droits associés paramétrés (congés, primes), célébrations tracées.

## Problème
Les anniversaires d'ancienneté (5, 10, 20 ans) passent inaperçus : droits liés à l'ancienneté oubliés et célébrations manquées.

## Fonctionnalités
- Paliers calculés automatiquement
- Droits associés paramétrés
- Alertes aux managers
- Célébrations tracées
- Rapport annuel

## Dépendances
- `hr`, `mail`
