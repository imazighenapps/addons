# Fenêtres de Silence (quiet_hours)

Fenêtres de silence : par utilisateur/groupe/type, différé et non-facturé, digest de reprise et journal.

## Problème
Les notifications de nuit/week-end harcèlent : les équipes désactivent tout et ratent les vraies alertes.

## Fonctionnalités
- Fenêtres par groupe
- Différé intelligent
- Digest de reprise
- Journal
- Exceptions urgences

## Dépendances
- `mail`
