# Déstockage des Proches Péremptions (stock_expiry_disposal_board)

Tableau de décision : file des lots à échéance, options valorisées (démarque, don, destruction), décision attribuée et mesurée, suivi de la valeur sauvée.

## Problème
Les lots proches de la date attendent une décision (démarque, don, destruction) qui reste dans des têtes : la perte se constate après coup.

## Fonctionnalités
- File des lots à échéance
- Options valorisées en un clic
- Décision attribuée et datée
- Valeur sauvée mesurée
- Historique par famille

## Dépendances
- `stock`, `account`, `mail`
