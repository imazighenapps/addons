# Notes Vocales (voice_notes)

Dictée vers note : enregistrement vocal lié à l'enregistrement, transcription automatique (modèle local ou API), relecture et archivage.

## Problème
Les techniciens dictent leurs notes au téléphone : transcription manuelle, oublis, retards.

## Fonctionnalités
- Enregistrement lié
- Transcription auto
- Relecture
- Archivage
- Statistiques

## Dépendances
- `base`, `mail`
