# OCR des Bons de Livraison (delivery_note_ocr)

OCR des bons de livraison : extraction des quantités/références, comparaison automatique avec la réception attendue et alerte d'écart.

## Problème
Les bons de livraison fournisseurs entrants sont archivés sans exploitation : les écarts de quantités sont découverts plus tard.

## Fonctionnalités
- Extraction du BL
- Comparaison à la réception
- Alerte d'écart
- File d'exceptions
- Historique

## Dépendances
- `stock`, `mail`
