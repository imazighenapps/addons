# Anonymisation de PDFs (pdf_redact)

Anonymisation réelle : suppression effective du texte masqué (pas juste recouvert), règles par gabarit et journal des redactions.

## Problème
Transmettre des PDFs à des tiers exige de masquer les données personnelles : masquage manuel risqué (le texte reste sous le rectangle).

## Fonctionnalités
- Suppression effective
- Règles par gabarit
- Journal des redactions
- Vérification
- Modèles

## Dépendances
- `base`, `mail`
