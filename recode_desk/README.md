# RecodeDesk

Renumber Without Breaking

## The problem

Renumbering a product breaks hidden references and leaves no proof of what changed; teams guess which labels and records still carry the old code.

## The solution

Renumber a product once and update every reference that points to it, with a full trace of what moved.

## Main features

- One renumbering request per product code change.
- Old code, new code, reason and planned application date.
- A trace line per reference with source and old/new values.
- Stored counts of total and updated references.
- Apply action that stamps completion and locks the request.
- Full trace posted to the chatter on completion.
- Draft and done states to separate planned from applied changes.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Recode Desk** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
