# FreightWatch

Freight Charged Fairly

## The problem

Freight overcharges hide inside supplier bills because billed transport lines are not checked against negotiated tariffs.

## The solution

Audit the transport lines on supplier bills against the freight tariffs you negotiated and keep the overcharges.

## Main features

- A register of freight tariffs with carrier, lane and agreed amount.
- Bill lines linked to a tariff with the amount actually charged.
- Overcharge computed and stored on every billed line.
- A disputed flag to track challenged freight amounts.
- An overcharges screen for every line billed above tariff.
- States to follow a line from draft to checked and disputed.
- Charged and tariff amounts must stay non-negative.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Freight Watch** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
