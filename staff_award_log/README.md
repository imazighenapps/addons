# StaffAwardLog

Employee Recognition and Award Register

## The problem

Informal employee recognition lacks a consistent, visible history.

## The solution

Record employee recognitions and awards with type, date, reason and states to keep a visible appreciation history.

## Main features

- Award records with employee, award type and date.
- Reason/description and awarded-by manager.
- Optional value or points note.
- Draft, announced and cancelled states.
- Recognition history per employee.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Staff Awards** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
