# Documentation du Modèle de Données (schema_doc)

Générateur de documentation : modèles et champs, droits par groupe, relations, diagrammes et export HTML/PDF régenérable.

## Problème
Documenter l'ERP (modèles, champs, droits) est refait à la main et périmé à chaque évolution.

## Fonctionnalités
- Catalogue des modèles
- Droits par groupe
- Relations
- Diagrammes
- Export HTML/PDF

## Dépendances
- `base`, `mail`
