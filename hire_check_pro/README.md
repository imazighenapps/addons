# HireCheck

Onboarding And Offboarding On Rails

## The problem

Each new hire is welcomed differently depending on who remembers what: the Odoo account exists after three days, the desk is wrong, the safety briefing is forgotten, and when somebody leaves the badge and the equipment are recovered weeks later, if ever.

## The solution

Launch a hire or an exit for an employee, get a starter checklist pushed into it, and close the file only when every task is done by its owner.

## Main features

- One checklist per employee hire or exit, typed onboarding or offboarding.
- Starter tasks pushed automatically in every new checklist.
- Tasks owned by users, with a category and a due date.
- Start, done, reopen and cancel states with a chatter trail.
- Closing is refused while tasks are still open.
- Live counters of open and total tasks on the checklist.
- Works directly on employee records, multi-company safe.

## Installation

1. Install the module from the Apps list.
2. Open the **Hire and Exit** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
