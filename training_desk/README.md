# TrainBook

From Plan To Certificate

## The problem

Training sessions are tracked in scattered documents, so attendance is unclear and certificates cannot be produced quickly when clients or auditors ask.

## The solution

Run training sessions from plan to attendance and hand each participant the certificate they can show.

## Main features

- Training sessions with topic, trainer and schedule.
- Attendance lines per employee with presence tracking.
- Certificate issuance recorded on each attendance line.
- A workflow to plan, confirm, complete and cancel sessions.
- Stored counters for attendees and issued certificates.
- Search filters and groupings for session follow-up.
- Validation of dates, capacity and participant uniqueness.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Training Desk** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
