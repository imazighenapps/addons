# Dossier d'Audit IT (it_audit_pack)

Générateur de dossier d'audit IT : droits, journaux, paramètres, sauvegardes, utilisateurs inactifs — PDF structuré et signé.

## Problème
L'auditeur IT demande des preuves (droits, journaux, configurations) : la collecte prend des jours.

## Fonctionnalités
- Sections par preuve
- Génération en un clic
- PDF signé
- Historique
- Checklist auditeur

## Dépendances
- `base`, `mail`
