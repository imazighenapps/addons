# Lot Économique de Commande (eoq_advisor)

Conseiller EOQ : coût de passation, coût de possession et demande configurables par produit, quantité optimale calculée et suggestion appliquée à la commande.

## Problème
Les quantités commandées sont fixées à l'intuition : trop petites (frais de commande) ou trop grandes (stock dormi), sans règle économique.

## Fonctionnalités
- Paramètres EOQ par produit
- Quantité optimale calculée
- Suggestion sur les commandes
- Simulation gain de coût
- Révision annuelle assistée

## Dépendances
- `stock`, `purchase`, `mail`
