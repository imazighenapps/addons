# Surcharge Indexée Client (customer_surcharge_index)

Surcharge indexée sur les ventes : indice périodique référencé, formule contractuelle par client, application automatique sur les lignes éligibles et justification imprimée sur la facture.

## Problème
Refacturer au client une surcharge carburant ou énergie liée à un indice se fait à la main : les surcharges sont oubliées ou contestées faute de base claire.

## Fonctionnalités
- Indice périodique référencé
- Formule contractuelle par client
- Application automatique sur les lignes
- Justification sur la facture
- Historique des indices appliqués

## Dépendances
- `sale`, `account`, `mail`
