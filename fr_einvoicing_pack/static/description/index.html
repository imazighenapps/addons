Feature 01

EN16931 Validation, Blocking on Posting

Every customer invoice is checked before posting: new legal mentions, one tax per line, totals consistency, identifiers. Non-compliant invoices are blocked with a precise report.

  • ✓ Customer SIREN, operation type, delivery address
  • ✓ Exactly one tax per invoice line
  • ✓ Untaxed + tax = total consistency check
  • ✓ Blocking behavior configurable in settings
Feature 02

Partner Readiness Score

SIREN / SIRET with Luhn checksum, French VAT format check, automatic SIREN completion from SIRET. Know instantly which customers are ready for e-invoicing.

  • ✓ Luhn validation on SIREN (9) and SIRET (14)
  • ✓ French VAT key check (FR + key + SIREN)
  • ✓ Ready flag + issues list per partner
  • ✓ SIRET must start with the partner SIREN
Feature 03

E-Reporting Register

Every posted invoice feeds the register automatically: B2B e-invoices, B2C and international e-reporting flows. Follow statuses, export CSV, and let the daily cron flag errors.

  • ✓ Automatic feed on invoice posting
  • ✓ Ready / Sent / Completed / Error workflow
  • ✓ One-click CSV export per invoice
  • ✓ Daily control of lines in error
