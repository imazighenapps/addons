# Débogueur de Rapports QWeb (qweb_report_debug)

Débogueur de rapports : erreurs de rendu avec contexte (record, lang, société), aperçu des variantes, historique des corrections.

## Problème
Les erreurs de rendu QWeb s'affichent brutes aux utilisateurs, sans contexte ni aperçu des variantes.

## Fonctionnalités
- Erreurs avec contexte
- Aperçu des variantes
- Historique des corrections
- Mode de diagnostic
- Journal de rendu

## Dépendances
- `base`, `mail`
