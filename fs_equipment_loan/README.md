# EquipLoan

Equipment and Tool Loans to Employees

## The problem

Equipment lent to employees is tracked informally, so overdue returns and current holders are hard to identify and items get lost.

## The solution

Register equipment and tool loans to employees, track checkout and due dates, capture returns with condition, and keep overdue or ongoing loans visible in a company-safe register.

## Main features

- Loanable equipment catalogue with reference and category.
- Employee loans with checkout date and expected return date.
- Return recording with date, condition and notes.
- Computed overdue state for ongoing loans past due date.
- Search and group by employee, equipment, state and period.
- Chatter tracking on loans and equipment.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Equipment Loans** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
