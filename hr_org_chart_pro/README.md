# Organigramme Interactif (hr_org_chart_pro)

Organigramme interactif : hiérarchie réelle depuis les données, postes vacants signalés, intérimaires marqués, filtres par site et fonction, export image à jour.

## Problème
L'organigramme n'existe qu'en PNG daté : postes vacants, managers intérimaires et dépendances invisibles pour la direction.

## Fonctionnalités
- Hiérarchie depuis les données
- Postes vacants signalés
- Intérimaires marqués
- Filtres par site et fonction
- Export image à jour

## Dépendances
- `hr`, `mail`
