# Pénalités de Retard Subies (sale_penalty_registry)

Registre des pénalités : détection depuis les retards de livraison, calcul au barème contractuel, justification, acceptation ou contestation et avoir tracé.

## Problème
Les pénalités de retard imposées par les clients industriels sont facturées sans justification ni suivi : les décisions se perdent dans les avoirs.

## Fonctionnalités
- Détection depuis les retards
- Calcul au barème contractuel
- Décision accepter/contester tracée
- Avoir généré au bon moment
- Statistiques par client et année

## Dépendances
- `sale`, `account`, `mail`
