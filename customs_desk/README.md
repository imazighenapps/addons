# CustomsDesk

Duty Checked Per Entry

## The problem

HS codes and duty rates are kept outside Odoo, so customs entries are checked by hand and wrong duties are paid or claimed back with no traceable reference.

## The solution

Keep HS codes and duty rates on your imported products and check every customs entry against them.

## Main features

- A register of HS codes with the applicable duty rate.
- Customs entries with supplier, origin country and declaration date.
- Entry lines with HS code, customs value and quantity.
- Stored duty amount per line and total duty per entry.
- Draft, checked and cleared states with a dated clearance.
- Cleared entries locked to preserve the declared amounts.
- A screen for entries still waiting to be checked.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Customs** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
