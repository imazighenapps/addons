# Suivi des Dosimétries (hr_dosimetry_tracking)

Registre de dosimétrie : port du dosimètre par travailleur, lectures périodiques saisies, seuils d'alerte, historique par travailleur et rapport pour les organismes.

## Problème
Les travailleurs exposés (radiologie industrielle, secteurs contrôlés) portent des dosimètres dont les lectures périodiques sont tenues hors ERP.

## Fonctionnalités
- Port du dosimètre par travailleur
- Lectures périodiques saisies
- Seuils d'alerte
- Historique par travailleur
- Rapport aux organismes

## Dépendances
- `hr`, `mail`
