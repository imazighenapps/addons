# Investigations OOS (quality_oos_investigation)

Workflow OOS : phase 1 (vérification laboratoire), phase 2 (investigation complète, causes probables), décision (retest, rejet, libération) tracée et archivée.

## Problème
Un résultat d'analyse hors spécification déclenche une investigation (phases labo, hypothèses, retest) menée dans Word : délais et preuves perdus.

## Fonctionnalités
- Déclenchement depuis un résultat hors spec
- Phases d'investigation guidées
- Retests tracés avec justification
- Décision finale signée
- Historique par produit et labo

## Dépendances
- `quality`, `mail`
