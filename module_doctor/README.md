# Docteur des Modules (module_doctor)

Vérificateur de santé des modules : chargement des dépendances, vues orphelines, champs manquants, erreurs de logs et rapport de compatibilité.

## Problème
Après une mise à jour, certains modules cassent silencieusement : les erreurs ne sont découvertes que par les utilisateurs.

## Fonctionnalités
- Contrôle des dépendances
- Vues orphelines
- Champs manquants
- Erreurs de logs
- Rapport de santé

## Dépendances
- `base`, `mail`
