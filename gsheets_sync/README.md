# Google Sheets Sync

Push Odoo data to Google Sheets

## The problem

Operational data is manually exported to Google Sheets, causing stale reports and repetitive work.

## The solution

Configure spreadsheet exports for Odoo data, schedule or run syncs, and track export runs and status.

## Main features

- Spreadsheet connection profiles per company.
- Export job definitions with model and field mapping text.
- Manual run action and run history.
- Row count, status and message tracking.
- Active/inactive jobs and last sync timestamp.
- Company-aware access control.
- No external Python dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Google Sheets Sync** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
