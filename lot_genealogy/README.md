# Genealogy

Every Lot Knows Its Roots

## The problem

When a quality issue hits a lot, tracing which input lots fed it and which finished lots inherited the risk takes hours in spreadsheets while suspect stock keeps moving.

## The solution

Trace the family tree of every produced lot: which parents fed it and which children inherit a quality issue.

## Main features

- One record per lot with product, reference and production date.
- Parent and child links to trace ancestry in both directions.
- Stored parent and child counts on every lot.
- Impact flag to mark lots affected by a quality issue.
- Ancestry and descendant views to walk the family tree.
- Notes kept on each lot and link for investigation context.
- A clear register of roots, intermediates and leaves.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Genealogy** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
