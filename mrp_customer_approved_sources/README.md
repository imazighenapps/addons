# Sources Approuvées par Client (mrp_customer_approved_sources)

Listes de sources approuvées par client et référence : blocage ou alerte à la commande, attestation de conformité sources lors de l'expédition.

## Problème
Sur les pièces contractualisées, le client impose ses sources autorisées (composants, sous-traitants) : les achats achètent hors liste sans s'en apercevoir.

## Fonctionnalités
- Sources autorisées par client/référence
- Alerte ou blocage à la commande
- Attestation d'approvisionnement conforme
- Historique des demandes de dérogation source
- Suivi des accords clients

## Dépendances
- `purchase`, `mrp`, `sale`, `mail`
