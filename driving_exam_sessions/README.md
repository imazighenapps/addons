# Sessions d'Examen (driving_exam_sessions)

Sessions d'examen avec candidats éligibles, convocations, saisie des résultats et relance des retests autorisés.

## Problème
L'organisation des passages d'examen (admissibilité, convocations, résultats, retests) vit dans un fichier du directeur.

## Fonctionnalités
- Sessions avec candidats éligibles
- Convocations générées
- Résultats enregistrés
- Retests autorisés suivis
- Taux de réussite par moniteur

## Dépendances
- `sale`, `mail`
