# Alertes de Champs Critiques (critical_field_alerts)

Alertes de champs critiques : liste de champs surveillés par modèle, notification à la modification, journal et revue périodique.

## Problème
Un prix modifié, une condition changée sans le savoir : des factures fausses partent.

## Fonctionnalités
- Champs surveillés
- Notification immédiate
- Journal des changements
- Revue périodique
- Seuils

## Dépendances
- `base`, `mail`
