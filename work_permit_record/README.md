# PermitTrack

Employee Work Permit and Authorization Records

## The problem

Work permits and authorizations tracked manually lack expiry visibility and a central compliance record.

## The solution

Register employee work permits and authorizations with type, reference and expiry dates, compute validity status, and keep a company-safe compliance record.

## Main features

- Permit records with employee, type, reference and issuer.
- Issue and expiry dates with computed validity status.
- Valid, expired and cancelled states with actions.
- Search and group by employee, type and state.
- Chatter tracking on records.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Work Permits** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
