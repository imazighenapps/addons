# Filigranes de Statut (doc_watermark)

Filigrane automatique selon le statut du document (brouillon, validé, copie, périmé) avec règles par modèle et date d'impression.

## Problème
Les brouillons et copies non contrôlées circulent sans marque : des documents périmés servent de référence.

## Fonctionnalités
- Filigrane par statut
- Règles par modèle
- Mention de date de tirage
- Blocage du filigrane manquant
- Journal

## Dépendances
- `base`, `mail`
