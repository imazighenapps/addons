# Digest des Erreurs Serveur (error_digest)

Digest hebdomadaire des erreurs : agrégation par trace, fréquence, utilisateurs touchés, tendance et assignment.

## Problème
Les erreurs applicatives s'accumulent sans que personne ne les voie : des bugs rongent le système pendant des semaines.

## Fonctionnalités
- Agrégation par trace
- Fréquence et tendance
- Utilisateurs touchés
- Assignment
- Digest hebdo

## Dépendances
- `base`, `mail`
