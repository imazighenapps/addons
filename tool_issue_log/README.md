# ToolIssue

Tool and Equipment Issue Log

## The problem

Shared tools issued informally lack a checkout history, leading to lost items and unclear responsibility.

## The solution

Register shared tools and log issues to employees with dates and condition notes, track issued and returned status in a company-safe history.

## Main features

- Tool catalogue with identifier and category.
- Issue records linking tool to employee with dates.
- Issued and returned states with condition notes.
- Return action updating status and date.
- Search and group by tool, employee and state.
- Chatter tracking on issues.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Tool Issues** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
