# LabWatch

Results Back To The Lot

## The problem

Samples go to the external lab with paper slips and emails, so results arrive disconnected from the lot and nobody can tell what is still awaiting analysis.

## The solution

Send samples to the external lab with a barcoded request and get the results back where the lot can see them.

## Main features

- A sample request with lot reference and barcoded identifier.
- The external laboratory and the date the sample was sent.
- The result and outcome recorded when the analysis comes back.
- A clear state from sent to result received.
- One awaiting screen for samples still at the lab.
- A received date before the sent date is refused for you.
- Chatter traceability on every sample request.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Lab Samples** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
