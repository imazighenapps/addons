# Intéressement & Participation (profit_sharing_calc)

Calculateur : formules légales paramétrées, plafonds, répartition par salarié (temps/salaires), provision comptable et DSN associée à vérifier.

## Problème
Le calcul de l'intéressement/participation (formules légales, plafonds, répartition) est un chantier annuel externalisé.

## Fonctionnalités
- Formules paramétrées
- Plafonds légaux
- Répartition par salarié
- Provision comptable
- Contrôle de cohérence paie

## Dépendances
- `account`, `mail`
