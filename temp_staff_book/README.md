# Intérim sur Projets (temp_staff_book)

Registre d'intérim : missions, agence, coût facturé vs budgété, rattachement projet et refacturation client si prévue.

## Problème
Les intérimaires sont gérés par agences avec coûts flous : le coût projet réel est faussé et les refacturations oubliées.

## Fonctionnalités
- Missions d'intérim
- Coût facturé vs budgété
- Rattachement projet
- Refacturation si prévue
- Comparaison agences

## Dépendances
- `project`, `purchase`, `mail`
