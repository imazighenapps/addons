# Calendrier de Dispatch avec Conflits (dispatch_calendar)

Calendrier de dispatch avec détection de conflits : chevauchements, absences, temps de trajet inter-interventions et règles de pause.

## Problème
Le planning terrain crée des doublons : même technicien sur deux chantiers, absences ignorées, conflits découverts le jour même.

## Fonctionnalités
- Détection de chevauchements
- Prise en compte des absences
- Temps de trajet inter-tâches
- Règles de pause
- Vue multi-techniciens

## Dépendances
- `project`, `hr_holidays`, `mail`
