# Chorus Pro Bridge

Submit and track public-sector invoices

## The problem

Public-sector invoices must be submitted and monitored in Chorus Pro outside Odoo, leading to lost status updates, unclear rejections and delayed payment follow-up.

## The solution

Prepare, submit and track Chorus Pro invoice submissions for French public-sector customers with status follow-up.

## Main features

- Chorus Pro connection profile per company (sandbox/production).
- Submission records linked to customer invoices and partners.
- Engagement, service code and recipient references.
- Statuses: draft, ready, submitted, accepted, rejected, paid.
- Status history log with messages and timestamps.
- Prepare, submit, mark status and reset actions.
- Rejection reason tracking for corrective action.
- No external Python dependency (API calls abstracted).

## Installation

1. Install the module from the Apps list.
2. Open the **Chorus Pro Bridge** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
