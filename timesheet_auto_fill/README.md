# Préremplissage des Feuilles de Temps (timesheet_auto_fill)

Préremplissage : feuilles de temps générées depuis le planning et les interventions réalisées, à confirmer ou corriger par la personne.

## Problème
Les techniciens ne saisissent pas leurs heures : la facturation du temps réel est impossible.

## Fonctionnalités
- Génération depuis le planning
- Confirmation/correction
- Traçabilité des corrections
- Couverture améliorée
- KPI de saisie

## Dépendances
- `hr_timesheet`, `project`, `mail`
