# Registre de Risques Projet (project_risk)

Registre de risques : identification, probabilité/impact, plan de mitigation, propriétaire et revue périodique avec rapport.

## Problème
Les risques projets (approvisionnements, autorisations, météo) vivent dans la tête du chef de projet et frappent sans plan B.

## Fonctionnalités
- Identification et scoring
- Plans de mitigation
- Propriétaires
- Revue périodique
- Rapport de risques

## Dépendances
- `project`, `mail`
