# SEPA Prélèvements In (sepa_direct_debit)

Gestion des mandats et prélèvements SEPA (pain.008.001.02) : registres de mandats avec cycle de vie et séquences (FRST/RCUR/OOFF/FNAL), lots de collecte, génération XML, import des rejets (pain.002).

## Dépendances
- `account`, `mail`

## Internationalisation
7 langues : en_US, fr_FR, ar_001, es_ES, de_DE, pt_BR, zh_CN.
