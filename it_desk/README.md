# ITBook

Hardware, Owned And Traced

## The problem

Hardware is handed out without a reliable record, so IT cannot tell who holds each device, since when, or what must be recovered when people move or leave.

## The solution

Register every laptop, phone and screen, who uses it, since when and what to do with it when they stop.

## Main features

- A hardware register with type, serial, model and purchase date.
- Lifecycle states for stock, in use, in repair and retired devices.
- Assignments with holder, handover date and return tracking.
- The current holder kept up to date on each asset.
- Open assignment counters stored on every asset.
- A clear queue of assignments still waiting for a return.
- Multi-company isolation out of the box.
- A full chatter trail for every handover decision.

## Installation

1. Install the module from the Apps list.
2. Open the **IT Assets** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
