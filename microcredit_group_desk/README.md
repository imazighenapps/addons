# Microcrédit Solidaire (microcredit_group_desk)

Groupes d'emprunteurs solidaires, comités d'octroi tracés, échéanciers, garanties de groupe et tableau de bord des retards.

## Problème
Les associations de microcrédit suivent groupes d'emprunteurs, comités d'octroi, échéanciers et garanties solidaires sur tableur, avec des retards découverts tardivement.

## Fonctionnalités
- Groupes solidaires
- Comités d'octroi
- Échéanciers
- Garanties de groupe
- Suivi des retards

## Dépendances
- `account`, `project`, `mail`
