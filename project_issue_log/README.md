# Registre des Blocages Projet (project_issue_log)

Registre de blocages : description, responsable du débloquage, échéance, vieillissement et impact chiffré (délai, coût).

## Problème
Les blocages (validation client, accès, approvisionnement) vivent dans les réunions : aucun suivi des vieillissements et des responsabilités.

## Fonctionnalités
- Registre de blocages
- Responsable du débloquage
- Vieillissement
- Impact chiffré
- Rapport hebdo

## Dépendances
- `project`, `mail`
