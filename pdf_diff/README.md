# Comparateur de PDFs (pdf_diff)

Comparateur : diff texte et visuel de deux versions, changements surlignés, rapport et archivage de la comparaison.

## Problème
Comparer deux versions d'un contrat/BL à l'œil est impossible : des changements passent inaperçus.

## Fonctionnalités
- Diff texte et visuel
- Surlignage
- Rapport
- Archivage
- Historique

## Dépendances
- `base`, `mail`
