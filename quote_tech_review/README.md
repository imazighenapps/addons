# Revue Technique des Devis (quote_tech_review)

Étape de revue interne avant envoi : checklist technique par famille de produits, validateur désigné, commentaires et blocage de l'envoi tant que la revue n'est pas passée.

## Problème
Les devis complexes partent au client sans revue technique : une impossibilité de production est découverte après la commande.

## Fonctionnalités
- Checklist technique par famille
- État revu/envoyé sur le devis
- Validateur désigné avec délai
- Commentaires et corrections
- Journal des revues

## Dépendances
- `sale`, `mail`
