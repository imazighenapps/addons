# Surcharge

Indexes Applied Right

## The problem

Raw material surcharges are recomputed in spreadsheets, so suppliers can bill outdated index values and buyers cannot quickly prove or dispute the difference.

## The solution

Recompute the raw material surcharge your suppliers may bill from the index you agreed and flag the deltas.

## Main features

- Index clauses with supplier, base index and surcharge factor.
- Applied surcharge lines per billing period and clause.
- The expected surcharge computed and stored from the index values.
- The billed amount compared with a stored variance.
- A clear workflow to review, accept or dispute each surcharge.
- One screen for clauses and one for billed surcharge variances.
- Disputes require no silent edits to the agreed formula.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Surcharge Watch** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
