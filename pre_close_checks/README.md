# Contrôles Pré-Clôture (pre_close_checks)

Série de contrôles de cohérence pré-clôture : comptes à sens anormal, écritures déséquilibrées, pièces sans pièce justificative, comptes de passage non soldés, rappro d'inventaire, avec un rapport d'exceptions assigné.

## Problème
Avant la clôture, des dizaines de contrôles manuels (équilibrages, sens des comptes, écritures orphelines) sont passés dans Excel.

## Fonctionnalités
- 10+ contrôles de cohérence configurables
- Rapport d'exceptions assignées
- Historique par période
- Intégration au checklist de clôture
- Non-blocage configurable

## Dépendances
- `account`, `mail`
