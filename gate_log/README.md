# GateBook

The Gate Tells The Truth

## The problem

Truck arrivals and departures are noted informally at the gate, so waiting time cannot be proven and demurrage disputes are settled from memory instead of facts.

## The solution

Register every truck entering and leaving the site from the gate, to prove the wait you billed or were billed.

## Main features

- A gate register for every truck with plate, carrier and driver.
- Purpose, dock and reference captured on each visit.
- Entry and exit times stamped with a simple gate workflow.
- Waiting duration computed and stored on every closed visit.
- On-site and closed states with a full chatter trail.
- Open visit counters stored on each gate point.
- Multi-company isolation out of the box.
- A factual log to prove the wait you billed or were billed.

## Installation

1. Install the module from the Apps list.
2. Open the **Gate Log** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
