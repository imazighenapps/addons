# Vendor Collaboration

Unified vendor collaboration workspace for Odoo Purchasing.

## Features

- Advanced Shipping Notices (ASN) with receipt tracking
- Vendor chargebacks with approval and resolution workflow
- Vendor catalog items with pricing, lead time, and validity
- Chatter tracking and multi-company support
