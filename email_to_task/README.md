# Emails vers Tâches (email_to_task)

Extracteur d'emails : règles de parsing (expéditeur, objet, corps), création de tâches pré-remplies avec pièces jointes liées.

## Problème
Les demandes qui arrivent par email doivent être recopiées en tâches : pertes, doublons et délais.

## Fonctionnalités
- Règles de parsing
- Création de tâches
- PJ liées
- Anti-doublon
- Journal des conversions

## Dépendances
- `project`, `mail`
