# Simulateur de Coût d'Arrivage (landed_cost_sim)

Simulation à la commande : paliers de fret, assurance, droits estimés, allocation par unité, comparaison fournisseurs et bascule du résultat dans le coût de l'article.

## Problème
Le vrai coût de revient à l'arrivée (prix, fret, assurance, droits) n'est connu qu'après la réception : les prix de vente sont fixés sur une base fausse.

## Fonctionnalités
- Estimation à la commande
- Paliers de fret configurables
- Allocation par unité
- Comparaison fournisseurs
- Bascule vers le coût réel

## Dépendances
- `purchase`, `stock`, `mail`
