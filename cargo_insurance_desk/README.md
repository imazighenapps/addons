# Assurance Marchandises Transportées (cargo_insurance_desk)

Registre d'assurance transport : valeurs déclarées par expédition, plafonds suivis, déclaration de sinistre dans les délais avec pièces et suivi d'indemnisation.

## Problème
L'assurance marchandises est déclarée à l'aveugle : valeurs transportées non cumulées, sinistres non déclarés dans le délai, indemnisations perdues.

## Fonctionnalités
- Valeur par expédition
- Plafonds suivis
- Déclaration de sinistre datée
- Suivi d'indemnisation
- Bilan annuel des primes

## Dépendances
- `sale`, `stock`, `account`, `mail`
