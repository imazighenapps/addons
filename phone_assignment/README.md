# PhoneAssign

Company Phone and SIM Assignment

## The problem

Phone and SIM assignments tracked informally lead to unknown holders, lost devices and weak accountability.

## The solution

Track company phones and SIM cards, assign them to employees with issue and return dates, record status changes, and keep a company-safe assignment history.

## Main features

- Phone/SIM catalogue with identifier, number and type.
- Assignments per employee with issue and return dates.
- Assigned, returned and lost states.
- Return and lost actions updating status and dates.
- Search and group by employee, item and state.
- Chatter tracking on assignments.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Phone Assignments** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
