# CancelDesk

Every Cancel Explained

## The problem

A cancelled order leaves the pipeline with no trace of the reason, the value or the decision maker, so the same loss repeats quarter after quarter and nobody can say how much revenue was recovered instead.

## The solution

Log every cancelled order with a reason, the lost value and who decided, and turn the pattern into decisions.

## Main features

- One cancellation record with order, customer and responsible.
- The exact lost value of the order and the decision date.
- A reason per cancellation: price, delivery, product, rival.
- Write off the loss with a dated stamp.
- Recoveries with the new order, the amount and the date.
- The sheet flips to recovered once the value is fully won back.
- Reason counters show why revenue actually disappears.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Cancel Desk** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
