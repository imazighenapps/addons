# Programme de Mentorat (hr_mentoring_program)

Programme de mentorat : duos appariés par objectifs, sessions planifiées et tracées, sujets suivis, bilan de valeur par duos et par programme.

## Problème
Les programmes de mentorat sont lancés puis abandonnés : duos informels, sessions non suivies, aucun bilan de valeur.

## Fonctionnalités
- Appariement par objectifs
- Sessions planifiées et tracées
- Sujets suivis
- Bilan de valeur
- Historique par duos

## Dépendances
- `hr`, `mail`
