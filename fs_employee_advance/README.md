# EmployeeAdvance

Cash Advances and Clearing

## The problem

Employee cash advances tracked outside Odoo leave unknown outstanding balances and no clear trail of approvals, payments and clearings.

## The solution

Track employee cash advances from request to clearing, record partial expense or cash returns, and keep the outstanding balance per advance and per employee in a company-safe register.

## Main features

- Advance request per employee with amount, date and purpose.
- Approval and payment workflow with explicit states.
- Partial and full clearing through expense or cash-return lines.
- Outstanding balance computed per advance and protected by controls.
- Search and group by employee, state and period.
- Chatter tracking for amounts and state changes.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Advances** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
