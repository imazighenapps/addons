# InspectLog

Equipment Inspection Log

## The problem

Equipment inspections tracked informally lead to missed checks and findings not followed to closure.

## The solution

Log equipment inspections with findings and follow-up actions, track status from planned checks to closure, and keep a company-safe inspection history.

## Main features

- Inspection records linked to equipment and inspector.
- Findings, condition and follow-up action fields.
- Planned, done, issue found and closed states.
- Actions to complete, flag issues and close inspections.
- Search and group by equipment, inspector and state.
- Chatter tracking on inspections.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Equipment Inspections** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
