# FeeWatch

Fees Signed, Fees Charged

## The problem

Payment platforms bill fees that drift from the signed rate card, and finance teams rebuild spreadsheets after the fact to spot and recover the unexpected charges.

## The solution

Compare what your payment platform charges with the rate you signed and recover every unexpected fee.

## Main features

- A fee contract per provider with the signed rates.
- A percentage rate and a fixed amount per transaction.
- Billed fee lines with settled amount and charged fee.
- Expected fee and variance computed and stored on every line.
- A workflow to dispute, recover or waive an unexpected fee.
- One variance screen for every line that differs from the contract.
- A recovered amount tracked on each disputed line.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Fee Watch** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
