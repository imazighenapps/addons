# WaterTemperatureLog

Water Temperature Monitoring Register

## The problem

Water readings on paper hide out-of-range points across 10 to 100 locations.

## The solution

Record water temperature readings per point with target range, automatic flag and alerts.

## Main features

- Points with name and type.
- Reading date and measured temperature.
- Configurable target minimum and maximum.
- Automatic in-range flag.
- Draft, recorded, alert and cancelled states.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Water Temperature** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
