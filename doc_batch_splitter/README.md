# Découpeur de Scans Multiples (doc_batch_splitter)

Découpeur de lot : détection des séparateurs (page de garde, QR, codes), découpe en documents individuels et affectation.

## Problème
Scanner 50 factures en un seul PDF : séparation et affectation manuelles de chaque page.

## Fonctionnalités
- Détection de séparateurs
- Découpe automatique
- Affectation
- Journal
- Prévisualisation

## Dépendances
- `base`, `mail`
