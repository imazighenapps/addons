# Opportunités Bloquées par Étape (stage_aging_alert)

Alerte d'ancienneté par étape : délai maximum par étape, liste des dépassés, action proposée (relancer, qualifier, clôturer) et rapport d'hygiène du pipeline.

## Problème
Des opportunités dormissent des semaines dans une étape sans personne ne le remarque : le pipeline s'encombre de deals fantômes.

## Fonctionnalités
- Délai maximum par étape
- Liste des opportunités dépassées
- Action proposée sur chaque deal
- Rapport d'hygiène du pipeline
- Statistiques d'ancienneté

## Dépendances
- `crm`, `mail`
