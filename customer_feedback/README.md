# FeedbackLog

Customer Feedback and Satisfaction Tracking

## The problem

Customer feedback scattered across inboxes and notes cannot be scored, trended or followed up consistently, so recurring issues go unnoticed.

## The solution

Log customer feedback with satisfaction score, topic and follow-up state, link it to customers and orders, and report trends by score, topic and period in a company-safe register.

## Main features

- Feedback entry per customer with channel, score and topic.
- Configurable feedback topics per company.
- Follow-up states with responsible user and resolution note.
- Optional sale order reference for context.
- Search and group by score, topic, state and period.
- Chatter tracking on feedback entries.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Feedback** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
