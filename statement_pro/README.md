# StatementPro - Customer and Supplier Statements

## The problem

Accounting teams rebuild statements in Excel every month, forget the opening balance, and spend two days sending PDFs one by one.

## The solution

Consolidated account statements per partner: opening balance, movements, aging, PDF and batch sending.

## Main features

- Statement per customer or supplier from posted journal items.
- Opening balance, movements and closing balance.
- Aging by due date with overdue amount and days late.
- Professional PDF using the company layout.
- Batch wizard for the whole customer list.
- Multi-company and multi-currency.
- Audit trail on generation and sending.

## Installation

1. Install the module from the Apps list.
2. Open the **Statements** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
