# VisitPlan

Routes That Respect The Map

## The problem

Weekly site visits are organized through phone calls and ad hoc messages, so routes are inefficient, stops are forgotten and there is no shared view of the planned travel order.

## The solution

Plan each week of site visits per technician with the sensible travel order instead of the phone ping-pong.

## Main features

- Weekly visit plans per technician with company isolation.
- Ordered stops with customer, site reference and planned date.
- Draft, planned and done workflow for every route.
- One-click action to complete individual stops.
- Stored counters for total, planned and completed stops.
- Dedicated list, kanban, form and search views for planning.
- Chatter tracking on plans and stops for coordination.

## Installation

1. Install the module from the Apps list.
2. Open the **Visit Planning** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
