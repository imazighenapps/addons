# File des Besoins sous Minimum de Commande (moq_queue_desk)

File des sous-MOQ : besoins en attente, délai d'accumulation maximal, regroupement différé ou rachat pénalisant avec justification tracée.

## Problème
Les besoins inférieurs au minimum de commande du fournisseur sont commandés de force ou abandonnés : surcoût ou rupture, sans règle.

## Fonctionnalités
- File des besoins sous MOQ
- Délai d'accumulation maximal
- Regroupement différé automatique
- Rachat pénalisant justifié
- Économies de regroupement mesurées

## Dépendances
- `purchase`, `stock`, `mail`
