# MileageLog

Business Mileage and Trip Log

## The problem

Mileage claims recorded informally are inaccurate and difficult to validate and reimburse consistently.

## The solution

Log business trips with distance, purpose and rate, compute reimbursable amounts, validate entries, and report mileage by employee and period in a company-safe register.

## Main features

- Trip logs with employee, date, route and purpose.
- Distance, rate and computed amount.
- Draft, submitted, validated and refused states.
- Submit and validate workflow actions.
- Search and group by employee, state and period.
- Chatter tracking on entries.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Mileage Log** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
