# Commandes Fournisseurs Multi-Sites (po_site_split)

Commande multi-destinations : une commande fournisseur avec lignes affectées à chaque site, livraison groupée ou éclatée au choix et suivi des réceptions par site.

## Problème
Commander pour plusieurs dépôts chez un même fournisseur oblige à N commandes séparées : frais de port multipliés et négociation affaiblie.

## Fonctionnalités
- Lignes affectées par site
- Expédition groupée ou éclatée
- Réceptions suivies par site
- Gain de transport consolidé
- Historique par dépôt

## Dépendances
- `purchase`, `stock`, `mail`
