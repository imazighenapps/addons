# Co-Vente avec Partenaire (partner_cosal_desk)

Co-vente partenaire : deal enregistré avec règle de partage convenue, part du partenaire calculée sur les factures réelles et refacturation tracée.

## Problème
Les deals menés avec un partenaire externe (apporteur, intégrateur) se négocient hors système : la part du partenaire n'est jamais documentée ni facturée proprement.

## Fonctionnalités
- Deal partagé avec règle convenue
- Part calculée sur les factures réelles
- Refacturation tracée du partenaire
- Statuts du deal
- Historique de performance par partenaire

## Dépendances
- `sale`, `account`, `crm`, `mail`
