# Classification des Documents Entrants (inbound_doc_classify)

Classification automatique : détection du type (facture, BL, courrier, contrainte) par modèle de texte, rattachement au dossier et file de revue.

## Problème
Les documents numérisés arrivent dans une boîte commune sans type : quelqu'un doit les trier à la main chaque jour.

## Fonctionnalités
- Détection du type
- Rattachement au dossier
- File de revue
- Règles métier
- Métriques de précision

## Dépendances
- `base`, `mail`
