# Import & Rappro FEC (fec_import_reconcile)

Importeur FEC : lecture des 18 champs, écritures créées avec pièces, rapprochement des totaux et liste des écarts non importés.

## Problème
Rapatrier la comptabilité d'un ancien outil en FEC vers Odoo, puis vérifier l'égalité des totaux, est un chantier manuel.

## Fonctionnalités
- Lecture FEC 18 champs
- Création d'écritures avec pièces
- Rapprochement des totaux
- Écarts listés
- Journal de migration

## Dépendances
- `account`, `mail`
