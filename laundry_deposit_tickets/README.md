# Tickets de Dépôt Pressing (laundry_deposit_tickets)

Tickets de dépôt numérotés avec statuts (reçu, en cours, prêt, rendu), sacs identifiés, retrait contrôlé et board des colis prêts.

## Problème
Les tickets de dépôt de blanchisserie sont manuels : statuts illisibles, litiges sur les remises, pièces perdues.

## Fonctionnalités
- Tickets numérotés avec statuts
- Sacs identifiés par ticket
- Board des colis prêts
- Retrait avec contrôle d'identité
- Relances des retraits tardifs

## Dépendances
- `sale`, `stock`, `mail`
