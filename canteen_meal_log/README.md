# CanteenLog

Canteen Meal and Service Log

## The problem

Canteen meal counts and costs tracked manually are difficult to reconcile and report accurately.

## The solution

Record daily canteen meal services with headcount, costs and notes, confirm logs, and report totals by meal type and period in a company-safe register.

## Main features

- Daily meal logs with date, meal type and headcount.
- Cost and subsidy fields with notes.
- Draft and confirmed states.
- Confirm action for reporting.
- Search and group by meal type, date and state.
- Chatter tracking on logs.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Canteen Log** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
