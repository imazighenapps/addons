# VendorBoard

Supplier Evaluation Scorecard

## The problem

SMBs have no shared, structured record of supplier performance, so vendor decisions rely on memory and issues repeat.

## The solution

Record periodic supplier evaluations with criteria scores, an overall rating, comments and follow-up states to compare vendor performance over time.

## Main features

- Periodic supplier evaluations with evaluation date and period label.
- Criteria scores for delivery, quality, price and service.
- Overall score computed from criteria scores.
- Draft, validated and archived states.
- Comments, strengths and improvement actions.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Vendor Board** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
