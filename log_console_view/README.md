# Console de Logs Filtrable (log_console_view)

Console de logs dans Odoo : filtres par niveau, module, utilisateur, requête, vues sauvegardées et surlignage d'erreurs.

## Problème
Débugger une instance oblige à SSH et grep dans des fichiers de logs énormes.

## Fonctionnalités
- Filtres par niveau et module
- Vues sauvegardées
- Surlignage d'erreurs
- Liens vers records concernés
- Extraction d'extraits

## Dépendances
- `base`, `mail`
