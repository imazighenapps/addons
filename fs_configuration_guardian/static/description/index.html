When a problem appears later, the difficult question is often not "what does Odoo do?" but "what changed?"

Configuration Guardian gives integrators and administrators a clear reference point and a practical way to investigate configuration drift.

FAQ

Frequently asked questions

Does it audit every business record?

No. The product is intentionally focused on configuration governance rather than a generic audit trail for every business transaction.

Does it automatically change or repair configuration?

No. The V1 approach is read, detect, explain, assess and review. It does not silently modify your production configuration.

Can I use it for client production databases?

Yes. The workflow is especially suited to Odoo integrators and managed-service teams that need a trusted configuration reference for production environments.

Is it Community and Enterprise compatible?

The module is designed for Odoo 19 and handles edition-specific configuration areas without requiring Enterprise-only dependencies for the core module.
