# HazardReportLog

Workplace Hazard Report Register

## The problem

Untracked hazard reports lack ownership and closure, allowing risks to persist.

## The solution

Record hazard observations with location, severity, responsible person and resolution states to track risks to closure.

## Main features

- Hazard reports with date, location, reporter and description.
- Hazard type and severity/priority.
- Responsible person and corrective action notes.
- Draft, reported, in progress, resolved and dismissed states.
- Resolution date and outcome tracking.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Hazard Reports** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
