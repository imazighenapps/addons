# Écarts par Machine (vending_machine_variance)

Comptage attendu vs constaté par machine avec journal des manquants, cassés et vols, historique par emplacement.

## Problème
Les écarts de caisse et produits cassés par machine ne sont jamais isolés : pertes réparties partout.

## Fonctionnalités
- Comptage attendu vs constaté
- Journal des manquants et cassés
- Historique par machine
- Machine à problème repérée
- Statistiques par emplacement

## Dépendances
- `stock`, `mail`
