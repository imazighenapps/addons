# Teams Notifications

Send Odoo alerts to Microsoft Teams

## The problem

Key Odoo events are missed because they are not pushed to Microsoft Teams channels where teams collaborate.

## The solution

Configure Microsoft Teams webhooks and notification rules to push Odoo business alerts to channels.

## Main features

- Teams webhook/channel configurations.
- Notification rules by business area/event.
- Notification records with payload preview and status.
- Test and send actions with logs.
- Active/inactive rules and channels.
- Company-aware access.
- No external Python dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Teams Notifications** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
