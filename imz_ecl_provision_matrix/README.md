# Provision IFRS9 (ecl_provision_matrix)

Matrice ECL : taux de perte par bucket d'ancienneté, scénarios prospectifs, calcul de la provision, justification pour l'auditeur et écritures.

## Problème
La matrice de pertes attendues (IFRS9 simplifiée) par ancienneté est tenue dans Excel par les entreprises auditées.

## Fonctionnalités
- Matrice par ancienneté
- Scénarios prospectifs
- Calcul de provision
- Dossier d'audit PDF
- Écritures automatiques

## Dépendances
- `account`, `mail`
