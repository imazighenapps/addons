# ApprovalDeskPro - Multi-Level Approval Workflow

## The problem

Approval rules live in email threads and spreadsheets: nobody knows who must sign a 12 000 EUR purchase order, the same request is approved twice or not at all, and there is no dated proof of who said yes.

## The solution

Route any record through a multi-level approval chain: one approver per amount threshold, strict step-by-step sign-off, dated decisions and a full chatter trail.

## Main features

- Approval request on any record: model, ID and display name.
- One approver per threshold, with a minimum amount.
- Chain built automatically at submission, ordered by threshold.
- Step-by-step approval: only the current approver can sign.
- Refusal closes the request and stops the chain.
- Reset to draft clears the chain and starts over.
- Dated decisions, comments and full chatter history.
- Multi-company and multi-currency, no external dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Approvals** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
