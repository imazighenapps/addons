# YieldWatch

Losses Never Anonymous

## The problem

Planned output and real output are compared in spreadsheets, so recurring losses stay anonymous, the yield drifts without a named cause and nobody can prove where the material went.

## The solution

Compare the output a production order should give with what it gave and name the losses that repeat.

## Main features

- One run record per production order with planned and actual output.
- Lost quantity and yield rate computed and stored on every run.
- Named loss lines with reason, step, quantity and note.
- Counters on the run for loss lines and total lost quantity.
- Draft, running and closed states with an audit trail.
- Closing the run freezes output and losses from further edits.
- A negative or impossible output is refused for you.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Yield Watch** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
