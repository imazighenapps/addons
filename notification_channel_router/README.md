# Routeur de Notifications (notification_channel_router)

Routeur de canaux : règles par type/urgence/utilisateur (email, SMS, messagerie, digest), quotas et journal d'envoi.

## Problème
Toutes les notifications partent par email : les urgences se noient et les emails meurent.

## Fonctionnalités
- Règles par type/urgence
- Canaux multiples
- Quotas
- Journal
- A/B de canaux

## Dépendances
- `mail`
