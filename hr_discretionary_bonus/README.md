# Primes Discrétionnaires (hr_discretionary_bonus)

Registre de primes discrétionnaires : proposition par manager avec justification, validation RH et direction, plafond d'enveloppe contrôlé et transmission à la paie.

## Problème
Les primes décidées par les managers (coup de cœur, mission particulière) se paient par emails à la paie : montants non justifiés, doublons, aucune vue du total.

## Fonctionnalités
- Proposition avec justification
- Workflow de validation
- Enveloppe annuelle contrôlée
- Transmission à la paie
- Historique par manager

## Dépendances
- `hr`, `mail`
