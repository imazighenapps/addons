# Audits d'Accessibilité RGAA (rgaa_audit_tracker)

Suivi d'audit d'accessibilité : critères par page, résultats consignés, plan d'action daté et ré-audit périodique.

## Problème
Les obligations d'accessibilité numérique exigent des audits structurés (critères, conformité, plan d'action) tenus hors système.

## Fonctionnalités
- Critères par page
- Résultats consignés
- Plan d'action daté
- Ré-audit périodique
- Déclaration d'accessibilité

## Dépendances
- `project`, `mail`
