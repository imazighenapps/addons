# Assurance-Crédit Interface (credit_insurance_desk)

Interface assurance-crédit : plafonds par acheteur, déclaration mensuelle des ventes, déclaration des sinistres avec pièces, suivi des indemnités.

## Problème
Les PME assurées crédit déclarent leurs ventes mensuelles et leurs sinistres manuellement, hors délais.

## Fonctionnalités
- Plafonds assureur par acheteur
- Déclaration mensuelle des ventes
- Déclaration de sinistre avec pièces
- Suivi des indemnités
- Alertes de plafond dépassé

## Dépendances
- `account`, `mail`
