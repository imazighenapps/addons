# File des Commandes Express (rush_order_desk)

File des commandes express : drapeau d'urgence avec motif, grille de surcharge appliquée au devis, priorité affichée en préparation et score de ponctualité des expresses.

## Problème
Les commandes urgentes arrivent dans la file standard : le personnel ne voit pas ce qui est critique et les surcoûts d'express ne sont ni chiffrés ni refacturés.

## Fonctionnalités
- Drapeau d'urgence avec motif
- Grille de surcharge express
- Priorité visible en préparation
- Score de ponctualité des expresses
- Rapport des surcharges refacturées

## Dépendances
- `sale`, `stock`, `mail`
