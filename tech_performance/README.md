# Rendement des Techniciens (tech_performance)

Comparaison planifié vs réalisé par technicien : taux de rendement, écarts récurrents, facteurs (distance, type, client) et objectif d'amélioration.

## Problème
Le temps réel des interventions n'est pas comparé au temps standard : impossible de mesurer l'efficacité et de planifier honnêtement.

## Fonctionnalités
- Temps standard vs réel
- Taux de rendement
- Écarts récurrents
- Facteurs d'écarts
- Objectifs par technicien

## Dépendances
- `project`, `hr_timesheet`, `mail`
