# VATCross

File What You Verified

## The problem

VAT returns are filed with unexplained gaps between the report and the journal entries because the reconciliation lives in spreadsheets and emails instead of a dated, reviewable record.

## The solution

Cross-check the VAT report against the underlying journal entries and explain the differences before filing.

## Main features

- A VAT cross-check per period with a clear filing status.
- One line per VAT box with reported and ledger amounts.
- The difference computed and stored on every line.
- A justification and a reviewed flag on each difference.
- One screen for every box that still differs or awaits review.
- The check closes only when every line is reviewed.
- A closing date stamped on the verified check.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **VAT Cross Check** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
