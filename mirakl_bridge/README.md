# Mirakl Bridge

Import Mirakl marketplace orders

## The problem

Mirakl marketplace orders and shipment updates are handled outside Odoo, leading to delays and fulfillment errors.

## The solution

Connect to Mirakl marketplaces to import orders, track shipments and synchronize order status with Odoo.

## Main features

- Mirakl connection profile (shop, environment, credentials ref).
- Marketplace order records with customer/amount details.
- Order line summary and fulfillment status.
- Accept/ship/invoice/close/reset actions.
- Shipment tracking fields and sync logs.
- Error tracking and payload snapshots.
- No external Python dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Mirakl Bridge** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
