# Performance des Collecteurs (collector_performance_report)

Rapport de performance de recouvrement : recouvré par collecteur, délai moyen, taux de promesse tenue et comparaison externe/interne.

## Problème
Les recouvrements menés par plusieurs personnes (interne/agence) ne sont pas comparés : qui récupère quoi, à quel coût.

## Fonctionnalités
- Recouvré par collecteur
- Délai moyen de récupération
- Taux de promesses tenues
- Comparaison interne/externe
- Rapport mensuel

## Dépendances
- `account`, `mail`
