# Amortissements Dérogatoires (fiscal_depreciation_split)

Double circuit d'amortissements : comptable + fiscal paramétrable, calcul de la différence (dérogatoire/reversement), état fiscal par exercice.

## Problème
La différence entre amortissement fiscal et comptable (dérogatoire) est calculée à la main pour la liasse fiscale.

## Fonctionnalités
- Circuit fiscal paramétrable
- Calcul dérogatoire/reversement
- État fiscal par exercice
- Écritures optionnelles
- Journal d'audit

## Dépendances
- `account`, `mail`
