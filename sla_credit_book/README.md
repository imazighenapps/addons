# Crédits SLA (sla_credit_book)

Moteur de crédits SLA : barème par type de manquement, calcul automatique, avoir client proposé et suivi des crédits émis.

## Problème
Les contrats prévoient des crédits/remboursements quand les SLA sont manqués : calculés à la main, ils sont souvent oubliés.

## Fonctionnalités
- Barème par manquement
- Calcul automatique
- Avoir proposé
- Suivi des crédits
- Rapport d'impact

## Dépendances
- `helpdesk`, `account`, `mail`
