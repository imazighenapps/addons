# TVA Non Déductible (vat_nd_flags)

Règles de non-déductibilité : règles par catégorie de produit/fournisseur, application automatique aux factures, ventilation comptable distincte et justification.

## Problème
Certaines dépenses (carburant, cadeaux, véhicules) ont une TVA non déductible variable par pays ; les comptables la retrouvent à la main.

## Fonctionnalités
- Règles par catégorie/fournisseur
- Application aux factures fournisseurs
- Ventilation TVA ND distincte
- Justification attachée
- Rapport de contrôle annuel

## Dépendances
- `account`, `mail`
