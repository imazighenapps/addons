# Qualification d'Équipements IQ/OQ/PQ (quality_equipment_qualification)

Registre de qualification : phases IQ/OQ/PQ avec protocoles, tests exécutés, critères, conclusions et requalification planifiée après changement.

## Problème
Les équipements critiques (pharma, stérilisation) exigent des qualifications IQ/OQ/PQ documentées : les protocoles et rapports restent en fichiers.

## Fonctionnalités
- Phases IQ/OQ/PQ par équipement
- Tests avec critères et conclusions
- Requalification après changement
- Planification des échéances
- Dossier d'audit par équipement

## Dépendances
- `quality`, `maintenance`, `mail`
