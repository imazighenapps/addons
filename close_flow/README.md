# CloseFlow - Month-End Close Checklist

## The problem

The monthly close lives in an Excel checklist. Tasks are forgotten, nobody knows who is late, there is no proof attached, and the file is still editable after the accounts are signed off.

## The solution

Run the monthly close with a reusable checklist: owners, deadlines, dependencies, evidence, progress dashboard and a locked audit trail.

## Main features

- Reusable close template.
- One-click period generation.
- Owners and deadlines per task.
- Task dependencies.
- Mandatory evidence attachment.
- Progress dashboard.
- Period locking.
- Manager-only unlock.
- Full audit trail.
- Multi-company.

## Installation

1. Install the module from the Apps list.
2. Open the **Close Flow** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
