# Souhaits de Mobilité (hr_mobility_preferences)

Registre de mobilité : souhaits déclarés (métier, site, horizon), compétences visées, correspondance aux postes ouverts et entretien de mobilité tracé.

## Problème
Les salariés intéressés par un changement de poste ne le disent qu'à l'oral : l'entreprise perd ses talents internes vers l'extérieur.

## Fonctionnalités
- Souhaits déclarés par salarié
- Compétences visées
- Correspondance aux postes ouverts
- Entretien de mobilité tracé
- Statistiques de mobilité interne

## Dépendances
- `hr`, `recruitment`, `mail`
