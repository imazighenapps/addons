# IncidentDesk

Every Incident Corrected For Real

## The problem

Incidents land in a mailbox or a spreadsheet with no owner, the corrective actions are promised in meetings and never tracked, and the same accident repeats three times before somebody can prove it was never really closed.

## The solution

Log workplace, property and environment incidents with a severity, drive the investigation in Odoo and close each case only when every corrective action is done.

## Main features

- Incidents typed as injury, near miss, property, environment or other.
- Four severity levels, from low to critical, with a location.
- Draft, investigating and closed states with a chatter trail.
- Corrective and preventive actions with an owner and a due date.
- Closing an incident is refused while corrective actions are open.
- Open action counter computed live on each incident.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Incident Desk** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
