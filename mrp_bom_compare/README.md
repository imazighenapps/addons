# Comparateur de Nomenclatures (mrp_bom_compare)

Comparateur côte à côte : composants, quantités, opérations et coûts diffèrents surlignés, export du rapport de comparaison pour revue.

## Problème
Vérifier ce qui a changé entre deux versions d'une nomenclature ou entre deux variantes se fait en relisant ligne par ligne.

## Fonctionnalités
- Comparaison de deux BOMs ou variantes
- Différences surlignées composants et opérations
- Impact coût affiché
- Export PDF du comparatif
- Lien vers les MOs utilisant chaque version

## Dépendances
- `mrp`, `mail`
