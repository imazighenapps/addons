# ContractExpiry

Contract and Expiry Tracker

## The problem

SMBs track contract expiry dates in spreadsheets and miss renewals or notice periods because there is no shared register.

## The solution

Register agreements with partners, track end and notice dates, surface upcoming expiries and follow renewal or closure states.

## Main features

- Contract register with partner, reference and key dates.
- Responsible owner, type and notes.
- Draft, active, expiring, renewed and closed states.
- Computed days to expiry and expiring-soon visibility.
- List, form and search views with state and date filters.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Contracts** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
