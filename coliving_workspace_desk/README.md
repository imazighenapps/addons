# Tiers-Lieu & Coworking (coliving_workspace_desk)

Gestion de tiers-lieu : abonnements par formule (poste fixe, flexible, casier), accès journalisés, réservations de salles et facturation mensuelle.

## Problème
Les tiers-lieux gèrent abonnements (postes, casiers, salles), accès et consommables sur des tableurs maison.

## Fonctionnalités
- Formules d'abonnement
- Postes et casiers assignés
- Accès journalisés
- Réservations de salles
- Facturation mensuelle

## Dépendances
- `sale`, `account`, `mail`
