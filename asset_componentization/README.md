# Composants d'Immobilisations (asset_componentization)

Décomposition en composants : arbre parent/enfants, amortissements par composant, remplacement de composant avec sortie du remplacé.

## Problème
Les immobilisations à composants (bâtiment+toiture, machine+moteur) exigent des amortissements distincts par composant.

## Fonctionnalités
- Arbre de composants
- Amortissement par composant
- Remplacement tracé
- Recalcul de valeur nette
- Écritures automatiques

## Dépendances
- `account`, `mail`
