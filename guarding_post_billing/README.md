# Facturation du Gardiennage (guarding_post_billing)

Postes par site avec barèmes horaires (nuit, dimanche, jours fériés), facturation des heures planifiées corrigées des heures réelles, contrôle des écarts.

## Problème
Les sociétés de gardiennage facturent des heures prévues alors que le réel diffère : litiges constants sur les postes de nuit.

## Fonctionnalités
- Postes par site avec barèmes
- Heures planifiées vs réelles
- Majorités nuit/férié appliquées
- Écarts justifiés
- Facturation mensuelle par site

## Dépendances
- `sale`, `account`, `hr`, `mail`
