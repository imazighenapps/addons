# Retenciones Espagne (es_retencion_desk)

Registre retenciones ES : calcul par régime, modèle 111 trimestriel, récapitulatif 190 annuel et journal de conformité.

## Problème
Les retenciones IRPF espagnoles (modèle 111/190) sont calculées et déclarées manuellement.

## Fonctionnalités
- Calcul par régime
- Modèle 111
- Récap 190
- Journal de conformité

## Dépendances
- `account`, `mail`
