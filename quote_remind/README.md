# QuotePing

Deals Never Die Quietly

## The problem

Quotations are sent without a follow-up plan: nobody knows which deals are overdue for a reminder, reminders are counted nowhere and the salesperson discovers the loss the day the customer already bought elsewhere.

## The solution

Watch quotations age day by day and remind your salespeople before a deal quietly dies in the pipeline.

## Main features

- One tracker per quotation with customer and salesperson.
- A reminder plan: interval in days and maximum attempts.
- Reminders stamped with date and channel.
- A due flag computed from the reminder plan.
- One click to remind: the log counts itself.
- The maximum number of attempts is enforced.
- Won and lost close the tracker and keep the evidence.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Quote Ping** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
