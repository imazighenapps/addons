# PayAdvance

Advances With A Plan

## The problem

Salary advances are approved informally, repayments are scattered across payslips and nobody can state the remaining balance with confidence.

## The solution

Handle salary advances with an approved request, a repayment schedule and the balance always visible.

## Main features

- A salary advance request per employee with amount and approval date.
- A repayment schedule with dated installments per request.
- Paid installments and a stored remaining balance on every request.
- A workflow to submit, approve, refuse and close repaid advances.
- The request refuses a repayment plan above the approved amount.
- One screen to see balances and repayment progress at a glance.
- Employee-linked requests for HR payroll follow-up.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **PayAdvance** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
