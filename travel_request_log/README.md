# TravelRequestLog

Employee Travel Request Register

## The problem

Travel requests managed informally lack visibility and approval traceability.

## The solution

Record employee travel requests with dates, destination, purpose, estimated cost and approval states.

## Main features

- Travel requests with employee, destination and dates.
- Purpose, estimated cost and notes.
- Approver and approval tracking.
- Draft, submitted, approved, completed and rejected states.
- History of travel requests per employee.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Travel Requests** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
