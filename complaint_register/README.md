# ComplaintLog

Complaint and Grievance Register

## The problem

Complaints handled informally lack central tracking, ownership and consistent resolution history.

## The solution

Log complaints with source, category, severity and description, assign responsibility, track investigation and resolution states in a company-safe register.

## Main features

- Complaint records with source, category and severity.
- Responsible user and resolution details.
- New, in progress, resolved, closed and cancelled states.
- Workflow actions for investigation and resolution.
- Search and group by category, severity and state.
- Chatter tracking on cases.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Complaints** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
