# DockAppointmentLog

Loading Dock Appointment Register

## The problem

Dock slots booked on whiteboards cause overlaps and waiting trucks.

## The solution

Schedule and track carrier arrivals at loading docks with direction, reference and pallet count.

## Main features

- Appointments with date/time, dock and direction.
- Carrier, vehicle plate and shipment reference.
- Pallet count and responsible user.
- Draft, confirmed, done and cancelled states.
- Search and grouping by dock, direction and state.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Dock Appointments** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
