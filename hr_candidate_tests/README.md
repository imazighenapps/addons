# Cas Pratiques des Candidats (hr_candidate_tests)

Registre d'essais candidats : exercice assigné avec consigne, réponse reçue, notation structurée par critères, comparaison entre candidats d'un même poste.

## Problème
Les essais techniques (cas, exercices, mises en situation) sont notés dans des emails : réponses perdues, notes incomparables entre candidats.

## Fonctionnalités
- Exercices assignés avec consigne
- Notation par critères
- Comparaison intra-poste
- Délais de rendu surveillés
- Archivage avec la candidature

## Dépendances
- `recruitment`, `mail`
