# Dispatch Dépannage (tow_dispatch_board)

Board de dispatch : appel avec véhicule et position, remorquer assigné, fenêtre d'intervention, suite (atelier ou remis) tracée.

## Problème
Les appels de dépannage arrivent au téléphone : qui part où, pour qui, et le retour atelier n'est jamais tracé.

## Fonctionnalités
- Appels avec véhicule et position
- Assignation remorquer/plateau
- Fenêtre d'intervention
- Chaînage vers l'atelier
- Historique par client et par véhicule

## Dépendances
- `sale`, `crm`, `mail`
