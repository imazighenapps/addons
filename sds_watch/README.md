# SDSWatch

Sheets Current Or Flagged

## The problem

Safety data sheets are stored as loose files with handwritten dates, so expired or missing sheets go unnoticed until an inspection or an incident exposes the gap.

## The solution

Keep the current safety data sheet of every chemical product valid and dated, and flag the lapsed ones.

## Main features

- One product register with supplier, hazard class and current version.
- Current sheet issue and expiry dates stored on every product.
- Lapsed and missing flags computed and stored for easy filtering.
- A version history with issue date, expiry date and reference.
- Marking a version current refreshes the product dates.
- Counters for version count stored on the product.
- A sheet whose expiry comes before its issue is refused for you.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **SDS Watch** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
