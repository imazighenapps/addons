# AllergenDesk

Allergens, Declared

## The problem

Allergen declarations are rebuilt from memory and spreadsheets, so recipe changes create undeclared risks and auditors cannot be shown a consistent matrix per product.

## The solution

Build the allergen matrix of your recipes and the cross-contact rules auditors ask you to demonstrate.

## Main features

- One recipe record per product with line and declaration reference.
- Allergen lines with allergen, presence type and source note.
- Counters for present and cross-contact allergens stored on the recipe.
- Draft, validated and archived states with an audit trail.
- Validating the recipe freezes the declaration from silent edits.
- Duplicate allergen entries on the same recipe are refused for you.
- A recipe without any allergen line cannot be validated.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Allergen Desk** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
