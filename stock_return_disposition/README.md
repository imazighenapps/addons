# Seconde Vie des Retours (stock_return_disposition)

Moteur de disposition des retours : règles de destination par catégorie/état/âge, file de tri avec affectation en un clic, valeur récupérée mesurée et tracée.

## Problème
Les retours validés s'entassent sans décision : restock, outlet, don ou destruction se décident au doigt mouillé, sans mesure de la valeur récupérée.

## Fonctionnalités
- Règles de destination par catégorie/état
- File de tri et affectation
- Restock/outlet/don/destruction
- Valeur récupérée mesurée
- Historique par canal

## Dépendances
- `stock`, `account`, `mail`
