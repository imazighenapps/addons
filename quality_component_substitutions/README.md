# Substitutions Composants Approuvées (quality_component_substitutions)

Registre de substitutions : équivalences par composant (ou selon caractéristiques), statut d'approbation qualité, périodes d'application et trace sur les lots produits.

## Problème
En pénurie, les équipes substituent des composants informellement : les décisions se perdent et la conformité des produits n'est plus prouvable.

## Fonctionnalités
- Equivalences par composant
- Approbation qualité tracée
- Application aux MOs concernées
- Période de substitution suivie
- Trace sur les lots produits

## Dépendances
- `quality`, `mrp`, `stock`, `mail`
