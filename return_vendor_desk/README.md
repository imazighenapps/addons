# VendorReturn

Rejected Goods, Credits Back

## The problem

Rejected goods go back to suppliers without a shared trace, transport details sit in emails and expected credit notes are forgotten before the money comes back.

## The solution

Return rejected goods to your supplier with the trace, the transport and the credit note you expect back.

## Main features

- A return case per supplier with reference and company.
- Return lines with product, quantity and rejection reason.
- Transport trace kept on the case for every parcel.
- The expected credit amount recorded and followed to receipt.
- A credits-awaited screen for returns still waiting for money.
- Decision states from draft to sent, credited and closed.
- A received credit requires a positive expected amount.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Vendor Returns** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
