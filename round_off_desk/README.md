# RoundOff

One Cent, Cleanly Gone

## The problem

One-cent and rounding differences clutter open balances and block reconciliations because booking a clean, controlled write-off is harder than leaving the penny behind.

## The solution

Absorb the one-cent and rounding differences between invoices, payments and statements with clean write-offs.

## Main features

- Write-off rules with a maximum amount and a reason.
- Small-difference write-offs with a source reference.
- A posted state that records the date the amount was cleared.
- Amounts above the rule limit refused for you.
- One cleared queue for every absorbed difference.
- A rule reference kept on every posted write-off.
- Draft write-offs that can be reviewed before posting.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Round Off** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
