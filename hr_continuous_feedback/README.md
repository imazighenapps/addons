# Feedback Continu (hr_continuous_feedback)

Feedback léger : kudos et retours constructifs entre collègues, visibilité d'équipe, agrégation dans le dossier d'évaluation, option anonyme pour les retours sensibles.

## Problème
Les félicitations et signalements d'équipe restent verbaux : rien n'est capitalisé et les comportements remarquables passent inaperçus.

## Fonctionnalités
- Kudos et retours entre collègues
- Vue d'équipe
- Agrégation dans l'évaluation
- Option anonyme
- Historique par personne

## Dépendances
- `hr`, `mail`
