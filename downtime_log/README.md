# Downtime

Availability, Measured

## The problem

Machine stops are recorded informally, so teams cannot measure availability, MTBF and MTTR reliably or identify the reasons that cause repeated downtime.

## The solution

Log every machine stop with its reason and compute the availability, MTBF and MTTR the plant really runs at.

## Main features

- Machine register with planned operating minutes baseline.
- Stop events with reason, timing and computed duration.
- Open and closed stop workflow with close action.
- Stored counters for stop count and total downtime minutes.
- Computed MTTR and availability indicators per machine.
- Timeline views with filters by machine, state and reason.
- Multi-company isolation for separate production sites.

## Installation

1. Install the module from the Apps list.
2. Open the **Downtime** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
