# Verrouillage après Validation (record_lock)

Verrou automatique : règles par modèle (après validation, après date, après facturation), exception justifiée tracée et journal.

## Problème
Les enregistrements validés (factures, BL, fiches) restent modifiables par erreur : des écarts inexpliqués.

## Fonctionnalités
- Règles par modèle
- Exceptions justifiées
- Journal des déverrouillages
- Alertes
- Statistiques

## Dépendances
- `base`, `mail`
