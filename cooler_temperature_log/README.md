# CoolerTemperatureLog

Cold Storage Temperature Register

## The problem

Cold storage readings on paper hide breaches across 3 to 40 units.

## The solution

Record cold storage temperatures with target range, automatic breach flag and states.

## Main features

- Readings with cooler name and location.
- Reading date/time and measured temperature.
- Configurable target minimum and maximum.
- Automatic in-range flag.
- Draft, recorded, breach and cancelled states.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Cold Storage** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
