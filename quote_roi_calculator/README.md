# Calculateur d'Économies Client (quote_roi_calculator)

Calculateur d'économies sur le devis : paramètres du client, formule de gain par produit ou solution, bloc ROI dans le PDF et comparaison avec coût de l'inaction.

## Problème
Le devis annonce un prix mais jamais l'économie : le client achète une solution sans voir son ROI chiffré, et la comparaison se fait sur le prix seul.

## Fonctionnalités
- Formules de gain par produit
- Paramètres client saisis
- Bloc ROI dans le PDF
- Comparaison coût de l'inaction
- Historique des promesses de gain

## Dépendances
- `sale`, `product`, `mail`
