# Budget Client du Projet (client_budget_tracker)

Suivi de l'enveloppe client : montant autorisé, engagé (temps+matériel+factures), reste à facturer et alerte avant dépassement.

## Problème
Le client fixe une enveloppe (PO client) : l'équipe la dépasse sans le savoir, la facture est refusée.

## Fonctionnalités
- Enveloppe autorisée
- Engagé consolidé
- Reste à facturer
- Alerte de seuil
- Validation d'extension

## Dépendances
- `project`, `sale`, `mail`
