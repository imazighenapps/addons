# PestControlLog

Pest Control Intervention Register

## The problem

Pest control intervention history is scattered, making audits and follow-up difficult.

## The solution

Record pest control visits with provider, area, findings, treatment notes and states to keep a traceable intervention history.

## Main features

- Intervention records with date, provider, area and responsible person.
- Pest type, findings and treatment/products notes.
- Scheduled/completed dates and follow-up notes.
- Draft, scheduled, done and cancelled states.
- Intervention history per site/area.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Pest Control** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
