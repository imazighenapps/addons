# CylinderDesk

Cylinders Billed Fairly

## The problem

Rented gas cylinders are counted from memory: empties are not returned, the supplier bill never matches the yard and rental charges run on cylinders that already left.

## The solution

Track every rented gas cylinder received, emptied and returned, so the supplier bill matches reality.

## Main features

- A register of cylinder types with gas, capacity and rental rate.
- Custody movements with supplier, received and returned quantities.
- The on-site balance computed and stored on every custody line.
- A return date stamped when the cylinders leave the yard.
- One open-custody screen for everything still billable on site.
- A return quantity above what was received is refused for you.
- A negative received quantity is refused for you.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Cylinders** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
