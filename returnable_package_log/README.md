# ReturnablePackageLog

Returnable Packaging Movement Register

## The problem

Packaging lent to partners is lost and deposits are not recovered.

## The solution

Track pallets, crates and containers sent to partners and returned, with due dates and deposits.

## Main features

- Movements with partner, packaging type and quantity.
- Outbound and inbound movement direction.
- Movement, due and return dates.
- Deposit amount at risk per movement.
- Draft, sent, returned, lost and cancelled states.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Returnable Packaging** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
