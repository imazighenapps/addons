# SiteAudit

Templates That Score A Site

## The problem

Site inspections are scored once in a spreadsheet and never rebuilt: two inspectors do not fill the same template, the points are not weighted the same way, and nobody can compare two visits of the same site or prove the improvement after the fixes.

## The solution

Build reusable site inspection templates with weighted points, run an audit from a template in one click and let the score, the failed points and the trend do the talking.

## Main features

- Reusable inspection templates with scored points and weights.
- An audit is instantiated from a template in one click.
- Each point is scored against its weight in the form.
- The global score of the audit is computed and stored.
- Closing the audit is refused while points stay unscored.
- A failed-points screen gathers everything below the threshold.
- Counts of points and failed points live on the audit.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Site Audits** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
