# Démurrage Client (stock_storage_demurrage)

Facturation de détention : délai gratuit par client, calcul journalier au-delà, facturation périodique automatique et journal des relances.

## Problème
Les clients qui ne retirent pas ou ne réceptionnent pas leurs marchandises occupent l'entrepôt gratuitement : la facturation de détention n'existe pas dans le flux.

## Fonctionnalités
- Délai gratuit par client
- Calcul journalier au-delà
- Facturation périodique
- Journal des relances
- Analyse de l'occupation par client

## Dépendances
- `stock`, `sale`, `account`, `mail`
