# Couture Sur Mesure (tailoring_measure_files)

Dossier client sur mesure : relevé de mesures versionné, stages d'essayage tracés, retouches consignées et livraison finalisée.

## Problème
Le tailleur consigne mesures, essayages et retouches sur des fiches qui se perdent entre deux rendez-vous.

## Fonctionnalités
- Mesures versionnées par client
- Stages d'essayage tracés
- Retouches consignées
- Livraison finalisée
- Historique de commandes

## Dépendances
- `sale`, `stock`, `mail`
