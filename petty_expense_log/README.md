# PettyExpenseLog

Petty Expense Request Register

## The problem

Petty expenses tracked informally lack approval and reimbursement traceability.

## The solution

Record petty expense requests with amount, purpose, approval and reimbursement states for simple tracking.

## Main features

- Expense requests with requester, date and amount.
- Category/purpose and notes.
- Approver and reimbursement tracking.
- Draft, submitted, approved, reimbursed and rejected states.
- History of petty expense requests.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Petty Expenses** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
