# UniformTrack

Employee Uniform and PPE Allocation

## The problem

Uniform and PPE allocations tracked informally lack per-employee history and status visibility.

## The solution

Track uniform and PPE items allocated to employees with quantity, issue date and status, record returns or replacements, and keep a company-safe allocation history.

## Main features

- Uniform/PPE item catalogue.
- Allocations per employee with quantity and issue date.
- Issued, returned and replaced states.
- Actions to return or replace allocations.
- Search and group by employee, item and state.
- Chatter tracking on allocations.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Uniform Allocation** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
