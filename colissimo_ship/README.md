# Colissimo Shipping

Ship with Colissimo from Odoo

## The problem

Colissimo labels and tracking are managed outside Odoo, causing manual work and limited shipment visibility.

## The solution

Prepare Colissimo parcels, generate label records and tracking numbers, and follow delivery statuses from your pickings.

## Main features

- Connection profile with contract and credential reference.
- Shipment records linked to pickings/partners.
- Service options (home, pickup, signature).
- Label and tracking references with lifecycle states.
- Prepare/label/ship/deliver/reset actions.
- Shipment event log and notes.
- Company-aware access.
- No external Python dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Colissimo Shipping** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
