# Recueil de Signatures RH (hr_policy_signoffs)

Recueil de signatures : diffusion par salarié, accusés datés, relances aux non-acquittés, registre complet pour les audits et le contentieux.

## Problème
Diffuser le règlement intérieur, les chartes (informatique, sécurité, anti-harcèlement) et prouver la lecture de chacun se fait par email : preuves non collectées.

## Fonctionnalités
- Diffusion par document et salarié
- Accusés datés
- Relances aux non-acquittés
- Registre d'audits
- Historique par version de document

## Dépendances
- `hr`, `mail`
