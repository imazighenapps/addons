# OvertimeLog

Employee Overtime Requests and Approval

## The problem

Overtime requests handled informally lack a consistent approval trail, making hours hard to validate and reconcile.

## The solution

Record employee overtime requests with date, hours and reason, run a submit/approve/refuse workflow, and report overtime by employee and period in a company-safe register.

## Main features

- Overtime requests with employee, date, hours and reason.
- Draft, submitted, approved and refused states.
- Manager approval and refusal actions.
- Optional overtime type and notes.
- Search and group by employee, state and period.
- Chatter tracking on requests.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Overtime** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
