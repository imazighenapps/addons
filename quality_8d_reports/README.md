# Rapports 8D Structurés (quality_8d_reports)

Rapports 8D structurés : équipe, description, containment, causes (5 Pourquoi, Ishikawa), actions, validation d'efficacité, export PDF client avec délais surveillés.

## Problème
Les clients automobiles demandent des 8D complets sous délai : les équipes assemblent les étapes dans Word sans cohérence ni archivage.

## Fonctionnalités
- Étapes D1 à D8 guidées
- Outils intégrés (5P, Ishikawa)
- Délais de réponse surveillés
- Export PDF conforme client
- Archivage lié à la réclamation

## Dépendances
- `quality`, `sale`, `mail`
