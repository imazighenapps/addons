# DriverHoursLog

Driver Duty and Driving Hours Register

## The problem

Fleets with 5 to 60 drivers check 9-hour driving limits after the fact.

## The solution

Record daily driver duty with driving and break minutes, limit and automatic exceedance flag.

## Main features

- Duty records with driver, vehicle and date.
- Driving and break minutes.
- Configurable daily limit with automatic exceedance flag.
- Responsible user and notes.
- Draft, validated, alert and cancelled states.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Driver Hours** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
