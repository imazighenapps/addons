# PriceShift

One Date, Every Price

## The problem

A price increase is applied product by product with no single record of the decision: salespeople keep quoting the old price, rounding is invented at each retyping and nobody can prove when a customer changed from how much to how much.

## The solution

Decide the next price increase once, schedule its effective date and see exactly when each customer moved.

## Main features

- One change record for the increase or the decrease, in percent.
- One line per customer with its current and computed new price.
- One effective date decided once and visible on the record.
- Scheduling locks the rule and the percentage.
- Applying stamps the date and freezes every line.
- Cancelling keeps the full trace of the decision.
- The applied screen lists exactly when each customer moved.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Price Changes** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
