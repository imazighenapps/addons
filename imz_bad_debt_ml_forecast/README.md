# Prévision d'Impayés (bad_debt_ml_forecast)

Prévision d'impayés : modèle statistique simple sur historique (par bucket/client), projection mensuelle de créances douteuses, impact trésorerie et fiabilité mesurée.

## Problème
Prévoir l'impayé du trimestre (impact trésorerie) se fait au doigt mouillé en fin de mois.

## Fonctionnalités
- Modèle statistique sur historique
- Projection mensuelle
- Impact trésorerie
- Mesure de fiabilité
- Comparaison vs réalisé

## Dépendances
- `account`, `mail`
