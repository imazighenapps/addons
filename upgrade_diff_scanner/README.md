# Diff de Mise à Niveau (upgrade_diff_scanner)

Scanner de mise à niveau : inventaire des modules personnalisés, détection des appels d'API obsolètes ou renommés, rapport de charge de migration.

## Problème
Passer d'une version Odoo à la suivante exige un inventaire des personnalisations et des API obsolètes que personne n'a le temps de dresser.

## Fonctionnalités
- Inventaire des modules personnalisés
- API obsolètes détectées
- Rapport de charge
- Évolution entre scans
- Planification de la migration

## Dépendances
- `base`, `mail`
