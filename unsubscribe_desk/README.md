# Gestion des Désinscriptions (unsubscribe_desk)

Registre de désinscriptions : traitement des réponses, liste de suppression appliquée à tous les canaux, preuve et audit.

## Problème
Les désinscriptions (clic, réponse, spam) ne remontent pas de manière fiable : des contacts continuent d'être contactés.

## Fonctionnalités
- Traitement des réponses
- Liste de suppression
- Application à tous les canaux
- Preuve datée
- Audit

## Dépendances
- `base`, `mail`
