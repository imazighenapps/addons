# Déclarations Matériaux (IMDS) (quality_material_declarations)

Registre de déclarations matériaux : IMDS/REACH/ROS par composant et fournisseur, numéros, statuts, validité, alertes de manques avant lancements série.

## Problème
Les donneurs d'ordre auto exigent les fiches IMDS de chaque composant : numéros, statuts, validité tenus dans des emails éparpillés.

## Fonctionnalités
- Déclaration par composant et fournisseur
- Numéros et statuts tracés
- Alerte sur les manques avant lancement
- Validité et renouvellements suivis
- Rapport de conformité par projet

## Dépendances
- `quality`, `purchase`, `mail`
