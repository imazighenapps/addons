# Surveillance des Connexions (login_watch)

Détection d'anomalies de connexion : motifs (heure, IP, échecs), alertes, blocage temporaire et journal d'investigation.

## Problème
Les connexions anormales (heure inhabituelle, IP étrangère, échecs répétés) ne sont détectées par personne.

## Fonctionnalités
- Motifs d'anomalie
- Alertes
- Blocage temporaire
- Journal d'investigation
- Rapport périodique

## Dépendances
- `base`, `mail`
