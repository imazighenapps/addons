# Trophées Saisonniers (seasonal_trophy_board)

Tableaux de trophées saisonniers : périodes paramétrées, catégories de trophées, cérémonies de remise tracées et historique des lauréats.

## Problème
Les classements mensuels d'équipe sont faits à la main puis oubliés : la reconnaissance ne ritualise pas les saisons.

## Fonctionnalités
- Périodes paramétrées
- Catégories de trophées
- Remises tracées
- Historique des lauréats
- Affichages de campagne

## Dépendances
- `base`, `mail`
