# PhotoGuard

A Catalog Ready To Show

## The problem

Product catalogs ship with missing or weak pictures because nobody keeps a clear, actionable list of the photo gaps that must be fixed before publishing.

## The solution

Find every product that ships without a proper picture and fix the catalog before the webstore does it for you.

## Main features

- Photo audits with a target area, owner and due date.
- Issue lines per product with missing, weak or outdated status.
- A simple issue workflow from open to fixed.
- Open and fixed counters computed and stored on each audit.
- Audits that can be completed only when every issue is fixed.
- Fixing an issue twice is refused for you.
- A quality score computed from the fixed issues.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Photo Guard** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
