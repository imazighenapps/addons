# Bibliothèque de Gammes Réutilisables (mrp_routing_templates)

Bibliothèque de gammes types : modèles d'opérations paramétrés (temps, poste, instructions) appliqués en un clic à un produit, avec variables ajustables.

## Problème
Les gammes d'opérations se recopient à la main d'un produit à l'autre : erreurs de temps, d'outils et de consignes.

## Fonctionnalités
- Gammes types réutilisables
- Variables par instance (taille, matière)
- Application en un clic
- Mise à jour en cascade optionnelle
- Historique des usages

## Dépendances
- `mrp`, `mail`
