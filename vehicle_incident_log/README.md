# VehicleIncident

Company Vehicle Incident Log

## The problem

Vehicle incidents reported informally lack consistent details and follow-up tracking per vehicle.

## The solution

Log company vehicle incidents with vehicle, driver, date and damage details, track follow-up through workflow states, and keep a company-safe incident history.

## Main features

- Incident records linked to vehicle and driver.
- Damage, description and insurance/follow-up fields.
- Draft, reported, in progress and closed states.
- Actions to report, progress and close incidents.
- Search and group by vehicle, driver and state.
- Chatter tracking on incidents.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Vehicle Incidents** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
