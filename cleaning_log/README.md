# CleanLog

Cleaning and Sanitation Task Log

## The problem

Cleaning activities recorded on paper lack a central, auditable log of completion and missed tasks.

## The solution

Log cleaning and sanitation tasks by area with scheduled and completion dates, responsible person and status, and keep a company-safe completion record.

## Main features

- Task records with area, description and responsible.
- Planned and completed date tracking.
- Planned, done, missed and cancelled states.
- Actions to mark done or missed.
- Search and group by area, state and period.
- Chatter tracking on tasks.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Cleaning Log** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
