# RentalLite - Equipment Rental for Odoo Community

## The problem

Odoo Rental is Enterprise only. Small rental businesses track availability, deposits and returns in Excel, double-book equipment, and forget to invoice the damage.

## The solution

Rent equipment with availability control, deposit, contract, return inspection and invoicing, without the Enterprise Rental app.

## Main features

- Rental products with daily price and owned quantity.
- Availability control against overlapping contracts.
- Contract with automatic day count and total.
- Refundable deposit and damage fee.
- Return inspection and deposit refund.
- One-click invoice.
- Overdue detection.
- Multi-company and multi-currency.

## Installation

1. Install the module from the Apps list.
2. Open the **Rental** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
