# File d'Attente des Mails (mail_spool_triage)

Triage de la file sortante : échecs classés par motif, renvoi groupé, liste de suppression et vue des mails bloqués.

## Problème
Les mails qui partent en échec (SMTP, rejet) s'accumulent sans triage : les clients ne reçoivent rien et personne ne le sait.

## Fonctionnalités
- File sortante avec échecs classés
- Renvoi groupé
- Liste de suppression
- Vue des mails bloqués
- Journal des interventions

## Dépendances
- `mail`
