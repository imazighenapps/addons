# AssetDisposalLog

Asset Disposal Authorization Register

## The problem

Disposal approvals by email leave no reason or value trail.

## The solution

Document asset disposal requests with method, values, requester, approver and tracked states.

## Main features

- Disposal records with asset reference and category.
- Disposal method: sale, scrap, donation, return.
- Disposal date, acquisition value and residual value.
- Requester, approver and reason.
- Draft, submitted, approved, disposed and cancelled states.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Asset Disposals** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
