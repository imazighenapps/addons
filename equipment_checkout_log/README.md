# EquipmentCheckoutLog

Equipment Checkout Register

## The problem

Informal equipment checkouts leave availability and returns unclear.

## The solution

Record shared equipment checkouts and returns with borrower, dates, condition notes and tracked states.

## Main features

- Checkout records with equipment, borrower and dates.
- Expected and actual return dates.
- Responsible issuer and condition notes.
- Draft, checked out, returned and cancelled states.
- Checkout history per equipment item.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Equipment Checkouts** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
