# Programme Annuel d'Audits Fournisseurs (supplier_audit_program)

Programme annuel : fournisseurs à auditer par criticité, planification des visites, grille d'évaluation remplie sur place, constats avec actions et ré-audit planifié.

## Problème
Les visites d'audit chez les fournisseurs sont décidées au fil de l'eau : fournisseurs critiques jamais audités, résultats non consolidés.

## Fonctionnalités
- Plan annuel par criticité
- Visites planifiées avec grille
- Constats et actions
- Ré-audit planifié
- Historique par fournisseur

## Dépendances
- `purchase`, `mail`
