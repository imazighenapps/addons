# Provisions Retraite (pension_provision_desk)

Registre d'engagements retraite : entrée des valeurs actuarielles, provision par exercice, mouvements (service, intérêts, décaissements) et dossier d'audit.

## Problème
Les engagements retraite (Article 39, plans internes) sont valorisés par l'actuaire puis provisionnés à la main.

## Fonctionnalités
- Valeurs actuarielles importées
- Provision par exercice
- Mouvements tracés
- Dossier d'audit
- Historique

## Dépendances
- `account`, `mail`
