# Plan de Recontact Périodique (periodic_recontact_plan)

Plan de recontact : règles de fréquence par segment de client, file des recontacts dus avec historique du dernier contact et mesure du réveil (commandes après recontact).

## Problème
Les clients sans contrat ni abonnement tombent du radar entre deux commandes : personne n'est prévenu qu'un client n'a pas été recontacté depuis 6 mois.

## Fonctionnalités
- Fréquence par segment de client
- File des recontacts dus
- Historique du dernier contact
- Mesure du réveil après recontact
- Statistique de couverture du portefeuille

## Dépendances
- `crm`, `sale`, `mail`
