# AuditBinder

The Binder Before They Ask

## The problem

Audit evidence is scattered across ledgers, mailboxes and spreadsheets, so assembling the pack for each period is a repeated scramble with no clear view of what is missing.

## The solution

Assemble the audit evidence pack per account and period: entries, documents and reconciliations in one bind.

## Main features

- One audit binder per period with a clear preparation status.
- Sections per account or topic inside each binder.
- Evidence items with a reference and a description per section.
- A ready flag on every item and missing counters on the binder.
- The binder closes only when every evidence item is ready.
- One screen listing every item still missing.
- Item and missing counts stored on each binder for quick review.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Audit Binder** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
