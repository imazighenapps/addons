# AssetPro - Fixed Asset Register and Depreciation

## The problem

In Odoo Community there is no fixed asset register: depreciation is tracked in spreadsheets, net book value is always wrong, and disposals are impossible to audit.

## The solution

Keep a fixed asset register, generate linear or declining depreciation schedules, post periods and record disposals with gain or loss.

## Main features

- Fixed asset register with categories.
- Linear and declining balance methods.
- Automatic monthly depreciation schedule.
- One-click posting of due periods.
- Net book value and remaining amount.
- Disposal with gain or loss.
- Reset and correction workflow.
- Multi-company and multi-currency.

## Installation

1. Install the module from the Apps list.
2. Open the **Assets** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
