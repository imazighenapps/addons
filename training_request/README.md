# TrainingRequest

Employee Training Request and Approval

## The problem

Training requests handled informally lack an approval trail and consolidated visibility.

## The solution

Submit and approve employee training requests with topic, provider and estimated cost, track status through review and completion in a company-safe register.

## Main features

- Training requests with employee, topic and provider.
- Estimated cost, dates and justification.
- Draft, submitted, approved, refused and done states.
- Approval and refusal actions.
- Search and group by employee, state and period.
- Chatter tracking on requests.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Training Requests** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
