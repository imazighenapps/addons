# VoucherBook

Vouchers Earned To The Day

## The problem

Meal voucher counts are rebuilt in spreadsheets every month, with no auditable link between worked days and the allocation handed to payroll.

## The solution

Compute the meal vouchers each employee earned per working day and hand payroll a clean allocation list.

## Main features

- A voucher period per month with daily value and working days.
- One allocation per employee with the days actually worked.
- Vouchers earned computed and stored for every allocation.
- A period total computed and stored for payroll handoff.
- Validation that locks the period once the count is agreed.
- Worked days above the period calendar are refused for you.
- Employee-linked allocations ready for payroll export.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **VoucherBook** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
