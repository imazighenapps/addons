# AnnounceBoard

Internal Employee Announcements

## The problem

Internal announcements scattered across email and chat are missed and hard to track, with no central view of current, time-bound notices.

## The solution

Publish and manage internal announcements with title, content, audience, publish and expiry dates, and draft/published/archived states in a company-safe board.

## Main features

- Announcements with title, content, author and department target.
- Publish and expiry dates with priority indicator.
- Draft, published and archived states.
- Search and group by state, department and period.
- Chatter tracking on announcements.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Announcements** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
