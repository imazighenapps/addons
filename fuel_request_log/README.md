# FuelRequestLog

Fuel Request and Approval Register

## The problem

Informal fuel requests lack approvals and traceable records.

## The solution

Record vehicle fuel requests with amount, approval and fulfillment states to control and track fuel usage.

## Main features

- Fuel requests with vehicle, requester and request date.
- Requested amount and purpose/notes.
- Approver and fulfillment tracking.
- Draft, submitted, approved, fulfilled and rejected states.
- History of requests per vehicle.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Fuel Requests** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
