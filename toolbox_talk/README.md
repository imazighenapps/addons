# Toolbox

Five Minutes, Remembered

## The problem

Five-minute safety briefings are held but not recorded: topics, dates and attendees are missing from the safety file when proof is needed.

## The solution

Log the five-minute safety briefings with whose attended, so the topic and the date stand in your file.

## Main features

- A register of toolbox talks with topic, date, location and leader.
- Attendance lines with employee and a stamped sign-off.
- Attendance counts computed and stored on every toolbox talk.
- A simple flow from planned to completed for each briefing.
- One open-talks screen for briefings not yet completed.
- A completed talk cannot be completed twice.
- Attendance cannot be added once the talk is completed.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Toolbox** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
