# ToolCrib

Nobody Trusts The Cabinet

## The problem

Workshop tools are taken from an open cabinet with no record, so nobody knows who holds what, when it is due back or which tools are missing.

## The solution

Lend workshop tools against an employee and a due-back date instead of trusting the open cabinet.

## Main features

- A catalogue of workshop tools with reference and condition.
- Loans recorded against a borrower with issue and due dates.
- The return stamped with the exact date the tool came back.
- Open loans listed so you see who holds what right now.
- Late loans flagged when the due date has passed.
- One screen to review tools and their lending history.
- A return before the issue date is refused for you.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Tool Crib** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
