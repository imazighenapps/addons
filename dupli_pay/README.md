# DupliPay - Duplicate Invoice and Payment Detection

## The problem

Duplicate vendor bills and double payments are discovered weeks later by the accountant, when the supplier has already been paid twice.

## The solution

Detect duplicate invoices, bills and payments before payment, with a tolerance on amount and date and a documented decision.

## Main features

- Scan invoices, bills and payments.
- Configurable amount and date tolerance.
- Reference similarity check.
- No duplicate alerts.
- Ignore or confirm decision.
- Audit trail.

## Installation

1. Install the module from the Apps list.
2. Open the **Duplicate Control** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
