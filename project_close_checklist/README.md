# Checklist de Clôture de Projet (project_close_checklist)

Checklist de clôture : gabarit par type de projet (facturation, livrables, archive, garanties, feedback), responsable et validation datée.

## Problème
Les projets restent « ouverts » des mois : livrables oubliés, heures non facturées, garanties non enclenchées.

## Fonctionnalités
- Gabarits de clôture
- Points avec responsables
- Validation datée
- Blocage du projet
- KPI de délai de clôture

## Dépendances
- `project`, `mail`
