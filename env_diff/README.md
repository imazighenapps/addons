# Diff d'Environnements (env_diff)

Comparateur d'environnements : paramètres système, listes de valeurs, droits, séquences, champs custom — diff signé et export de correction.

## Problème
Ce qui marche en test casse en prod : personne ne compare réellement les deux environnements.

## Fonctionnalités
- Diff de paramètres
- Diff de droits
- Diff de listes
- Export de correction
- Historique

## Dépendances
- `base`, `mail`
