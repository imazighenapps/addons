# ShiftHandover

Shift Handover and Notes Log

## The problem

Shift handovers without structured records lose context, leading to delays and recurring issues.

## The solution

Record shift handovers with status summary, incidents and pending tasks, submit and acknowledge notes to preserve context across shifts in a company-safe register.

## Main features

- Handover records with date, shift and area.
- Outgoing/incoming responsible and status summary.
- Incidents and pending task fields.
- Draft, submitted and acknowledged states.
- Search and group by shift, area and state.
- Chatter tracking on handovers.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Shift Handovers** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
