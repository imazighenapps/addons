# MinuteBook

Minutes and Action Items

## The problem

A meeting produces decisions and tasks, then the minutes end up in a document nobody reopens: the action list is rebuilt from memory at every meeting, an overdue task is only discovered when somebody asks about it, and the chair has no way to prove what was decided.

## The solution

Write structured meeting minutes with attendees, agenda, decisions and assigned action items, then follow every action until it is done or overdue.

## Main features

- Minutes with date, place, chair and attendees.
- Agenda and decisions in dedicated fields.
- Action items with an owner, a due date and a status.
- Overdue flag computed from the due date and the status.
- Action and open action counters on every meeting.
- Draft, held, closed and cancelled states with an audit trail.
- Closing refused while the decisions are still empty.
- Kanban by state and multi-company isolation.

## Installation

1. Install the module from the Apps list.
2. Open the **Meeting Minutes** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
