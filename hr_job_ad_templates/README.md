# Modèles d'Annonces par Métier (hr_job_ad_templates)

Modèles d'annonces par métier : gabarits avec sections obligatoires (missions, profil, avantages, mentions légales), cohérence de marque employeur et publication rapide.

## Problème
Chaque annonce est réécrite de zéro : ton incohérent, obligations légales manquantes, qualité très variable entre recruteurs.

## Fonctionnalités
- Gabarits par métier
- Sections obligatoires verrouillées
- Insertion des informations standard
- Historique des annonces publiées
- Cohérence de marque employeur

## Dépendances
- `recruitment`, `mail`
