# GiftWallet - Gift Cards and Store Credit

## The problem

Gift cards are managed in a notebook or a spreadsheet: the balance is wrong, expired cards are still accepted, and the accounting liability is invisible.

## The solution

Issue gift cards with a unique code, redeem partially, reload, track the balance and expire them automatically.

## Main features

- Unique gift card code.
- Partial redemption and reload.
- Balance and transaction history.
- Automatic expiry.
- Outstanding liability indicator.
- Redemption wizard.
- Multi-company and multi-currency.

## Installation

1. Install the module from the Apps list.
2. Open the **Gift Wallet** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
