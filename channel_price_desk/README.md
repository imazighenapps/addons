# ChannelRate

Every Channel, Its Margin

## The problem

Maintain a distinct price list and margin target per sales channel and compare performance channel by channel.

## The solution

Maintain a distinct price list and margin target per sales channel and compare performance channel by channel.

## Main features

- Sales channels tracked in a dedicated register.
- Channel rates recorded with clear ownership and dates.
- Channel margin visible so nothing slips through.
- Draft, confirmed and done states with an audit trail.
- Computed totals and counts kept up to date.
- Active flag to archive records no longer needed.
- Company-aware records for multi-company use.
- Mail chatter for notes and follow-up.

## Installation

1. Install the module from the Apps list.
2. Open the **ChannelRate** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
