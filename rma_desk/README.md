# ReturnDesk

Returns Handled Like Sales

## The problem

Customer returns are handled informally, so approvals, receipts and credits are hard to trace and disputes have no reliable history.

## The solution

Run customer returns properly: request, approval, inbound receipt, keep or scrap, and the credit the customer awaits.

## Main features

- Return requests with customer, reason and requested date.
- Returned lines with product, quantity and unit value.
- A workflow from draft to approved, received and resolved.
- Approve, refuse, receive and resolve actions with traceability.
- A resolution decision to keep, scrap or credit the goods.
- Returned quantities and totals computed and stored on the request.
- Approving a request without lines is refused for you.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Returns** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
