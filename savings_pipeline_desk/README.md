# Pipeline d'Économies d'Achats (savings_pipeline_desk)

Pipeline d'économies : initiatives identifiées, montant négocié, baseline de prix, mise en œuvre suivie et économie réellement constatée sur les factures.

## Problème
Les économies négociées s'évaporent : rien ne relie la promesse du fournisseur à la baisse effective des prix payés.

## Fonctionnalités
- Initiatives avec baseline de prix
- Montants négociés vs constatés
- Concrétisation suivie sur factures
- Tableau des économies par période
- Rapport pour la direction

## Dépendances
- `purchase`, `account`, `mail`
