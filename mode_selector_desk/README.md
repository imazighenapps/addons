# Arbitrage de Mode de Transport (mode_selector_desk)

Arbitreur de mode : grille de coûts et délais par mode et corridor, calcul du surcoût d'express vs économie de délai, recommandation par priorité de la commande.

## Problème
Choisir entre colis, groupage, express ou affrètement se fait au ressenti : le mode le plus rapide est pris par réflexe sans voir le surcoût.

## Fonctionnalités
- Grille coûts/délais par mode
- Surcoût d'express chiffré
- Recommandation par priorité
- Historique des arbitrages
- Gains mesurés

## Dépendances
- `sale`, `stock`, `mail`
