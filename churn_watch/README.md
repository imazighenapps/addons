# ChurnWatch

Nobody Slips Away Twice

## The problem

Repeat customers go silent and nobody notices until they are gone, because there is no shared signal, no owner and no trace of save attempts.

## The solution

Spot the subscribers and repeat customers who stop ordering and trigger a save action before they are gone.

## Main features

- A risk signal per customer with last activity and silence threshold.
- Days without activity computed and stored on each signal.
- Risk status derived from the threshold to focus the save queue.
- Save actions with owner, planned date, outcome and notes.
- One screen for at-risk customers and their follow-up actions.
- Search filters for signals at risk and actions still pending.
- Validation that refuses impossible dates and thresholds.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Churn Watch** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
