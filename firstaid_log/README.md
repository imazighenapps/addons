# FirstAid

Kits Ready In Seconds

## The problem

First aid kits are checked from memory, so missing or expired contents are only discovered during an incident instead of during a refill round.

## The solution

Keep every first aid kit complete: what must be inside, what expires when and the refill rounds to run.

## Main features

- A register of first aid kits with location and responsible.
- Kit contents with required quantity, on hand and expiry date.
- Refill rounds recorded with date and restocked items.
- Missing and expired items counted and stored on the kit.
- A quick view of kits that need attention.
- One screen to review kits and their refill history.
- An on-hand quantity below zero is refused for you.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **First Aid** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
