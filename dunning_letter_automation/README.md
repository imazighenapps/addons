# DunningFlow

Overdue Invoice Dunning Letters

## The problem

SMBs chasing overdue invoices manually send reminders late or inconsistently, and cannot show which invoice was reminded at which level.

## The solution

Define reminder levels with delays and letter texts, then generate dunning letters for overdue customer invoices and track them until payment.

## Main features

- Dunning levels with delay in days, subject and letter body.
- Generation of letters for overdue posted customer invoices.
- Residual amount and due date captured on each letter.
- Draft, sent, paid and cancelled states with send date.
- Chatter trail on every letter.
- No duplicate open letter per invoice and level.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Dunning** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
