# LockerAssign

Employee Locker Assignment Tracking

## The problem

Locker assignments tracked informally become outdated, causing uncertainty about holders and availability.

## The solution

Manage lockers and assign them to employees with issue and return dates, track assigned and returned states, and keep a company-safe assignment history.

## Main features

- Locker catalogue with identifier and location.
- Assignments per employee with issue and return dates.
- Assigned and returned states.
- Return action updating status and date.
- Search and group by locker, employee and state.
- Chatter tracking on assignments.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Lockers** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
