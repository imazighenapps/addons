# Synchronisation Drive (drive_sync)

Synchronisation bidirectionnelle : dossier cloud ↔ Documents (SharePoint, Google Drive, Nextcloud), règles par espace, journal de conflits.

## Problème
Les équipes continuent de travailler sur un drive partagé : les documents ne remontent pas dans Odoo.

## Fonctionnalités
- Sync bidirectionnelle
- Règles par espace
- Résolution de conflits
- Journal des runs
- Sélecteur du fournisseur

## Dépendances
- `base`, `mail`
