# Rapprochement Marketplaces (marketplace_settlement_recon)

Import des relevés marketplace : ventilation ventes/commissions/AB/frais, rapprochement avec commandes et écriture d'encaissement nette.

## Problème
Les vendeurs marketplaces (Amazon, Allegro, etc.) reçoivent des relevés de règlement mêlant ventes, commissions, publicité et rembours.

## Fonctionnalités
- Import relevé marketplace
- Ventilation par type de flux
- Rapprochement avec commandes
- Écriture nette automatique
- Écart de rupture de stock AB

## Dépendances
- `account`, `mail`
