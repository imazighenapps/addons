# DriverAssign

Vehicle Driver Assignment Log

## The problem

Vehicle driver assignments tracked informally lack history and clarity on current responsibility.

## The solution

Track vehicle-to-driver assignments with start/end dates and status, keeping a clear current and historical record per vehicle and driver.

## Main features

- Assignment records linking vehicle and driver/employee.
- Start/end dates and assignment status.
- Active, ended and cancelled states.
- Actions to end or cancel assignments.
- Search and group by vehicle, driver and state.
- Chatter tracking on assignments.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Driver Assignments** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
