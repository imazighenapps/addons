# Prêts Employeur (hr_employer_loans)

Registre de prêts : demande avec justification, échéancier de prélèvements sur paie, solde restant toujours visible, régularisation au départ.

## Problème
Les prêts à taux zéro accordés aux salariés (montant, échéancier, prélèvements) sont gérés dans Excel : erreurs de prélèvement et soldes invisibles.

## Fonctionnalités
- Demande avec justification
- Échéancier de prélèvements
- Solde restant visible
- Régularisation au départ
- Historique par salarié

## Dépendances
- `hr`, `mail`
