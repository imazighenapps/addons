# Jalons de Relation Client (relationship_milestones)

Jalons de relation : jalons automatiques détectés (anniversaire, rang de commande, durée), rappels avec geste commercial proposé et mesure de l'effet sur les commandes suivantes.

## Problème
Anniversaire de collaboration, X-me commande, jalon de fidélité : ces moments passent sans geste ni message et l'attachement client ne se cultive pas.

## Fonctionnalités
- Jalons détectés automatiquement
- Rappels avec geste proposé
- Suivi du geste donné
- Effet mesuré sur les commandes
- Historique des jalons

## Dépendances
- `crm`, `sale`, `mail`
