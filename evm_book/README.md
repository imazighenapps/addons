# Gestion de Valeur Acquise (evm_book)

Indicateurs EVM simplifiés par projet : CPI, SPI, EAC, dérivés du coût planifié vs réalisé vs valeur acquise, avec alertes et historique mensuel.

## Problème
Les longs projets dérivent sans qu'on sache si le retard vient du coût ou du planning : les PME ne disposent pas d'indicateurs EVM.

## Fonctionnalités
- CPI et SPI par projet
- Estimation à l'achèvement (EAC)
- Courbe d'avancement planifié vs réel
- Alertes de dérive
- Historique mensuel

## Dépendances
- `project`, `account_analytic`, `mail`
