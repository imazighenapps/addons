# IFRS16 Locations (ifrs16_lease_desk)

Moteur IFRS16 : bilan d'ouverture du ROU, amortissement, intérêts actuariels, ré-évaluation (index) et clôture anticipée, avec écritures.

## Problème
Les contrats de location au sens IFRS16 (ROU actif/passif, intérêts actuariels) sont traités dans Excel par les entreprises auditées.

## Fonctionnalités
- Bilan d'ouverture ROU
- Amortissement et intérêts actuariels
- Ré-évaluation par index
- Clôture anticipée
- Dossier d'audit

## Dépendances
- `account`, `mail`
