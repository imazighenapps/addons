# Contrôles Réglementaires du Stockage (stock_equipment_statutory_inspections)

Registre des contrôles réglementaires : périodicité par type d'équipement, prochaine échéance, prestataires, rapport attaché et blocage d'usage en cas de retard.

## Problème
Ponts roulants, portiques, nacelles : les contrôles réglementaires périodiques se décident au calendrier papier, un oubli égale un risque d'arrêté.

## Fonctionnalités
- Périodicité par type d'équipement
- Prochaine échéance calculée
- Prestataire et rapport attachés
- Blocage d'usage en cas de retard
- Historique complet

## Dépendances
- `stock`, `mail`
