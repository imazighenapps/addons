# Certificats d'Analyse par Lot (coa_lot_desk)

Registre de COA par lot reçu : exigence par produit, capture du certificat à la réception, contrôle de complétude et blocage ou alerte avant mise en stock.

## Problème
Les certificats d'analyse accompagnant chaque lot (chimie, pharma, agro) sont éparpillés dans les emails ; à l'audit, impossible de les retrouver vite.

## Fonctionnalités
- Exigence COA par produit
- Capture à la réception
- Contrôle de complétude par lot
- Retrouvabilité instantanée
- Export dossier d'audit

## Dépendances
- `stock`, `purchase`, `mail`
