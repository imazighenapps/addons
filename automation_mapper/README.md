# Cartographe des Automatisations (automation_mapper)

Cartographie des automatisations : déclencheurs, champs surveillés, ordre d'exécution, conflits potentiels et chemins de cascade détectés.

## Problème
Les automatisations Odoo s'accumulent : déclencheurs méconnus, règles qui se déclenchent en cascade, bugs incompréhensibles.

## Fonctionnalités
- Inventaire des règles
- Déclencheurs et champs listés
- Cascades détectées
- Conflits signalés
- Documentation exportable

## Dépendances
- `base`, `mail`
