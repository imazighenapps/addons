# CheckFlow

Reusable Service and Job Checklists

## The problem

Service jobs executed without reusable, recorded checklists lead to missed steps, inconsistent quality and no provable completion record.

## The solution

Define reusable checklist templates, run them on jobs with per-item results and notes, and track completion progress and outcomes in a company-safe, reportable register.

## Main features

- Reusable checklist templates with ordered items.
- Checklist runs instantiated from a template for each job.
- Per-item results (done, failed, not applicable) with notes.
- Computed completion progress and overall run state.
- Search and group by template, responsible, state and period.
- Chatter tracking on runs.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Checklists** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
