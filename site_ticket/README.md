# SiteTicket

Buildings Fixed, Not Begged

## The problem

Building problems are reported informally, contractors are chased without a record, deadlines slip and nobody can prove what is open, fixed or still waiting for a visit.

## The solution

Turn every building problem into a ticket routed to the right contractor with a deadline and the photos.

## Main features

- A ticket register for every building issue with location and priority.
- Assignment to an internal owner and to the contractor partner.
- Requested, started and resolved dates stamped on the workflow.
- New, in progress, done and cancelled states with chatter history.
- Cost tracking and a photo or evidence note on each ticket.
- Counters for open tickets kept up to date on each site area.
- Multi-company isolation out of the box.
- A clean queue for the issues that still need action.

## Installation

1. Install the module from the Apps list.
2. Open the **Site Tickets** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
