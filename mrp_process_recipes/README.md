# Recettes de Process Versionnées (mrp_process_recipes)

Recettes de process : paramètres par produit et équipement, versions datées, diffusion contrôlée aux conducteurs et comparaison recette vs réalisation.

## Problème
Les paramètres de fabrication (températures, temps, vitesses, dosages) vivent dans des fiches papier : chaque conducteur applique sa version.

## Fonctionnalités
- Paramètres par produit/équipement
- Versions datées avec historique
- Diffusion contrôlée aux conducteurs
- Comparaison recette vs réalisé
- Recherche de recettes similaires

## Dépendances
- `mrp`, `quality`, `mail`
