# Digest Quotidien Intelligent (daily_digest)

Digest quotidien par rôle : résumé de ce qui attend l'utilisateur (validations, relances, échéances), heure d'envoi configurable et historique.

## Problème
Chacun rate ce qui l'attend (approbations, échéances, tâches) : les notifications noient l'information.

## Fonctionnalités
- Résumé par rôle
- Sections par type
- Heure configurable
- Clic direct vers les actions
- Désinscription par section

## Dépendances
- `mail`
