# VisitorMealLog

Visitor and Guest Meal Register

## The problem

Visitor meals tracked informally are hard to coordinate and reconcile.

## The solution

Record visitor and guest meals with host, date, quantity, details and states to coordinate and track provided meals.

## Main features

- Meal records with host, date and number of meals.
- Visitor/guest details and notes.
- Location or meeting reference.
- Draft, requested, served and cancelled states.
- Meal history tracking.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Visitor Meals** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
