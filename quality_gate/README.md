# QualityGate - Quality Control and Inspections

## The problem

Quality checks live on a paper form at the end of the line. Checkpoints are skipped, tolerances are never compared with the measured value, and non-conformities are closed by an email that nobody can find three months later.

## The solution

Run incoming, in-process and outgoing quality inspections with reusable control plans, measured checkpoints and tracked non-conformities.

## Main features

- Reusable control plans per operation.
- Pass/fail, measure, range and text checkpoints.
- Acceptance limits with unit of measure.
- Inspections linked to product, lot and transfer.
- Automatic checkpoint loading.
- Pass blocked until required checkpoints are validated.
- Non-conformities with severity and corrective action.
- Audit trail and multi-company.

## Installation

1. Install the module from the Apps list.
2. Open the **Quality** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
