# Prévision d'Encombrement du Stockage (storage_growth_forecast)

Prévision d'encombrement par modèle et par type de pièce jointe, top consommateurs, seuils d'alerte et projection de date de saturation.

## Problème
Le disque se remplit sans prévenir : la prévision de croissance et les gros consommateurs ne sont pas visibles.

## Fonctionnalités
- Croissance par modèle et par type
- Top consommateurs
- Seuils d'alerte
- Projection de saturation
- Recommandations d'action

## Dépendances
- `base`, `mail`
