# Linter de Modèles d'Emails (email_template_linter)

Linter des modèles d'emails : variables vérifiées contre les champs des modèles, rendu d'essai avec un record de test et rapport d'anomalies.

## Problème
Les modèles d'emails cassés (variables inexistantes, boucles vides) partent au client avant d'être détectés.

## Fonctionnalités
- Variables vérifiées contre les champs
- Rendu d'essai avec record de test
- Rapport d'anomalies
- Historique des corrections
- Validation avant publication

## Dépendances
- `mail`
