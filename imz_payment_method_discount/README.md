# Remise Selon Mode de Paiement (payment_method_discount)

Remise par mode de paiement : règles par client ou canal, application automatique à la facturation selon le mode réel utilisé et statistique d'usage par mode.

## Problème
Récompenser les clients qui paient par virement plutôt que par carte exige des remises saisies à la main et jamais cohérentes.

## Fonctionnalités
- Règles par client ou canal
- Application selon le mode réel
- Statistique d'usage par mode
- Alerte si le mode change après devis
- Journal des remises de mode

## Dépendances
- `sale`, `account`, `mail`
