# Taux de Change Automatiques (rate_provider_sync)

Synchronisation des taux : sources configurables (BCE par défaut), historique, alertes d'écart anormal et re-saisie manuelle justifiée.

## Problème
Saisir les taux manuellement chaque jour source d'erreurs ; plusieurs sources (BCE, ECB, banques) coexistent.

## Fonctionnalités
- Sources configurables (BCE…)
- Historique des taux
- Alerte d'écart anormal
- Saisie manuelle justifiée
- Journal de synchronisation

## Dépendances
- `account`, `mail`
