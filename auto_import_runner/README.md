# Exécutant d'Imports Planifiés (auto_import_runner)

Exécutant planifié : sources (email, SFTP, URL), mapping réutilisé, exécution horaire, gestion des erreurs et rapport quotidien.

## Problème
Les fichiers d'import arrivent par email/SFTP chaque jour : quelqu'un les télécharge et importe à la main.

## Fonctionnalités
- Sources configurables
- Mapping réutilisé
- Exécution horaire
- Gestion d'erreurs
- Rapport quotidien

## Dépendances
- `base`, `mail`
