# Journal de Baignade (pool_water_logbook)

Journal numérique des tests d'eau par bassin avec seuils, lectures hors plage signalées, actions correctives et registre imprimable pour l'autorité sanitaire.

## Problème
Les campings et hôtels consignent les analyses d'eau (chlore, pH) sur un cahier perdu à la moindre inspection.

## Fonctionnalités
- Plan de tests par bassin
- Seuils chlore/pH paramétrables
- Alertes hors plage avec action
- Registre imprimable daté
- Historique par saison

## Dépendances
- `maintenance`, `mail`
