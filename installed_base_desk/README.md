# Parc Installé chez les Clients (installed_base_desk)

Fiche de parc installé par site client : équipements avec numéros de série, options, dates, échéances et interventions rattachées à l'équipement.

## Problème
Le service technique ignore ce qui est réellement installé chez chaque client : numéros de série, versions, options, date de mise en service, échéances de contrôle.

## Fonctionnalités
- Parc par site client
- Numéros de série
- Options et versions
- Échéances de contrôle
- Interventions rattachées

## Dépendances
- `project`, `sale`, `stock`, `mail`
