# SafetyReport

Workplace Safety Incident Log

## The problem

Safety incidents captured informally lack consistent structure and follow-up tracking, increasing risk and audit effort.

## The solution

Log workplace safety incidents with date, location, type, severity and corrective actions, track status from report to closure, and report incidents in a company-safe register.

## Main features

- Incident records with date, location, type and severity.
- Reporter, involved persons and detailed description.
- Corrective action and follow-up fields.
- Draft, reported, in progress and closed states.
- Search and group by type, severity, state and period.
- Chatter tracking on incidents.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Safety Incidents** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
