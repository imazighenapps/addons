# QMS Objectives

## Purpose
QMS Objectives provides measurable quality and management-system objectives with periodic measurements and progress monitoring.

## Main capabilities
- Create objectives with an owner, process and objective type.
- Categorize objectives as quality, customer, process, supplier, compliance, people or other.
- Define baseline and target values.
- Select measurement direction: increase, decrease or reach target.
- Record a unit of measure.
- Record start and deadline dates.
- Add periodic objective measurements with source and notes.
- Calculate current value and progress percentage automatically.
- Track objective status: draft, on track, at risk, delayed, achieved, failed or cancelled.

## Models
- `qms.objective`: objective master record.
- `qms.objective.measurement`: dated objective measurement.

## Menu
- QMS / Objectives
- QMS / Objective Measurements

## Dependencies
`qms_core`, `mail`.
