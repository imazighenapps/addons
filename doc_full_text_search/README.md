# Recherche Plein-Texte Documents (doc_full_text_search)

Recherche plein-texte : indexation OCR du contenu des PDFs, recherche par mots, filtrage par dossier et extrait surligné.

## Problème
Retrouver une clause dans un contrat PDF exige de les ouvrir un par un : la base documentaire est une boîte noire.

## Fonctionnalités
- Indexation du contenu
- Recherche par mots
- Extrait surligné
- Filtres par dossier
- Index géré

## Dépendances
- `base`, `mail`
