# Coût par Lavage (carwash_cost_per_wash)

Consommables rattachés par type de lavage, coût et marge par formule, alertes de dérive de consommation.

## Problème
Le coût réel d'un lavage (produits, eau, consommables) n'est jamais calculé : les tarifs sont fixés à l'aveugle.

## Fonctionnalités
- Consommables par type de lavage
- Coût et marge par formule
- Dérive de consommation
- Comparatif par station
- Tarifs fondés sur les coûts

## Dépendances
- `account`, `stock`, `mail`
