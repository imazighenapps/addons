# Import de Données Rejouable (data_import_playbook)

Playbooks d'import réutilisables : mapping sauvegardé par modèle, essai à blanc, rapport d'erreurs ligne par ligne, rejouabilité.

## Problème
Chaque import CSV est refait à la main avec des mappings perdus et des erreurs qui se corrigent à tâtons.

## Fonctionnalités
- Mappings sauvegardés par modèle
- Essai à blanc avec rapport
- Erreurs ligne par ligne
- Rejouabilité datée
- Historique des imports

## Dépendances
- `base`, `mail`
