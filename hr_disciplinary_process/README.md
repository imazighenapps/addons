# Procédure Disciplinaire (hr_disciplinary_process)

Procédure guidée : étapes obligatoires avec délais (convocation, entretien, notification), modèles de pièces, registre des sanctions avec expiration (effacement) et preuve complète.

## Problème
Les sanctions disciplinaires (avertissements, mises à pied) exigent une procédure stricte (convocation, entretien, délais) : procès-verbal souvent non conforme, risques aux prud'hommes.

## Fonctionnalités
- Étapes obligatoires avec délais
- Modèles de pièces jointes
- Registre des sanctions
- Expiration des avertissements
- Preuve complète pour contentieux

## Dépendances
- `hr`, `mail`
