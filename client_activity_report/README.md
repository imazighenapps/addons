# Rapport d'Activité Client Périodique (client_activity_report)

Générateur de rapport d'activité : synthèse mensuelle par client (interventions, heures, pièces, recommandations) en PDF blanc-marqué.

## Problème
Les clients récurrents demandent un rapport d'activité (interventions, temps, réalisations) reconstitué à la main chaque mois.

## Fonctionnalités
- Rapport mensuel par client
- Interventions et heures
- Pièces consommées
- Recommandations
- Envoi automatique

## Dépendances
- `project`, `account`, `mail`
