# Découpeur de PDFs (pdf_splitter)

Découpeur intelligent : règles de séparation (page de garde, codes, sauts), fichiers nommés et affectés automatiquement.

## Problème
Les relevés/rapports multi-clients arrivent en un seul PDF : découpage manuel et erreurs d'affectation.

## Fonctionnalités
- Règles de séparation
- Nommage automatique
- Affectation auto
- Journal
- Prévisualisation

## Dépendances
- `base`, `mail`
