# Surveillance de la File d'Emails (mail_queue_watch)

Surveillance de la file : longueur, âge des plus anciens, échecs, alertes de seuil et vidage contrôlé.

## Problème
La file d'emails s'engorge silencieusement : relances et factures partent avec des heures de retard.

## Fonctionnalités
- Longueur de file
- Âge des messages
- Échecs
- Alertes de seuil
- Vidage contrôlé

## Dépendances
- `mail`
