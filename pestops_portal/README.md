# PestOps Portal — Odoo 19 Community

Customer portal extension for the PestOps suite.

## Features

- Customer dashboard under `/my/pestops`
- Authorized site listing and site detail
- Visit listing and visit detail
- Downloadable service reports and treatment certificates
- Customer service requests with type, priority and description
- Automatic PestOps re-service generation for portal requests linked to a visit
- Backend Service Requests menu for PestOps users
- Ownership checks based on the customer's commercial partner
- No Enterprise-only dependency

## Dependencies

- `pestops_core`
- `portal`

The module stays Community-first. Sales, Accounting and other integrations remain optional suite modules.
