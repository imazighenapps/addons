# CanteenBook

One Count, No Waste

## The problem

Daily lunch counts arrive by email and notes with no cut-off or trace, so the caterer gets the wrong headcount and nobody knows what was actually ordered.

## The solution

Tell the caterer each morning how many lunches per team and shut the count at a fixed cut-off time.

## Main features

- A daily headcount per team with responsible employee.
- The number of meals ordered for each team.
- A fixed cut-off time recorded on every count.
- One action to close the count once it is sent to the caterer.
- A daily total of meals computed from the open records.
- A sent count that cannot be edited by mistake.
- Chatter traceability on every headcount.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Canteen** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
