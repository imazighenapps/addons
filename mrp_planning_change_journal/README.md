# Journal des Changements de Planification (mrp_planning_change_journal)

Journal des replanifications : chaque décalage de MO tracé (qui, quand, avant/après, motif), statistiques de stabilité du plan et alerte sur les usines volatiles.

## Problème
Les dates de MOs sont déplacées sans trace : impossible d'expliquer pourquoi un lot a raté la fenêtre d'expédition.

## Fonctionnalités
- Trace avant/après par MO
- Motifs de décalage codifiés
- Indice de stabilité du plan
- Alerte sur la volatilité
- Rapport mensuel

## Dépendances
- `mrp`, `mail`
