# Contrôle des Temps de Repos au Planning (hr_rest_time_guard)

Garde-fou de repos : vérification au placement (repos quotidien, hebdomadaire, jours consécutifs), blocage ou alerte selon les règles, correction guidée.

## Problème
Les plannings publiés violent souvent les temps de repos réglementaires (11h entre deux services, 24h hebdomadaire) : contrôles faits au doigt.

## Fonctionnalités
- Règles de repos paramétrées
- Contrôle au placement
- Blocage ou alerte configurable
- Correction guidée
- Journal des violations

## Dépendances
- `hr`, `mail`
