# PettyCashPro - Petty Cash Fund Management

## The problem

Petty cash is reimbursed on trust: the box balance is unknown, receipts are lost, and nobody notices a gap until the annual audit.

## The solution

Manage petty cash funds, top-ups, expenses with receipts, reconciliations and closures, with a live balance and an explained gap.

## Main features

- Fund per cash box with code and responsible.
- Initial float, top-ups, expenses and returns.
- Live balance and totals per fund.
- Receipt attached to each transaction.
- Confirmation workflow with user and timestamp.
- Reconciliation with counted cash and difference.
- Closing blocked until the gap is explained.
- Multi-company and multi-currency.

## Installation

1. Install the module from the Apps list.
2. Open the **Petty Cash** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
