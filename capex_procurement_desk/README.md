# Achats d'Investissement (CAPEX) (capex_procurement_desk)

Circuit CAPEX : dossier d'investissement avec devis comparés, approbation par enveloppe, suivi du chantier de dépense et bascule contrôlée en immobilisation.

## Problème
Les achats d'investissement (machine, travaux, licences lourdes) suivent le même circuit que les achats courants : pas de cycle de devis spécifique, pas d'activation en immobilisation cohérente.

## Fonctionnalités
- Dossier d'investissement
- Devis comparés dans le dossier
- Approbation par enveloppe
- Suivi des dépenses engagées
- Bascule en immobilisation

## Dépendances
- `purchase`, `account`, `mail`
