# Certificats Matière 3.1 (quality_mills_certificates)

Registre de certificats matière : 3.1/2.2/3.2 par lot de réception, contrôle du fournisseur et de la coulée, rattachement au lot, disponibilité pour les CoA clients.

## Problème
Les acheteurs de matières (métaux, aciers) reçoivent des certificats 3.1 en PDF jamais reliés aux lots reçus : impossible de répondre à une demande de traçabilité matière.

## Fonctionnalités
- Certificat par lot de réception
- Contrôle fournisseur/coulée
- Rattachement au lot Odoo
- Disponibilité pour les CoA clients
- Alerte sur les lots sans certificat

## Dépendances
- `quality`, `purchase`, `stock`, `mail`
