# BudgetCtlPro

Budget Control with Commitments

## The problem

A budget is compared with the invoices received, never with the purchase orders already signed. The committed money is invisible, the available amount looks healthy, and the department discovers the overrun only when the invoices arrive and the envelope is already spent.

## The solution

Compare planned, actual and committed amounts line by line, see what is really left to spend, and freeze the budget once the period is closed.

## Main features

- Planned, actual and committed amounts on every budget line.
- Available amount computed as planned minus actual minus committed.
- Stored header totals and an automatic overspend flag.
- Optional analytic account, or a global budget for the company.
- Period based budgets with a BGT/ sequence reference.
- Draft, running and closed states with an audit trail.
- Budget lines locked once the budget is closed, unlocked by a reset.
- Multi-company and multi-currency, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Budget Control** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
