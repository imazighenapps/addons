# RoomBook

Meeting Room Booking and Availability

## The problem

Shared meeting rooms booked informally lead to double-bookings and wasted time because availability is not enforced in one place.

## The solution

Manage meeting rooms and bookings with organizer, time range and attendees, prevent overlapping reservations for the same room, and view availability in a company-safe register.

## Main features

- Room catalogue with capacity, location and active flag.
- Bookings with organizer, time range, subject and attendees count.
- Overlap detection blocking conflicting bookings for a room.
- Draft, confirmed and cancelled booking states.
- Search and group by room, organizer and period.
- Chatter tracking on bookings.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Room Booking** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
