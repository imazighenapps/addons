# ParkSpot

Parking Spot Reservation and Availability

## The problem

Parking spots reserved informally lead to conflicts and wasted time because availability is not enforced or visible.

## The solution

Manage parking spots and reservations with requester, time range and vehicle plate, prevent overlapping bookings per spot, and track availability in a company-safe register.

## Main features

- Parking spot catalogue with location and active flag.
- Reservations with requester, time range and vehicle plate.
- Overlap detection blocking conflicting spot reservations.
- Draft, confirmed and cancelled states.
- Search and group by spot, requester and period.
- Chatter tracking on reservations.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Parking** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
