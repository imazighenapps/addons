# SafetyDrillLog

Health and Safety Drill Register

## The problem

Safety drills recorded informally lack a traceable history and tracked follow-up actions.

## The solution

Record safety drills with type, date, participants, observations and corrective actions to keep an auditable drill history.

## Main features

- Drill records with type, date, location and responsible person.
- Participant count and attendance notes.
- Observations, findings and corrective actions.
- Draft, completed and cancelled states.
- Planned and performed date tracking.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Safety Drills** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
