# Badges & Niveaux (community_badge_levels)

Système de badges et niveaux : points pour contributions, paliers, badges attribuables et profil de contributeur visible.

## Problème
Les communautés d'usagers (clients, partenaires) manquent de reconnaissance : les contributeurs actifs restent invisibles.

## Fonctionnalités
- Points pour contributions
- Niveaux et paliers
- Badges attribuables
- Profil de contributeur
- Tableau des meilleurs contributeurs

## Dépendances
- `base`, `mail`
