# Projets Co-Financés (co_funded_project)

Répartition par financeur : parts conventionnées, ventilation analytique des coûts, dossiers justificatifs par financeur et rapports de remboursement.

## Problème
Les projets subventionnés ou co-financés exigent une répartition des coûts par financeur avec pièces justificatives : tenue dans Excel.

## Fonctionnalités
- Parts par financeur
- Ventilation des coûts
- Dossiers justificatifs
- Rapports de remboursement
- Contrôles de cohérence

## Dépendances
- `project`, `analytic`, `mail`
