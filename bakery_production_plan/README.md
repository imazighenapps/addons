# Prévision de Production Boulangerie (bakery_production_plan)

Plan de production par jour et produit fondé sur l'historique des ventes, comparaison plan/réel et correction hebdomadaire.

## Problème
Le boulanger produit à l'instinct : invendus certains jours, ruptures d'autres, sans plan fondé sur l'historique.

## Fonctionnalités
- Plan de production par jour
- Historique des ventes intégré
- Comparaison plan/réel
- Invendus consignés
- Correction hebdomadaire

## Dépendances
- `point_of_sale`, `stock`, `mail`
