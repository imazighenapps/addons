# Grilles de Majoration d'Heures (hr_overtime_rate_table)

Grille de majoration paramétrable : tranches et taux par convention et par catégorie, application automatique aux heures relevées, contrôle avant transmission paie.

## Problème
Les taux de majoration (nuit, dimanche, jours fériés, au-delà de X h) vivent dans les accords : chaque fiche de paie les applique différemment à la main.

## Fonctionnalités
- Grille par convention/catégorie
- Application aux heures relevées
- Distinction par type d'heure
- Contrôle avant transmission
- Historique des grilles

## Dépendances
- `hr`, `hr_attendance`, `mail`
