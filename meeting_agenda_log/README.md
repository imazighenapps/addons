# MeetingAgenda

Meeting Agenda and Action Log

## The problem

Meeting agendas and actions tracked informally lead to missed follow-ups and poor visibility.

## The solution

Plan meetings with agendas and attendees, record outcomes and action items, and track follow-up through clear workflow states.

## Main features

- Meeting records with organizer, date and attendees.
- Agenda, outcomes and action item fields.
- Draft, planned, done and cancelled states.
- Workflow actions to plan, complete and cancel meetings.
- Search and group by organizer and state.
- Chatter tracking on meetings.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Meeting Agendas** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
