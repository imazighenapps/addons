# Absorption des Frais Généraux Atelier (mrp_overhead_absorption)

Clés d'absorption par poste de charge : taux horaire chargé d'indirects, application aux heures passées, réconciliation mensuelle des frais absorbés vs réels.

## Problème
Les frais généraux (locaux, énergie, encadrement) ne sont jamais absorbés dans le coût des opérations : le coût de revient sous-estime l'atelier.

## Fonctionnalités
- Taux d'absorption par poste de charge
- Application automatique aux opérations
- Réconciliation absorbé vs réel
- Simulation de taux
- Historique par période

## Dépendances
- `mrp`, `account`, `mail`
