# Analyseur de Performances (page_perf_profiler)

Analyse de performance : mesure des requêtes lentes et du temps par modèle, drill-down par page, comparaisons avant/après optimisation.

## Problème
Les pages lentes sont signalées par les utilisateurs sans qu'on puisse dire quelle requête ou quel calcul bloque.

## Fonctionnalités
- Requêtes lentes classées
- Temps par modèle et page
- Drill-down par requête
- Comparaisons avant/après
- Rapport d'optimisation

## Dépendances
- `base`, `mail`
