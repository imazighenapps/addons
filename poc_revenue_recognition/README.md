# Reconnaissance du Revenu POC (poc_revenue_recognition)

Moteur POC : avancement calculé (coûts engagés/estimés), revenu reconnu par période, écritures et justificatif client auditable.

## Problème
Reconnaître le revenu à l'avancement (coût-coût) sur les longs projets est impossible dans Odoo Community.

## Fonctionnalités
- Avancement coût-coût
- Revenu reconnu par période
- Écritures automatiques
- Justificatif PDF
- Prévision d'avancement

## Dépendances
- `account`, `mail`
