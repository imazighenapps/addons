# Équipes Multi-Techniciens (crew_job_desk)

Composition d'équipe par intervention, heures synchronisées, matériel partagé et répartition facturable entre membres de l'équipe.

## Problème
Les interventions à 2-4 techniciens (levage, sécurité, séquences synchronisées) sont coordonnées par téléphone : heures cumulées perdues, matériel partagé non tracé.

## Fonctionnalités
- Composition d'équipe
- Heures synchronisées
- Matériel partagé
- Répartition facturable
- Historique par équipe

## Dépendances
- `project`, `hr`, `mail`
