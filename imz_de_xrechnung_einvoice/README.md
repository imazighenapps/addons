# e-Invoicing XRechnung DE (de_xrechnung_einvoice)

Génération XRechnung (CIUS) à partir des factures clients, contrôles, suivi d'acceptation.

## Fonctionnalités
- XML XRechnung (CrossIndustryInvoice) avec totaux
- Contrôles de complétude avant génération
- Statuts (brouillon → prête → envoyée → acceptée/refusée)

## Dépendances
- `account`, `mail`
