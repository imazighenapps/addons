# OnboardLog

Employee Onboarding Checklist Log

## The problem

Onboarding tasks tracked informally lead to missed steps and unclear status for new hires.

## The solution

Track new employee onboarding with checklist tasks, owners and due dates, monitor progress through states, and keep a company-safe completion record.

## Main features

- Onboarding records per employee with task lines.
- Task owners, due dates and completion flags.
- Draft, in progress, done and cancelled states.
- Actions to start and complete onboarding.
- Search and group by employee, state and period.
- Chatter tracking on records.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Onboarding** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
