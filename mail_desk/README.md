# MailDesk

Mail In, Mail Out, Traced

## The problem

Registered and tracked mail is logged on paper, so items wait uncollected, tracking numbers are lost and nobody can prove what arrived or left.

## The solution

Log the registered and tracked mail that enters or leaves the company and who collected each item.

## Main features

- A register of inbound and outbound tracked mail items.
- Sender or recipient, tracking number and logged date on each item.
- The collector and pickup date stamped when the item is collected.
- A clear state from waiting to collected.
- One pickup screen for everything still waiting.
- A pickup before the logged date is refused for you.
- Chatter traceability on every mail record.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Registered Mail** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
