# GaugeBook

Only Fresh Instruments

## The problem

Calibration certificates live in binders and spreadsheets, so lapsed gauges keep measuring, the next due date is guessed and audits find overdue instruments after the fact.

## The solution

Never measure with an overdue instrument: the calibration calendar follows each gauge and blocks the lapsed.

## Main features

- One instrument register with serial number, location and interval.
- Next calibration due date computed and stored on every instrument.
- Calibration history with date, result, certificate and technician.
- Confirming a calibration refreshes the instrument due date.
- Blocked and in-service states with an explicit lapsed flag.
- Counters for calibration count and overdue status, stored for filters.
- A calibration before the instrument date is refused for you.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Gauge Book** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
