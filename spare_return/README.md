# SpareBack

What Goes Out Comes Back

## The problem

Spare parts and samples sent to site are not tracked consistently, so unused material is lost in vans or on site and teams cannot see what still needs to come back.

## The solution

Track the spare parts and samples sent to site and get back what the job did not consume.

## Main features

- Material lines with customer, site, owner and due date.
- Track quantities sent, consumed and returned per line.
- Simple open and returned workflow with return action.
- Stored counters for open and recovered material lines.
- Overdue and open filters to chase pending returns.
- List, kanban and form views for field follow-up.
- Multi-company isolation for independent operations.

## Installation

1. Install the module from the Apps list.
2. Open the **Field Returns** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
