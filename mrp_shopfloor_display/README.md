# Mur d'Affichage Atelier (mrp_shopfloor_display)

Page d'affichage publique par URL (écran TV ou tablette sans connexion utilisateur) : MOs en cours par poste, retard, priorité, attente qualité, rafraîchi automatiquement.

## Problème
L'atelier n'a pas de vision partagée de l'état des MOs : les questions en permanence au superviseur ralentissent tout le monde.

## Fonctionnalités
- URL publique sans session Odoo
- Vue par poste et par équipe
- Codes couleur retard/priorité
- Rafraîchissement automatique
- Filtres par zone d'atelier

## Dépendances
- `mrp`, `mail`
