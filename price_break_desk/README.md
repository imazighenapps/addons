# SupplierBreak

Order The Smart Quantity

## The problem

Store supplier quantity price breaks and highlight the order quantity that lands the best unit cost.

## The solution

Store supplier quantity price breaks and highlight the order quantity that lands the best unit cost.

## Main features

- Supplier tiers tracked in a dedicated register.
- Break prices recorded with clear ownership and dates.
- Best quantity visible so nothing slips through.
- Draft, confirmed and done states with an audit trail.
- Computed totals and counts kept up to date.
- Active flag to archive records no longer needed.
- Company-aware records for multi-company use.
- Mail chatter for notes and follow-up.

## Installation

1. Install the module from the Apps list.
2. Open the **SupplierBreak** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
