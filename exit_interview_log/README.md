# ExitInterview

Employee Exit Interview Log

## The problem

Exit interview insights stored informally are inconsistent and difficult to review for retention improvements.

## The solution

Record employee exit interviews with departure reasons, feedback and follow-up actions, track completion and review in a company-safe register.

## Main features

- Exit interview records linked to employee and department.
- Departure reason, feedback and follow-up action fields.
- Draft, completed and reviewed states.
- Actions to complete and review interviews.
- Search and group by reason, department and state.
- Chatter tracking on records.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Exit Interviews** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
