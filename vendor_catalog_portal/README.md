# Portail Catalogue Fournisseur (vendor_catalog_portal)

Le fournisseur maintient son catalogue (prix, délais, références) via un portail ; l'acheteur valide chaque proposition avec un diff clair avant application.

## Problème
Les prix et délais produits vivent sur des tarifs papier que les fournisseurs mettent à jour sans prévenir ; l'acheteur les découvre sur la facture.

## Fonctionnalités
- Propositions du fournisseur via portail
- Diff avant/après en un écran
- Validation par l'acheteur tracée
- Historique des révisions
- Alerte de tarif expiré

## Dépendances
- `purchase`, `product`, `mail`
