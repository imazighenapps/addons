Overview

All Key Interfaces in One Module

Dashboard

Compliance Dashboard

  • Global compliance score with visual status.
  • Breakdown by entity type (Persons, Partners, Vehicles, Equipment, Other).
  • Alert tracking (90-day, 30-day, 7-day, and escalation alerts sent).
  • Top document types, upcoming expirations, and recently expired documents.
  • Quick navigation to related views and records.

Renewal

Renewal Wizard

  1. Open an active document and click Renew Document.
  2. Enter the new dates, reference, responsible user, notes, and attachments.
  3. Confirm: the old document is marked as Renewed, a new active document is created, and the renewal history is linked.

Depending on the document type, an attachment may be required during renewal.

Configuration

Document Types & Alert Rules

  • Types applicable by entity (person, partner, vehicle, equipment, other, or all).
  • Configurable thresholds: 1st/2nd/3rd alerts (days before expiry) and escalation (days after expiry).
  • Option to require an attachment on renewal, plus color, code, and active flag.
  • Access related documents directly from the document type.

Analytics & Compliance Report

  • Analytics: graph and pivot views (distribution by entity/type/status, measures).
  • PDF Compliance Report: summary (valid/expiring/expired/rate) and a printable detailed table from documents.

Alert Automation

  • Cron "Send Expiry Alerts": daily notifications (90/30/7 days) and post-expiry escalation based on document type settings.
  • Cron "Refresh Expiry States": daily recalculation of days left and status.
  • 4 preconfigured email templates (90-day, 30-day, 7-day, escalation), fully customizable.
  • Chatter logging for alerts, renewals, and archiving actions.

Security & Multi-Company

  • Access groups: User (read/create/edit according to rules) and Manager (full administration, types, deletions).
  • Access rights and domain restrictions adapted to Odoo 18 (unified ir.access model).
  • Multi-company isolation on documents (company_id).
  • Configuration menu restricted to managers; compatible with Community & Enterprise.
Installation

Quick Installation

  1. Copy the smart_document_expiry folder into your addons path.
  2. Restart the Odoo server and update the apps list.
  3. Install Smart Document Expiry Tracker (demo data is available for quick testing).
# Example (Docker / CLI)
odoo -d <db_name> -i smart_document_expiry --stop-after-init
# Add your DB/host parameters according to your environment
