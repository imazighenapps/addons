# Contrôles Périodiques en Stockage (stock_storage_periodic_checks)

Contrôles périodiques de stockage : plan de contrôle par famille/zone (intervalle, points), rondes enregistrées et non-conformités routées vers le responsable.

## Problème
Les marchandises qui dorment des mois ne subissent aucun contrôle : dégradation, emballage mouillé ou rongé se découvre à l'expédition.

## Fonctionnalités
- Plan de contrôle par famille/zone
- Rondes enregistrées datées
- Non-conformités routées
- Historique par emplacement
- Rapport de conformité

## Dépendances
- `stock`, `mail`
