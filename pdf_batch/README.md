# PdfBatch - Batch PDF Printing

## The problem

Odoo prints one PDF per invoice. A accountant who must send 80 invoices spends an hour clicking and renaming files.

## The solution

Select invoices, preview, merge them into one numbered PDF and archive the result, instead of printing one document at a time.

## Main features

- Select invoices and merge them into one PDF.
- Cover page with total and period.
- Optional watermark.
- Preview before printing.
- PDF archived as attachment.
- Multi-company.

## Installation

1. Install the module from the Apps list.
2. Open the **PDF Batch** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
