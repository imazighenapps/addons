# Smart Financial Dashboard - CFO Pack Pro

Professional financial dashboard for Odoo 19 with intelligent cash flow forecasting, profitability analysis, and risk management.

## Features

- **Executive Financial Cockpit**: Real-time KPIs and metrics
- **Cash Flow Forecast Engine**: 180-day intelligent projections
- **Profitability Analysis**: Multi-dimensional margin analysis
- **Risk Management**: DSO/DPO tracking and customer risk scoring
- **Multi-Company Consolidation**: Group-level financial reporting
- **Smart Alerts**: Automated financial threshold monitoring

## Installation

1. Copy module to addons directory
2. Update apps list
3. Install "Smart Financial Dashboard - CFO Pack Pro"
4. Configure settings under CFO Dashboard > Configuration

## Requirements

- Odoo 19.0
- account, sale_management, purchase, stock modules
