# LegalArchivePro

Tamper-Evident Legal Document Archive

## The problem

Legal documents are kept for years in shared folders where anyone can modify them. No one can prove during an audit that an invoice or a contract was never altered, files are never purged on time, and there is no trace of who accessed what and when.

## The solution

Keep invoices, bills, contracts and payslips in a tamper-evident archive with SHA-256 hash chaining, retention expiry dates and a complete audit log.

## Main features

- Central register for invoices, bills, contracts and payslips.
- One-click SHA-256 sealing with hash chaining between documents.
- Verification that detects any modification of the archived file.
- Retention period in years with an automatic expiry date.
- File purge blocked until the retention period has elapsed.
- Immutable audit log for every archive action.
- Multi-company archive with one hash chain per company.
- Searchable archive with no external Python dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Legal Archive** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
