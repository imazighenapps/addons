# RebateBook

Rebates Accrued On Time

## The problem

Volume rebates are promised, tracked in spreadsheets and settled late: accruals drift from invoices and nobody can state the amount owed at year end.

## The solution

Accrue the annual volume rebate you promised per customer, watch it grow with each invoice and settle it once a year.

## Main features

- A rebate contract per customer with period, rate and target amount.
- Accrual lines tied to the contract with invoice reference and value.
- Totals for accrued, settled and remaining amounts stored on the contract.
- A settlement action that closes the contract with a dated payout.
- One screen to review contracts and their accrual history together.
- Search filters for open and settled contracts.
- Validation that blocks negative amounts and bad date ranges.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Rebates** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
