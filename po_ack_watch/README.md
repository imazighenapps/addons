# AckWatch

Signed By The Supplier

## The problem

Supplier acknowledgements are buried in emails, so buyers cannot tell which purchase orders are confirmed, which are overdue and what has already been chased.

## The solution

Track which supplier confirmed which purchase order and chase the acknowledgements you are still waiting for.

## Main features

- A tracking record per purchase order with supplier and references.
- Sent date, acknowledgement deadline and confirmed acknowledgement date.
- Acknowledge action that stamps the supplier confirmation details.
- Follow-up notes to log every chase sent to the supplier.
- Computed counters for follow-ups and days waiting stored on the record.
- Search filters for unacknowledged and overdue purchase orders.
- Validation that refuses impossible dates and duplicate acknowledgements.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **PO Acknowledgements** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
