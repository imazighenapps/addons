# ProjectMargin - Project Profitability and Budget Control

## The problem

A project is quoted with a healthy margin and then quietly bleeds to death: extra days, unbilled subcontractors and forgotten expenses pile up in spreadsheets that nobody reconciles. The real margin is only discovered at the closing meeting, when there is nothing left to arbitrate.

## The solution

Track budgeted and actual revenue and cost per project, watch the margin rate and get flagged before a cost overrun eats the profit.

## Main features

- Budget revenue and budget cost per project.
- Revenue and cost lines with category and invoice reference.
- Actual revenue, cost, margin and margin rate, live.
- Cost ratio against the budget cost.
- Overrun alert above a configurable threshold.
- Draft, running and closed states with an audit trail.
- Budget and lines locked once the project is closed.
- Multi-company and multi-currency, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Project Margin** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
