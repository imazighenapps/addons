# KeyBook

Every Key Has An Owner

## The problem

Keys and badges are tracked on paper, so nobody knows who holds which key or since when and missing items are noticed too late.

## The solution

Know exactly who holds which key or badge since when, and chase the ones that never came back.

## Main features

- A register of keys and badges with label, type and reference.
- The current holder and the date each key was issued.
- The return date stamped when a key comes back.
- A clear state from issued to returned.
- One missing-keys screen for everything still out.
- A return before the issue date is refused for you.
- Chatter traceability on every custody record.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Keys & Badges** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
