# Élagage du Chatter (chatter_prune_tool)

Élagage du chatter : rétention par modèle, archivage optionnel des messages supprimés, aperçu avant exécution et journal.

## Problème
Les fils de messages et notes internes s'accumulent des années : la base grossit sans valeur opérationnelle.

## Fonctionnalités
- Rétention par modèle
- Archivage optionnel
- Aperçu avant exécution
- Journal d'élage
- Mode test

## Dépendances
- `base`, `mail`
