# SampleKit

Samples That Sell Or Come Back

## The problem

Samples handed to prospects disappear into notebooks and shelves: no one knows who received what, the follow-up date exists in nobody's calendar and the cost of the samples is never tied to the orders they generated.

## The solution

Track the samples you hand to prospects: to whom, when, consumed or returned, with the follow-up they deserve.

## Main features

- A catalog of samples with category and follow-up delay.
- Hand-outs with recipient, quantity and date.
- The follow-up date computed and stored on each hand-out.
- One state per unit: outside, consumed or returned.
- One click to attach the order the sample sold.
- A return stamped with the exact date it came back.
- One follow-up queue for everything still outside.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Sample Log** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
