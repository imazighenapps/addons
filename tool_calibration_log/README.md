# ToolCalibrationLog

Tool and Instrument Calibration Register

## The problem

Calibration schedules and records tracked manually lead to overdue tools and poor audit traceability.

## The solution

Record tool calibrations with dates, provider, result, certificate reference and next due date to track calibration history.

## Main features

- Calibration records with tool, date and provider.
- Result, certificate reference and notes.
- Next due date and responsible person.
- Draft, scheduled, done and cancelled states.
- Calibration history per tool/instrument.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Tool Calibration** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
