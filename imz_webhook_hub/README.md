# Hub de Webhooks (webhook_hub)

Hub de webhooks : déclencheurs universels sortants, endpoints entrants avec signature, retries avec backoff et console de test.

## Problème
Rattacher Odoo à d'autres outils exige du code à chaque fois : pas de plateforme de webhooks interne.

## Fonctionnalités
- Déclencheurs sortants
- Endpoints entrants
- Signature HMAC
- Retries avec backoff
- Console de test

## Dépendances
- `base`, `mail`
