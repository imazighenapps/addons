# Diff d'Instantanés (snapshot_diff_compare)

Instantanés comparables : capture d'un périmètre de modèles, diff champ par champ entre deux captures, rapport des changements par utilisateur.

## Problème
« Qu'est-ce qui a changé depuis la semaine dernière ? » est une question impossible à répondre sans comparaison manuelle.

## Fonctionnalités
- Captures de périmètres
- Diff champ par champ
- Changements par utilisateur
- Rapport exportable
- Captures planifiées

## Dépendances
- `base`, `mail`
