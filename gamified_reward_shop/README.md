# Boutique de Récompenses (gamified_reward_shop)

Boutique de récompenses : catalogue de privilèges et bénéfices échangeables contre des points, stock de privilèges limités et journal des échanges.

## Problème
Les points gagnés (fidélité, gamification interne) n'ont pas de magasin : la valeur reste théorique.

## Fonctionnalités
- Catalogue de privilèges
- Échanges contre points
- Privilèges limités
- Journal des échanges
- Analyse d'usage

## Dépendances
- `base`, `account`, `mail`
