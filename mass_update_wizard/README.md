# Mise à Jour Massive Assistée (mass_update_wizard)

Assistant de mise à jour massive : sélection par filtre, aperçu avant/après, règles de valeur, journal d'exécution avec annulation datée.

## Problème
Corriger un champ sur 10 000 lignes passe par du code ou des manipulations risquées sans trace.

## Fonctionnalités
- Sélection par filtres
- Aperçu avant/après
- Règles de valeur (fixe, formule)
- Journal avec annulation
- Rapport d'exécution

## Dépendances
- `base`, `mail`
