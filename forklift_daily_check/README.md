# Contrôle Quotidien des Chariots (forklift_daily_check)

Checklist journalière par chariot (freins, fourche, klaxon, batteries, fuites), défauts consignés avec photos, alerte maintenance automatique.

## Problème
Les chariots élévateurs doivent être vérifiés avant chaque prise de poste : les checklists papier se perdent et les défauts remontent avec des jours de retard.

## Fonctionnalités
- Checklist avant-poste
- Défauts avec photos
- Alerte maintenance
- Historique par chariot
- Tableau de conformité

## Dépendances
- `stock`, `maintenance`, `mail`
