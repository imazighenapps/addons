# Session de Paiement (payment_run_planner)

Sessions de paiement : sélection par critères (dates, devises, fournisseurs), total de session, approbation hiérarchique, génération de paiements et fichier bancaire.

## Problème
Payer les fournisseurs se fait facture par facture, sans vue de session ni approbation du lot.

## Fonctionnalités
- Sélection par critères
- Total et plafond de session
- Approbation hiérarchique
- Génération des paiements
- Historique des sessions

## Dépendances
- `account`, `mail`
