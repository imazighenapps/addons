# Échéancier de Facturation Projet (billing_schedule)

Échéancier contractuel : dates/montants/conditions par projet, génération des factures à échéance, écart planifié vs émis et relance des retards.

## Problème
Les échéanciers de facturation contractuels (dates, conditions, montants) vivent dans le contrat PDF : les émissions dérivent.

## Fonctionnalités
- Échéancier par projet
- Génération à échéance
- Écart planifié vs émis
- Relances des retards
- Prévision de revenus

## Dépendances
- `sale`, `project`, `account`, `mail`
