# MeterBook

Meters Read, Consumption Known

## The problem

Utility meters are read on a hand-written note that lives in a drawer, the values are never kept in one place, and when a bill looks wrong nobody can rebuild the series of readings to prove what the site really consumed.

## The solution

Keep an Odoo register of every electricity, water and gas meter, file the periodic readings in order and see the consumption of each period computed for you.

## Main features

- A register of electricity, water, gas and other utility meters.
- Dated readings with the reader who took them.
- One reading per meter and per day, enforced for you.
- The delta from the previous reading computed and stored.
- Meters show their last value, last date and reading count.
- Readings follow the meter in a clean, dated history.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Meter Book** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
