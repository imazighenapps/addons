# Options de Financement sur Devis (quote_financing_options)

Module d'options de financement sur le devis : calcul de mensualités selon durée et apport, comparaison affichée, bloc d'information financement dans le PDF et suivi du dossier envoyé au partenaire.

## Problème
Le client veut payer en leasing : le commercial recompte les mensualités à la main et le partenaire financier attend un dossier propre.

## Fonctionnalités
- Calcul de mensualités par durée
- Comparaison des scénarios de financement
- Bloc financement dans le PDF
- Statut du dossier partenaire
- Historique des offres de financement

## Dépendances
- `sale`, `mail`
