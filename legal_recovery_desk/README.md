# Suivi Contentieux Créances (legal_recovery_desk)

Registre contentieux : étapes procédurales datées, honoraires d'avocat/huissier, issues et écritures de sortie.

## Problème
Les procédures judiciaires de recouvrement (injonction de payer, huissier, audience) sont suivies hors ERP.

## Fonctionnalités
- Étapes procédurales datées
- Frais judiciaires
- Issues et écritures
- Statistiques par agence/huissier

## Dépendances
- `account`, `mail`
