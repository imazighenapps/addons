# DeliverySlot - Delivery Time Slots and Capacity Planning

## The problem

Deliveries are promised on the phone without looking at the dock. Everybody picks the same 08:00 window, three trucks arrive at once, the crew unloads in a hurry and the customer waits in the yard. Nobody knows how many places are left, and a stocktake day still gets bookings.

## The solution

Plan weekly delivery windows with a capacity, book customers into a slot, close blackout days and stop the dock from being overloaded.

## Main features

- Weekly delivery windows per weekday.
- Capacity enforced at confirmation.
- Bookings per customer, date and reference.
- Weekday control on every booking.
- Blackout days per warehouse or per slot.
- Places left for today, always visible.
- Confirm, done, cancel and reset workflow.
- Chatter, multi-company, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Delivery Slots** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
