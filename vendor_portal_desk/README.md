# Portail Fournisseur Complet (vendor_portal_desk)

Portail fournisseur : consultation de ses commandes et de leurs statuts, dépôt de documents, avis d'expédition, suivi des factures et paiements, dans un périmètre strictement filtré.

## Problème
Les fournisseurs n'ont aucune visibilité : ils appellent pour savoir si une commande est payée, si une facture est validée, quand livrer.

## Fonctionnalités
- Commandes visibles filtrées
- Dépôt de documents
- Suivi factures et paiements
- Messagerie tracée par commande
- Journal d'accès

## Dépendances
- `purchase`, `account`, `mail`
