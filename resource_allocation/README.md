# Allocation des Ressources (resource_allocation)

Matrice d'allocation : projet × ressource × période, réservations fermes/tentatives, conflits détectés et vues de disponibilité.

## Problème
Les ressources clés (experts, machines) sont réservées oralement : conflits entre projets découverts tard.

## Fonctionnalités
- Matrice d'allocation
- Réservations fermes/tentatives
- Détection de conflits
- Vue disponibilité
- Historique des arbitrages

## Dépendances
- `project`, `hr`, `mail`
