# Reçus Fiscaux de Dons (donation_receipts)

Générateur de reçus fiscaux : numérotation continue, rattachement au don, campagne fiscale annuelle, attestations PDF et registre de contrôle.

## Problème
Émettre des reçus fiscaux numérotés et traçables pour les dons est une obligation administrative lourde pour les associations.

## Fonctionnalités
- Numérotation continue
- Rattachement au don
- Campagne annuelle
- Attestations PDF
- Registre de contrôle

## Dépendances
- `account`, `mail`
