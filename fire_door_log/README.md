# FireDoorLog

Fire Door Inspection Register

## The problem

Fire door checks tracked on paper leave defects and due dates unclear.

## The solution

Record fire door inspections with location, type, dates and hinge, seal, closer and gap results.

## Main features

- Door records with reference, location and type.
- Inspection date and next inspection date.
- Hinge, seal, closer and gap check results.
- Responsible inspector and notes.
- Draft, passed, defect and cancelled states.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Fire Doors** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
