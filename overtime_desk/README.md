# OverTime

Extra Hours, Properly Owned

## The problem

Overtime is requested informally and approved implicitly, so teams cannot see how many extra hours are banked and payroll inherits disputes instead of clean records.

## The solution

Collect overtime requests per employee, approve them properly and keep the hours each team banked.

## Main features

- Overtime requests per employee with date and reason.
- A draft, approved and rejected workflow for every request.
- Requested and approved hours stored on each request.
- Validation that refuses zero or negative hour entries.
- Grouping by employee and state for team-level review.
- Chatter tracking for decisions and clarifications.
- Simple actions to approve or reject pending requests.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Overtime Desk** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
