# Habilitations de Sécurité Privée (private_security_licences)

Registre des habilitations : cartes avec validité et conditions, affectations aux sites compatibles, renouvellements pilotés.

## Problème
Les cartes professionnelles des agents de sécurité ont des validités et conditions : l'entreprise découvre les caducités aux contrôles.

## Fonctionnalités
- Cartes avec validité
- Affectations compatibles
- Renouvellements pilotés
- Contrôle avant mission
- Historique par agent

## Dépendances
- `hr`, `mail`
