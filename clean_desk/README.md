# HygieneBook

Cleaned, Dated, Proven

## The problem

Cleaning is planned informally and proven on paper, so areas waiting for cleaning and the dated proof of execution are hard to show.

## The solution

Schedule who cleans what, when and how, keep the dated proof and show the areas still waiting.

## Main features

- Cleaning plans with area, frequency, method and owner.
- Execution logs with schedule, performer and completion date.
- A workflow from planned to done or cancelled.
- Pending executions filtered for areas still waiting.
- Completion refused when the execution date is missing.
- Stored counters for executions and pending work.
- Notes kept on each plan and execution for the audit file.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Hygiene Book** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
