# PestWatch

Stations Checked, Traced

## The problem

Pest control stations are tracked on maps and contractor PDFs, so overdue checks and findings are hard to prove and the HACCP file cannot be produced from one register.

## The solution

Log the pest control stations of the site: checks, findings and the contractor visits the HACCP file wants.

## Main features

- One station register with code, location, type and check interval.
- Next check date and overdue flag computed and stored on every station.
- Inspection history with date, findings, severity and contractor.
- Confirming an inspection refreshes the station next due date.
- Active and out-of-service states with an audit trail.
- Counters for inspection count and open findings stored for filters.
- An inspection dated in the future is refused for you.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Pest Watch** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
