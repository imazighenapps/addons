# ShrinkWatch

Losses With Names

## The problem

Stock adjustments are recorded as anonymous totals, so nobody knows which location, product or reason is driving shrinkage until the money is already gone.

## The solution

Turn every stock adjustment into a shrinkage analysis by location, product and reason, with the cost attached.

## Main features

- A shrinkage register with product, location and reason on every entry.
- Quantity and unit cost with the loss value computed and stored.
- States to draft, confirm and close each adjustment entry.
- Stored counters and totals ready for filters and analysis views.
- One screen to review confirmed and closed losses by reason.
- Search filters and group-by views for location, product and reason.
- A close date stamped when the entry is finalized.
- Multi-company isolation with per-company records.

## Installation

1. Install the module from the Apps list.
2. Open the **Shrinkage** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
