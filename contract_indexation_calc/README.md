# Indexation Contractuelle des Prix (contract_indexation_calc)

Calculateur d'indexation : formule contractuelle par contrat, indice annuel saisi, nouveau prix calculé, aperçu par client et application à la date d'anniversaire.

## Problème
Les contrats à indexation annuelle (ILC, indices sectoriels) exigent un calcul en formule (part fixe + part indexée) refait à la main pour chaque client.

## Fonctionnalités
- Formule contractuelle par contrat
- Indice annuel référencé
- Calcul du nouveau prix
- Aperçu par client avant application
- Application à l'anniversaire du contrat

## Dépendances
- `sale`, `account`, `mail`
