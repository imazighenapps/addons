# Délai Dock-to-Stock (stock_dock_to_stock_kpi)

Indicateur dock-to-stock : mesure par réception (chargé, contrôlé, rangé, disponible), cibles par flux, alerte sur les réceptions qui traînent et historique hebdomadaire.

## Problème
Le temps entre déchargement et mise à disposition en stock n'est mesuré nulle part : les marchandises dorment sur les aires d'attente.

## Fonctionnalités
- Mesure par étape de réception
- Cibles par flux
- Alerte sur les réceptions traînantes
- Historique hebdomadaire
- Comparaison entrepôts

## Dépendances
- `stock`, `mail`
