# Cycles de Stérilisation (clinic_steril_cycles)

Traçabilité stérilisation : paniers d'instruments par cycle, paramètres du cycle, et lien usage→patient pour l'enquête de traçabilité.

## Problème
Les cabinets perdent la trace de quel lot d'instruments a passé quel cycle de stérilisation et servi quel patient.

## Fonctionnalités
- Paniers d'instruments par cycle
- Paramètres du cycle consignés
- Lien usage→patient
- Alerte d'instruments non tracés
- Registre d'inspection prêt

## Dépendances
- `stock`, `mail`
