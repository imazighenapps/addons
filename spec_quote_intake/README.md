# Intake de Devis Technique (spec_quote_intake)

Portail d'intake de devis technique : formulaire structuré, upload de specs obligatoire, rattachement automatique au prospect et file de chiffrage avec délai cible.

## Problème
Les demandes de devis techniques arrivent en pièce jointe (plans, cahier des charges) : elles se noient dans la boîte mail et la qualification prend des jours.

## Fonctionnalités
- Formulaire d'intake structuré
- Upload de specs obligatoire
- Rattachement au prospect
- File de chiffrage avec délai cible
- Statistiques de délai de réponse

## Dépendances
- `sale`, `crm`, `portal`, `mail`
