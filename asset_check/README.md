# AssetCheck

Fix What Exists, Cancel The Rest

## The problem

Fixed asset counts are done on paper and reconciled in spreadsheets, so missing and moved assets stay in the register while the floor reality is never captured with proof.

## The solution

Count fixed assets on the floor with tags and statuses, and reconcile the register with what really exists.

## Main features

- Physical asset count campaigns with a planned date and owner.
- Count lines with asset tag, description and expected location.
- Found, missing and moved results with the observed location.
- Stored totals for found, missing and moved assets per campaign.
- Draft, in progress and closed states with a dated close.
- Closed campaigns locked to preserve the verified results.
- One screen for campaigns still in progress on the floor.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Asset Check** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
