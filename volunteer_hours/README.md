# VolunteerLog

Volunteer Hours Tracking

## The problem

Volunteer hours tracked informally are difficult to consolidate, validate and report.

## The solution

Log volunteer hours with volunteer, date, hours and activity, validate submitted entries, and report time by volunteer and period in a company-safe register.

## Main features

- Hour entries with volunteer, date, hours and activity.
- Draft, submitted and validated states.
- Actions to submit and validate entries.
- Search and group by volunteer, state and period.
- Chatter tracking on entries.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Volunteer Hours** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
