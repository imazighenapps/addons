# Clôture d'Exercice Automatique (year_end_close_wizard)

Assistant de clôture : calcul des soldes de résultat, écriture de clôture/reprise générée, contrôles avant validation et journal d'audit de clôture.

## Problème
L'OD de clôture d'exercice (soldes de résultats, transferts) est saisie à la main chaque année avec des erreurs récurrentes.

## Fonctionnalités
- Calcul des soldes de résultats
- Écriture de clôture générée
- Contrôles avant validation
- Journal d'audit de clôture
- Rejeu possible

## Dépendances
- `account`, `mail`
