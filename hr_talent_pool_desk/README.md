# Réserve de Candidatures (hr_talent_pool_desk)

Réserve de candidatures par métier : pool segmenté (compétences, disponibilité, avis), rappel des profils quand un poste s'ouvre, campagnes de re-contact tracées.

## Problème
Les bons candidats non retenus partent définitivement : aucun réexamen quand un poste équivalent rouvre.

## Fonctionnalités
- Pool segmenté par métier
- Rappel automatique à l'ouverture de poste
- Campagne de re-contact tracée
- Statut et avis conservés
- Statistiques de conversions pool → embauche

## Dépendances
- `recruitment`, `mail`
