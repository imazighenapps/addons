# Bons à Tirer (print_bat_workflow)

Workflow de bon à tirer : versions de fichier, approbation client datée, verrouillage de la mise en production et refus documentés.

## Problème
Les imprimeurs valident les fichiers clients par email : quelle version a été approuvée ? Le retard du BAT bloque toute la planification.

## Fonctionnalités
- Versions de fichiers suivies
- Approbation client datée
- Verrou avant mise en production
- Refus documentés
- Historique par job

## Dépendances
- `sale`, `documents`, `mail`
