# Aging AR/AP Avancé (partner_aging_desk)

Analyse d'ancienneté clients (AR) et fournisseurs (AP) par tranches (0-30, 31-60, 61-90, >90 jours) avec totaux, DSO/DPO pondéré, actions recommandées et exports PDF/CSV.

## Dépendances
- `account`

## Utilisation
Menu **Comptabilité → Rapports → Aging AR/AP avancé** : choisir type (AR/AP), date d'analyse, optionnellement des partenaires, puis **Calculer**.

## Internationalisation
7 langues : en_US, fr_FR, ar_001, es_ES, de_DE, pt_BR, zh_CN.
