# Superviseur des Tâches Planifiées (cron_watch)

Supervision des crons : retards, échecs, durées, alertes et redémarrage contrôlé, avec historique par tâche.

## Problème
Les crons échouent silencieusement : factures non générées, relances manquées, synchronisations bloquées.

## Fonctionnalités
- Alertes de retard
- Détection d'échec
- Durées par run
- Redémarrage contrôlé
- Historique

## Dépendances
- `base`, `mail`
