# SignDesk

Proof In Every Hand

## The problem

Delivery disputes are hard to resolve because teams lack a consistent record of who received the shipment, when it arrived and whether signature or photo proof was collected.

## The solution

Capture the signature and photo that prove each delivery reached its customer in the right condition.

## Main features

- Delivery proof register with customer and reference details.
- Recipient, signature and photo evidence captured per delivery.
- Pending and signed workflow with dated confirmation action.
- Stored indicators for missing signature or photo evidence.
- Filters for pending, signed and incomplete proof records.
- List, kanban and form views for logistics follow-up.
- Multi-company isolation for independent operations.

## Installation

1. Install the module from the Apps list.
2. Open the **Delivery Proofs** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
