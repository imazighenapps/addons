# Atelier d'Import (import_desk)

Atelier d'import : mappings sauvegardés par source, validation préalable, prévisualisation et journal d'import avec annulation.

## Problème
Les imports récurrents (fournisseurs, tarifs) refont le mapping à chaque fois : erreurs et pertes de temps.

## Fonctionnalités
- Mappings sauvegardés
- Validation préalable
- Prévisualisation
- Journal avec annulation
- Récurrence

## Dépendances
- `base`, `mail`
