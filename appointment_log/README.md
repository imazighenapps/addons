# AppointmentLog

External Appointment and Visit Log

## The problem

Appointment outcomes and follow-ups noted informally are easy to lose, leading to missed next actions.

## The solution

Log external appointments with contact, date, subject, outcome and next actions, track planned/done/cancelled states, and report follow-ups in a company-safe register.

## Main features

- Appointment records with contact, date, subject and responsible.
- Outcome, next action and follow-up date fields.
- Planned, done and cancelled states.
- Actions to mark done or cancel.
- Search and group by contact, responsible and state.
- Chatter tracking on appointments.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Appointments** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
