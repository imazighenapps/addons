# ConsentBook

Consent You Can Show

## The problem

Consent proofs are scattered across tools and people, so teams cannot reliably show when a contact agreed, through which source, or when the consent was withdrawn.

## The solution

Keep the dated proof of every marketing consent, its source and withdrawal, the only defence that counts.

## Main features

- A dated register of marketing consents per contact and purpose.
- Source and channel captured for every consent you collect.
- Granted and withdrawn dates with a written withdrawal reason.
- Active, withdrawn and expired states with a clear audit trail.
- A proof reference or note kept on every record.
- Contact consent counters stored for quick review.
- Multi-company isolation out of the box.
- A defensible history that can be shown when it matters.

## Installation

1. Install the module from the Apps list.
2. Open the **Consents** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
