# CreditGuard - Customer Credit Control

## The problem

Sales keep confirming orders for customers who already owe too much, and finance discovers the problem weeks later when the invoice is never paid.

## The solution

Live credit limits for every customer, with automatic blocking of over-limit orders and a controlled override workflow.

## Main features

- Live credit profile per customer with limit, exposure and available amount.
- Automatic exposure from open invoices and confirmed orders.
- Overdue amount and average payment delay.
- Warn or block mode on order confirmation.
- Override request with approval workflow and audit trail.
- Smart button on quotations showing the credit status.
- Multi-company and multi-currency.

## Installation

1. Install the module from the Apps list.
2. Open the **Credit Control** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
