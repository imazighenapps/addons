# DocFlow

Read, Signed, Compliant

## The problem

Controlled document revisions are shared by email: acknowledgements are missing, the distribution list is a spreadsheet and the quality audit has no proof that everyone read the current version.

## The solution

Distribute each controlled document revision to the right people and collect the acknowledgements ISO wants.

## Main features

- A register of controlled documents with code, revision and effective date.
- Distribution lines with recipient, sent date and acknowledgement date.
- Acknowledgements stamped with the exact date the recipient confirmed.
- Open and acknowledged counts computed and stored on every document.
- One pending-acknowledgements screen for everyone who still has to sign.
- An acknowledgement before the sent date is refused for you.
- Duplicate distribution to the same recipient is refused for you.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Documents** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
