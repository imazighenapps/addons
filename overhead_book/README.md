# Répartiteur de Frais Généraux (overhead_book)

Moteur d'allocation : clés de répartition paramétrables (heures, CA, effectif), écritures analytiques mensuelles et marge fully-loaded par projet.

## Problème
Les frais généraux (locaux, support, direction) ne sont pas alloués aux projets : la marge réelle par projet est faussée.

## Fonctionnalités
- Clés de répartition paramétrables
- Allocation mensuelle automatique
- Marge avec frais généraux inclus
- Comparaison des clés alternatives
- Journal des allocations

## Dépendances
- `project`, `analytic`, `mail`
