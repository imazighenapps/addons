# VehicleBook

Company Vehicle Reservation

## The problem

Shared vehicles reserved informally cause conflicts and delays because availability is not enforced or visible in one place.

## The solution

Reserve company vehicles with requester, time range and purpose, prevent overlapping bookings per vehicle, and track reservations through a clear workflow in a company-safe register.

## Main features

- Vehicle catalogue with plate, seats and active flag.
- Bookings with requester, time range, destination and purpose.
- Overlap detection blocking conflicting vehicle reservations.
- Draft, confirmed, done and cancelled states.
- Search and group by vehicle, requester and period.
- Chatter tracking on bookings.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Vehicle Booking** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
