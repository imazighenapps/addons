# MilestoneBill

Bill What Was Delivered

## The problem

Tie invoicing to project milestones so you bill what was delivered and never miss a billable event.

## The solution

Tie invoicing to project milestones so you bill what was delivered and never miss a billable event.

## Main features

- Milestones tracked in a dedicated register.
- Billable events recorded with clear ownership and dates.
- Invoiced milestones visible so nothing slips through.
- Draft, confirmed and done states with an audit trail.
- Computed totals and counts kept up to date.
- Active flag to archive records no longer needed.
- Company-aware records for multi-company use.
- Mail chatter for notes and follow-up.

## Installation

1. Install the module from the Apps list.
2. Open the **MilestoneBill** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
