Feature 01

Invite, Don't Type for Them

Create an acknowledgment from the purchase order and send the vendor a secure portal link with an expiration date. The supplier answers there — your PO stays untouched, and any PO change auto-supersedes the old version.

  • ✓One-click ack from the PO
  • ✓Token-secured portal, no login
  • ✓Expiration date per invitation
  • ✓Auto-versioning on PO changes
Feature 02

Line-by-Line Proof

Each line is confirmed, partially confirmed or rejected — with a mandatory reason on partials and rejects. Quantity and date differences compute automatically, and contested answers raise a buyer follow-up activity.

  • ✓Confirmed / partial / rejected lines
  • ✓Qty and date difference metrics
  • ✓Buyer activity when contested
  • ✓Chatter log + PO counter
