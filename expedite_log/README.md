# PremiumWatch

Urgency Has A Price

## The problem

Expedited and emergency purchases add hidden premiums that are never totaled, so repeat urgency and its extra cost stay invisible.

## The solution

Log every expedited or emergency purchase with the extra premium it cost and show who triggered it most.

## Main features

- A log entry per expedited or emergency purchase.
- Normal cost and actual cost recorded on every entry.
- The urgency premium computed and stored for analysis.
- Requester and reason kept to spot repeat patterns.
- States to follow an entry from draft to confirmed.
- A screen focused on costly premium entries.
- Actual and normal costs must stay non-negative.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Premium Watch** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
