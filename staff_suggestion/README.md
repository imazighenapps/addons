# IdeaBox

Employee Suggestion and Improvement Log

## The problem

Employee suggestions collected informally are lost or untracked, with no clear review status or feedback loop.

## The solution

Collect employee suggestions with category, description and expected benefit, review them through a decision workflow, and track outcomes in a company-safe register.

## Main features

- Suggestions with submitter, category, title and description.
- Expected benefit and reviewer comment fields.
- Draft, submitted, under review, accepted, rejected and done states.
- Review actions for decisions and completion.
- Search and group by category, state and period.
- Chatter tracking on suggestions.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Suggestions** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
