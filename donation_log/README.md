# DonationLog

Donation and Contribution Tracking

## The problem

Donation records kept in spreadsheets are inconsistent and hard to summarize by donor and period.

## The solution

Record donations with donor, date, amount and purpose, track received and acknowledged states, and report contributions by donor and period in a company-safe register.

## Main features

- Donation records with donor, date, amount and purpose.
- Payment method and reference fields.
- Draft, received and acknowledged states.
- Actions to mark received and acknowledged.
- Search and group by donor, state and period.
- Chatter tracking on donations.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Donations** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
