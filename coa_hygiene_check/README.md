# Contrôle Qualité du Plan Comptable (coa_hygiene_check)

Score d'hygiène du plan comptable : liste des anomalies (doublons, inutilisés, non-lettrables, sens inversé) et plan d'action de nettoyage.

## Problème
Les plans comptables s'encrassent : doublons de libellés, comptes inutilisés, sens anormal, comptes orphelins.

## Fonctionnalités
- Score global d'hygiène
- Liste d'anomalies triée
- Actions de correction
- Historique du score
- Export Excel

## Dépendances
- `account`, `mail`
