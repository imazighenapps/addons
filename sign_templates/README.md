# Bibliothèque de Gabarits de Signature (sign_templates)

Gabarits de signature : placement de champs sauvegardé par document type, texte, ordre des signataires et lancement en un clic.

## Problème
Chaque demande de signature est refaite : placement des champs, texte d'accompagnement, destinataires types.

## Fonctionnalités
- Gabarits par document type
- Placement sauvegardé
- Lancement en un clic
- Statistiques d'usage
- Journal

## Dépendances
- `base`, `mail`
