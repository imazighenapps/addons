# Accueils de Crèche (nursery_slot_plan)

Planning d'accueil par demi-journée avec capacité, ratio d'encadrants légal vérifié, présences enregistrées et adaptations gérées.

## Problème
Les crèches gèrent les accueils (quotas, ratios d'encadrants, adaptations) sur un planning papier quotidien.

## Fonctionnalités
- Accueils par demi-journée avec capacité
- Ratio encadrants/enfants vérifié
- Présences enregistrées
- Adaptations gérées
- Alertes de ratio dépassé

## Dépendances
- `hr`, `sale`, `mail`
