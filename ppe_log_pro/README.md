# GuardKit

Every Vest, Helmet And Glove Tracked

## The problem

Protective equipment is handed out from a cabinet and noted in a paper register: the inspectorate question has no answer, used gear stays assigned forever and renewals happen on nobody's calendar.

## The solution

Keep the register of every protective equipment you issue: what each employee received, in which size, when it must be renewed and whether it came back.

## Main features

- A register of protective equipment with category and standard.
- A renewal period per equipment, in months.
- Issues with employee, size, quantity and issue date.
- The renewal date computed and stored on every issue.
- Returns stamped with the exact date the gear came back.
- One open-issues screen for everything still in service.
- A return before its issue is refused for you.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **PPE Book** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
