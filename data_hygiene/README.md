# Hygiène des Données (data_hygiene)

Nettoyeur de données : règles de normalisation (téléphones, emails, codes), détection d'incohérences, correction en masse planifiée et score de qualité.

## Problème
Téléphones mal formatés, emails invalides, codes doublons polluent les bases et cassent les campagnes.

## Fonctionnalités
- Règles de normalisation
- Détection d'incohérences
- Correction en masse
- Score de qualité
- Planification

## Dépendances
- `base`, `mail`
