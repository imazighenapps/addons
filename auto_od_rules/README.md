# Moteur d'OD Automatiques (auto_od_rules)

Moteur de règles : définition d'OD récurrentes par formule (comptes, clés, montants calculés), exécution planifiée, aperçu avant comptabilisation et historique.

## Problème
Les écritures récurrentes par règles (répartitions, régularisations internes, fees) sont saisies chaque mois à la main.

## Fonctionnalités
- Règles paramétrables avec formules
- Exécution planifiée mensuelle
- Aperçu avant validation
- Historique des exécutions
- Désactivation temporaire

## Dépendances
- `account`, `mail`
