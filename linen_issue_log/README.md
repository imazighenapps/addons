# LinenIssueLog

Linen Issue and Return Register

## The problem

Manual linen tracking leaves outstanding items, losses and returns unclear.

## The solution

Track linen issues and returns with item, quantity, recipient, dates and states to control circulation and outstanding items.

## Main features

- Issue/return records with item, quantity and recipient.
- Issue, expected return and actual return dates.
- Condition and notes for loss or damage.
- Draft, issued, returned and cancelled states.
- Search and tracking of outstanding items.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Linen Issues** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
