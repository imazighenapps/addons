# Revue de Talents (9-Box) (hr_talent_review)

Revue de talents : placement 9-box (performance/potential), revue par équipe avec décision tracée, plans d'actions (développement, mobilité, rétention) et suivi annuel.

## Problème
Les revues de talents sont préparées dans des slides anonymes : grille 9-box jamais tenue à jour et décisions non suivies.

## Fonctionnalités
- Grille 9-box par personne
- Decisions tracées par revue
- Plans d'actions (développement, rétention)
- Suivi des mouvements de box
- Vue portefeuille talents

## Dépendances
- `hr`, `mail`
