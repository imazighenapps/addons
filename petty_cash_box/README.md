# PettyCash Box

Petty Cash Fund Movements and Balance

## The problem

Petty cash tracked on paper leaves no reliable running balance and makes discrepancies visible only at month-end counts.

## The solution

Manage petty cash boxes with opening balance, categorized in and out movements, running balance and periodic cash counts to reconcile expected versus counted cash per company.

## Main features

- Multiple petty cash boxes per company with responsible user.
- Top-up, expense and adjustment movements with categories.
- Expected balance computed from opening balance and movements.
- Cash counts storing expected, counted and difference amounts.
- Search and group by box, movement type, category and period.
- Chatter tracking on boxes and counts.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Petty Cash** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
