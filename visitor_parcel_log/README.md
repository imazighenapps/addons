# VisitorParcelLog

Parcel and Delivery Register

## The problem

Parcels tracked manually lead to missed notifications, delays and lost items.

## The solution

Log incoming parcels with recipient, carrier, arrival, storage location and pickup states to track deliveries at reception.

## Main features

- Parcel records with recipient, carrier and arrival date.
- Tracking reference and storage location.
- Received by and collected by/date details.
- Received, notified, collected and returned states.
- Notes and parcel description.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Parcel Log** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
