# Registre d'Essais R&D (mrp_rd_test_registry)

Registre d'essais : demandes d'essai (objet, protocole, matériel), résultats structurés, conclusion et décision (formulation validée, modification à appliquer).

## Problème
Les essais internes (formulations, prototypes, essais machine) sont notés au carnet : résultats égarés, leçons non capitalisées.

## Fonctionnalités
- Demandes d'essai avec protocole
- Résultats structurés par essai
- Décision et liens vers les changes
- Recherche des essais passés
- Rapport mensuel d'activité labo

## Dépendances
- `quality`, `mrp`, `mail`
