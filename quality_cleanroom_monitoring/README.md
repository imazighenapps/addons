# Relevés d'Ambiance Salle Blanche (quality_cleanroom_monitoring)

Registre d'ambiance : points de mesure par zone, relevés manuels périodiques, limites à l'état repos/activité, déviations traitées et historique pour audits ISO/GMP.

## Problème
Les paramètres d'ambiance (température, hygrométrie, particules) des salles blanches sont relevés à la main et classés hors Odoo : écarts non maîtrisés.

## Fonctionnalités
- Points de mesure par zone
- Limites repos/activité paramétrables
- Déviations tracées avec actions
- Historique pour audits
- Rapports périodiques par zone

## Dépendances
- `quality`, `stock`, `mail`
