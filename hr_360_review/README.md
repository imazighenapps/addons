# Évaluation 360° (hr_360_review)

Campagne 360° : évaluateurs assignés (pairs, subordonnés, clients internes), questionnaire anonymisé, rapport individuel avec repères, plan d'action rattaché.

## Problème
L'évaluation d'un manager ou d'un expert par ses pairs se fait dans des Google Forms : réponses non anonymes, résultats non structurés.

## Fonctionnalités
- Évaluateurs par catégories
- Questionnaire anonymisé
- Rapport individuel avec repères
- Plan d'action rattaché
- Historique par personne

## Dépendances
- `hr`, `mail`
