# LockOut

Locked, Tagged, Restored

## The problem

Lockout/tagout relies on paper tags and memory, so nobody can prove who locked a machine, why it was isolated or who restored it when the audit comes.

## The solution

Run lockout/tagout properly: who locked the machine, why, and who restored it, with no gap in the trace.

## Main features

- A register of lockouts with equipment, tag holder and reason.
- The lock date recorded when the isolation starts.
- The restore date and restorer stamped on every restoration.
- A clear state from locked to restored.
- One open-lockouts screen for everything still isolated.
- A restoration before the lock date is refused for you.
- Chatter traceability on every lockout record.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Lockout** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
