# Rapport SLA Client Mensuel (sla_report)

Rapport SLA client automatique : incidents par type, délais vs engagements, crédits SLA applicables et annexe contractuelle PDF.

## Problème
Les clients sous contrat SLA exigent un rapport de conformité mensuel : reconstitué à la main, il arrive en retard et sous tension.

## Fonctionnalités
- Rapport mensuel automatique
- Incidents par type
- Délais vs engagements
- Crédits applicables
- Annexe PDF

## Dépendances
- `helpdesk`, `mail`
