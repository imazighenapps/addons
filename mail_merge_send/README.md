# Envoi en Masse Personnalisé (mail_merge_send)

Mail merge avec PJ personnalisées : gabarit par destinataire, génération des PDFs, file d'envoi et journal de remise.

## Problème
Envoyer à 200 clients un document personnalisé (attestation, relevé) exige des envois manuels un à un.

## Fonctionnalités
- Gabarit personnalisé
- Génération des PDFs
- File d'envoi
- Journal de remise
- Reprise des échecs

## Dépendances
- `mail`, `base`
