# WarrantyTrack - Product Warranty and Claims

## The problem

Warranties are managed by email. Nobody knows if a serial number is still covered, and the money recovered from the supplier is never tracked.

## The solution

Register the warranty of every serial number, check coverage at claim time, record repair or replacement cost and recover from the supplier.

## Main features

- Warranty per customer, product and serial.
- Automatic end date and coverage status.
- Claim workflow with coverage check.
- Repair and replacement cost.
- Supplier recovery amount.
- Claims history per warranty.
- Expiry scheduler.

## Installation

1. Install the module from the Apps list.
2. Open the **Warranty** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
