# Remises en Cascade (stacked_discount_waterfall)

Cascade d'escomptes ordonnée : chaîne de remises appliquées dans un ordre défini, base de calcul transparente à chaque étape et décomposition visible sur la ligne.

## Problème
Remise commerciale, remise famille, remise promotionnelle s'empilent sans ordre ni trace : personne ne sait quel escompte final a été appliqué ni pourquoi.

## Fonctionnalités
- Chaîne de remises ordonnée
- Base de calcul transparente
- Décomposition sur la ligne
- Règles de cumul autorisé
- Rapport des cascades appliquées

## Dépendances
- `sale`, `product`, `mail`
