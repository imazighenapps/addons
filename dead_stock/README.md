# DeadStock

Dormant Inventory Radar

## The problem

Dormant stock is invisible until the annual inventory: it locks cash, takes space and nobody is accountable for it. By the time it is counted, the season, the customer and the supplier credit are gone.

## The solution

Spot products that no longer move, measure the cash they lock up and the cost of holding them, and decide discount, bundle, return or scrap from one screen.

## Main features

- Detect stock with no customer delivery for N days.
- Value at standard cost and cost of holding.
- Suggested action per line: discount, bundle, return or scrap.
- Persistent scan snapshots with totals.
- Scope by warehouse and product category.
- Actioned, ignored and reopen workflow.
- Kanban, graph and pivot analysis.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Dead Stock** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
