# TimesheetApproval

Timesheet Submission and Approval Log

## The problem

Without a tracked submission record, timesheet approval is hard to audit and billing disputes are difficult to resolve.

## The solution

Track timesheet period submissions per employee with draft, submitted, approved and rejected states, totals and approver comments.

## Main features

- Approval log per employee and period with date range.
- Draft, submitted, approved and rejected states with actions.
- Total logged hours computed for the employee and period.
- Approver, submission and approval dates, and comments.
- Optional project context and notes.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Timesheet Approval** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
