# Compresseur d'Images (image_squeeze)

Optimiseur d'images : compression/dégradation automatique des images volumineuses, seuils par contexte, action groupée et gain mesuré.

## Problème
Les photos produits téléchargées en 10 Mo gonflent la base et ralentissent les sites.

## Fonctionnalités
- Compression automatique
- Seuils par contexte
- Action groupée
- Gain mesuré
- Journal

## Dépendances
- `base`, `mail`
