Installation

Quick Installation

  1. Copy the corporate_gift_desk folder into your addons path.
  2. Restart the Odoo server and update the apps list.
  3. Install Corporate Gift Desk (demo data is available for quick testing).
# Example (Docker / CLI)
odoo -d <db_name> -i corporate_gift_desk --stop-after-init
# Add your DB/host parameters according to your environment
