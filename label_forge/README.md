# LabelForge

Labels Straight From Odoo

## The problem

Warehouse labels are managed in scattered files with no consistent templates and no trace of what was printed, when and for which target.

## The solution

Design the product, lot and location labels your warehouse needs and print them straight from Odoo.

## Main features

- A label template library for product, lot and location labels.
- Template settings for size, content and active status.
- A print job log with target, quantity and template reference.
- States to draft, print and cancel each label job.
- Stored counters linking templates to their print jobs.
- Search filters and group-by views for label type and status.
- Notes on templates and jobs for operational context.
- Multi-company isolation with per-company records.

## Installation

1. Install the module from the Apps list.
2. Open the **Labels** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
