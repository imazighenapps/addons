# FleetTireLog

Fleet Tire Wear and Rotation Register

## The problem

Tire wear tracked in notebooks hides wear and rotation due dates.

## The solution

Track tire fitting, rotation, replacement and removal with tread depth, odometer and cost.

## Main features

- Tire events with vehicle plate, brand and position.
- Event type: fitting, rotation, replacement, removal.
- Tread depth and odometer reading.
- Event date and unit cost.
- Draft, recorded, due and cancelled states.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Fleet Tires** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
