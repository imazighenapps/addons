# Dossiers d'Homologation CE (machine_ce_dossier)

Dossier de conformité par machine : déclaration de conformité, essais consignés, notices versionnées, validité et rappels.

## Problème
Les dossiers CE des machines (déclarations, notices, tests) sont des dossiers papier que les revendeurs réclament à chaque inspection.

## Fonctionnalités
- Dossier par machine
- Déclarations et essais
- Notices versionnées
- Validité suivie
- Émission de copies

## Dépendances
- `documents`, `maintenance`, `mail`
