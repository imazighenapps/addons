# Journal de Chantier (construction_site_diary)

Point quotidien de chantier : effectif par corps de métier, événements et aléas, photos horodatées, avancement, PDF hebdomadaire signé.

## Problème
Le journal de chantier (effectifs, événements, photos) tenu sur un cahier ne ressort jamais quand il faut prouver un aléa.

## Fonctionnalités
- Point quotidien avec effectifs
- Aléas et événements datés
- Photos horodatées
- Avancement par lot
- PDF hebdomadaire signé

## Dépendances
- `project`, `sale`, `mail`
