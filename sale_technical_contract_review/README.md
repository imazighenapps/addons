# Revue de Contrat Technique (sale_technical_contract_review)

Revue de contrat : checklist de faisabilité avant confirmation (matière, capacité, certifications, délais), décisions tracées et conditions de vente ajustées.

## Problème
Les commandes techniques sont confirmées sans vérifier la faisabilité (matière, capacité, spécifications client) : les litiges naissent à la réception.

## Fonctionnalités
- Checklist de faisabilité par commande
- Bloque la confirmation tant qu'incomplète
- Décisions et arbitrages tracés
- Conditions techniques rattachées
- Historique par client

## Dépendances
- `sale`, `mrp`, `mail`
