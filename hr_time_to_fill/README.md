# Délai d'Embauche par Poste (hr_time_to_fill)

Mesure du time-to-fill : étapes datées automatiquement, délai par poste et par canal, alerte sur les postes ouverts depuis trop longtemps, cibles par famille de poste.

## Problème
Personne ne mesure le temps entre l'ouverture d'un poste et l'acceptation de l'offre : les postes critiques restent vacants sans alerte.

## Fonctionnalités
- Étapes datées automatiquement
- Délai par poste et canal
- Alerte sur les postes trop ouverts
- Cibles par famille de poste
- Comparaison annuelle

## Dépendances
- `recruitment`, `mail`
