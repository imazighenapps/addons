# TimeApprove - Weekly Timesheet Approval

## The problem

Odoo Community has no weekly timesheet validation. Hours are edited after invoicing, and nobody can prove which week was approved by which manager.

## The solution

Weekly timesheet submission, manager approval, rejection comments and locking, so approved hours can no longer be edited.

## Main features

- Weekly timesheet per employee.
- Submit, approve, reject with comment.
- Locked hours after approval.
- Reminder for pending weeks.
- Submission and approval history.
- Total hours per week.
- Compatible with standard timesheet lines.

## Installation

1. Install the module from the Apps list.
2. Open the **Timesheet Approval** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
