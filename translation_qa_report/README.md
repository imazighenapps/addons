# QA des Traductions (translation_qa_report)

Rapport de qualité des traductions : termes manquants par module/langue, incohérences de terminologie, placeholders cassés et source à corriger.

## Problème
Les traductions manquantes ou incohérentes apparaissent chez le client, jamais à l'interne.

## Fonctionnalités
- Termes manquants par module/langue
- Incohérences de terminologie
- Placeholders cassés
- Source à corriger
- Historique des passes

## Dépendances
- `base`, `mail`
