# DepositPro - Customer Deposits and Prepayments

## The problem

Customer prepayments live in a spreadsheet: nobody knows which invoice they were applied to, the remaining balance is wrong, and refunds are not traceable.

## The solution

Register customer deposits and prepayments, apply them to posted invoices, track the remaining balance, refund it and report on it.

## Main features

- Numbered deposit register.
- Payment method and journal per deposit.
- Allocation against posted invoices and credit notes.
- Partial and full application.
- Remaining balance kept in sync.
- Refund the remaining balance with a reason.
- Customer and status reporting.
- Multi-company and multi-currency.

## Installation

1. Install the module from the Apps list.
2. Open the **Deposits** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
