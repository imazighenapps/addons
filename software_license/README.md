# LicenseTrack

Software License and Subscription Register

## The problem

Software licenses tracked in spreadsheets risk missed renewals, lapses and unclear seat allocation.

## The solution

Register software licenses with vendor, seats and expiry dates, track active/expired/cancelled status, and keep a company-safe license inventory.

## Main features

- License records with software, vendor and seats.
- Owner, purchase and expiry dates.
- Active, expired and cancelled states.
- Computed expiry flag for visibility.
- Search and group by vendor, owner and state.
- Chatter tracking on records.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Software Licenses** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
