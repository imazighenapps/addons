# Rapports Planifiés (scheduled_reports)

Envoi planifié de rapports : vue/filtre sauvegardé, fréquence, destinataires, PDF/Excel et journal des envois.

## Problème
Les rapports de pilotage sont régénérés à la main chaque lundi : oublis et versions divergentes.

## Fonctionnalités
- Vue sauvegardée
- Fréquence
- Destinataires
- Formats PDF/Excel
- Journal

## Dépendances
- `base`, `mail`
