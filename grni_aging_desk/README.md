# GRNI : Marchandises Reçues Non Facturées (grni_aging_desk)

Desk GRNI : liste des réceptions non facturées avec ancienneté, provision automatique, alerte d'obsolescence et clôture par justification.

## Problème
Les réceptions sans facture (GRNI) s'accumulent : la comptabilité ne sait pas ce qui reste à facturer, les audits pointent les écarts.

## Fonctionnalités
- Liste GRNI avec ancienneté
- Provision automatique
- Alertes d'obsolescence
- Clôture par justification
- Rapport mensuel

## Dépendances
- `account`, `stock`, `purchase`, `mail`
