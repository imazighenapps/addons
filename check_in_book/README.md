# Pointage de Présence Terrain (check_in_book)

Pointage terrain : horodatage à l'arrivée/départ depuis le mobile (géolocalisation optionnelle), preuve jointe à l'intervention.

## Problème
Facturer ou payer sur la foi du technicien seul : aucune preuve de présence sur site (heure d'arrivée/départ).

## Fonctionnalités
- Pointage arrivée/départ
- Horodatage fiable
- Géoloc optionnelle
- Preuve jointe
- Écarts détectés

## Dépendances
- `project`, `mail`
