# Opportunités Parent-Enfants (parent_child_deals)

Opportunités liées : deal parent consolidé, lots enfants avec montants et étapes propres, total consolidé du deal et avancement d'ensemble.

## Problème
Un grand projet se vent en plusieurs lots (matériel, licences, services) : chaque lot devient une opportunité isolée et la vision du deal global disparaît.

## Fonctionnalités
- Deal parent consolidé
- Lots enfants autonomes
- Total consolidé du deal
- Avancement d'ensemble
- Rapport du deal par lot

## Dépendances
- `crm`, `sale`, `mail`
