# CashCountLog

Cash Count and Reconciliation Register

## The problem

Manual cash counts lack a consistent, auditable reconciliation record.

## The solution

Record cash counts with expected and counted amounts, computed difference, notes and validation states for reconciliation.

## Main features

- Cash count records with date, location and counter.
- Expected, counted amounts and computed difference.
- Discrepancy notes and reviewer.
- Draft, submitted and validated states.
- History of counts and variances.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Cash Counts** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
