# Chatbot FAQ Interne (faq_bot)

Chatbot FAQ interne : base de connaissances structurée, réponses sourcées, escalade vers une personne et métriques d'usage.

## Problème
Les mêmes questions de procédure (congés, achats, process) arrivent à RH/IT toute la journée.

## Fonctionnalités
- Base de connaissances
- Réponses sourcées
- Escalade
- Métriques d'usage
- Mise à jour guidée

## Dépendances
- `mail`
