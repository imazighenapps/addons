# Conciliation des Relevés Fournisseurs (supplier_statement_recon)

Assistant de conciliation fournisseurs : import du relevé, propositions de correspondance, écarts classés (en retard, inconnus, frais) et journal de conciliation.

## Problème
Les relevés de compte fournisseurs reçus diffèrent du solde Odoo (retards d'enregistrement, frais) et la conciliation est manuelle.

## Fonctionnalités
- Import du relevé fournisseur
- Propositions de correspondance
- Écarts classés
- Journal de conciliation
- Suivi des conflits

## Dépendances
- `account`, `mail`
