# Visionneuse de Logs (log_viewer)

Visionneuse intégrée : filtres par niveau/module/utilisateur, recherche, corrélation aux enregistrements et export d'analyse.

## Problème
Diagnostiquer une erreur exige d'accéder au serveur et de grep les logs : impossible pour un administrateur fonctionnel.

## Fonctionnalités
- Filtres avancés
- Recherche
- Corrélation aux records
- Export
- Retenue configurable

## Dépendances
- `base`, `mail`
