# Baromètre d'Engagement (hr_engagement_survey)

Baromètre : campagnes récurrentes (semestrielles) avec questionnaire paramétré, anonymat garanti par seuils de réponse, résultats par équipe avec repères et tendances.

## Problème
La mesure d'engagement se fait via des plateformes tierces coûteuses : les PME renoncent faute de solution intégrée.

## Fonctionnalités
- Campagnes récurrentes
- Questionnaire paramétrable
- Anonymat par seuil de réponse
- Résultats par équipe avec tendance
- Plan d'action rattaché

## Dépendances
- `hr`, `mail`
