# MarginGuard

No Discount Below The Floor

## The problem

Discount floors live on a whiteboard and disappear under year-end pressure: order lines ship below margin without anyone noticing, and the loss is discovered on the finance review instead of at the order.

## The solution

Set discount and margin floors per product or category and block the sale order line until the rule is respected.

## Main features

- Discount and margin floors in percentages, in one place.
- A scope for each rule: product, category, customer or global.
- Each attempt below a floor becomes an explicit check.
- The reference, discount and margin requested on each check.
- Approve or refuse, with date and decision maker recorded.
- One screen of the approvals you still have to chase.
- A rule without any floor is refused for you.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Margin Guide** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
