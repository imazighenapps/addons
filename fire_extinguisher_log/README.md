# FireExtinguisherLog

Fire Extinguisher Inspection Register

## The problem

Extinguisher checks tracked on paper leave due dates and failures unclear.

## The solution

Record fire extinguisher inspections with location, type, dates, pressure and seal results.

## Main features

- Extinguisher records with reference, type, capacity and location.
- Last and next inspection dates with overdue tracking.
- Pressure and seal check results.
- Responsible inspector and notes.
- Draft, validated, overdue and cancelled states.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Fire Safety** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
