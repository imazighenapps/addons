# PatrolBook

Rounds You Can Prove

## The problem

Security patrols live on clipboards, so skipped checkpoints and on-site findings cannot be proven to the next shift, the client or the auditor.

## The solution

Record the security patrol rounds and their findings, and expose the checkpoints that were skipped.

## Main features

- A register of patrol rounds with guard, route and schedule.
- Stops per round with checkpoint, status and observation.
- The time each checkpoint was checked, stored on the stop.
- Skipped checkpoints exposed and counted on the round.
- Findings flagged on a stop for quick follow-up.
- A single screen to review rounds and their stops.
- A stop time before the round start is refused for you.
- Multi-company isolation out of the box.

## Installation

1. Install the module from the Apps list.
2. Open the **Patrol Book** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 20.0 Community and Enterprise.
- Odoo 18.0 and 19.0 versions are provided separately.
- No external Python dependency.
