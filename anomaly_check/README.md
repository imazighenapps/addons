# AnomalyCheck

Impossible Bills Caught

## The problem

Bills are reviewed by eye, so impossible quantities, VAT mismatches and duplicated lines slip through until after posting when corrections are costly and hard to explain.

## The solution

Scan bills before posting for impossible quantities, VAT mismatches and suspicious doublings of products.

## Main features

- A catalog of anomaly rules with control type and tolerance.
- Severity levels to separate warnings from blocking findings.
- A queue of flagged checks with document and supplier details.
- Quantity, tax and total amounts stored on every check.
- Stored counters per rule for how often each control fires.
- A review workflow to confirm, resolve or reject findings.
- Search filters and groupings for fast triage.
- Multi-company isolation for rules and checks.

## Installation

1. Install the module from the Apps list.
2. Open the **Anomaly Check** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 19.0 Community and Enterprise.
- Odoo 18.0 and 20.0 versions are provided separately.
- No external Python dependency.
