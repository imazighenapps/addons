# AccessRequest

IT Access and Permission Requests

## The problem

IT access requests handled informally lack an approval trail and auditable record of granted or revoked access.

## The solution

Request, approve and track IT access to systems and resources with justification, workflow states and a company-safe audit trail.

## Main features

- Access requests with system/resource, access type and justification.
- Submit, approve, refuse, grant and revoke workflow.
- Needed-by date and reviewer notes.
- Search and group by requester, system and state.
- Chatter tracking on requests.
- Multi-company safe, no Enterprise dependency.

## Installation

1. Install the module from the Apps list.
2. Open the **Access Requests** menu.
3. Create your first record and follow the guided empty state.

## Compatibility

- Odoo 18.0 Community and Enterprise.
- Odoo 19.0 and 20.0 versions are provided separately.
- No external Python dependency.
