# File d'Ordonnances (pharma_rx_queue)

File d'ordonnances avec étapes de dispensation, double contrôle signé, statuts visibles au comptoir et délais par ordonnance.

## Problème
Le circuit de l'ordonnance (réception, préparation, délivrance, double contrôle) vit au comptoir sans traçabilité.

## Fonctionnalités
- File par ordonnance avec étapes
- Double contrôle avec signatures
- Statuts visibles au comptoir
- Délais et goulots par étape
- Registre de dispensation

## Dépendances
- `sale`, `stock`, `mail`
