# Carnet de Pension Équestre (horse_boarding_book)

Contrat de pension avec planning de soins quotidien, passages maréchal et vétérinaire tracés, extras facturés au client.

## Problème
Les pensions de chevaux (box, nourrissage, maréchal, véto) sont facturées de tête et les extras se perdent.

## Fonctionnalités
- Contrat de pension par cheval
- Soins quotidiens tracés
- Maréchal et véto consignés
- Extras facturés
- Historique par cheval

## Dépendances
- `sale`, `account`, `mail`
