# Motifs de Clôture d'Intervention (outcome_book)

Motifs de clôture : codes obligatoires par type d'intervention, statistiques par motif, actions de fond (stock de pièces, formation) et rapports.

## Problème
Les interventions se clôturent sans motif structuré : aucune analyse des raisons (réparé, pièce à commander, refus client, report).

## Fonctionnalités
- Codes de clôture obligatoires
- Statistiques par motif
- Lien aux actions
- Rapport mensuel
- Amélioration continue

## Dépendances
- `project`, `mail`
